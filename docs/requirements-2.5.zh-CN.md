# MangaView 2.5 需求（整理稿）

基于 2.4.0。未写到的地方沿用 README 与 docs/dev-guidelines.zh-CN.md 的现有行为。
标记：**【补】** 原话没有、补全的细节；**【议】** 与原话不同、已获同意的做法。第 11 节的 8 项均已确认（2026-11-27）。

## 1. 文件栏（新，位于总控栏上方）

视频画面内的浮动控件与总控栏都在窗口底部，互相遮挡。改为：总控栏上方加一行「文件栏」，作用于当前文件，与总控栏一起弹出 / 收起。

```
[ 文件名 ][ ▶ ───●────── 0:42 / 3:10 ][ 字幕 书签 区段 封面 全屏 ]   ← 文件栏
[ 左区：阅读 ][ 中区：运行 ][ 右区：媒体 ]                            ← 总控栏
```

- 左：文件名（只显示末段，限长约 24 字，省略中间，完整路径在悬停提示）。
- 中：媒体的播放 / 暂停、进度条（含书签与区段标记）、当前时间 / 总时长；图片时留空。
- 右（靠右对齐，只有图标）：
  - 图片：添加书签、添加区段书签、设置为封面；
  - 视频：字幕、添加书签、添加区段书签、设置为封面、全屏；**【补】**
  - 音频：字幕、添加书签、添加区段书签。
- 三种文件的布局一致，按钮位置不随类型跳动（没有的按钮留空位）。**【补】**
- **当前文件**：有选中媒体（见第 3 节）时是它；否则是视窗中心所在的页。快捷键与文件栏作用于同一个对象。**【补】**
- 视频画面内不再有浮动控件，只剩字幕和未选中时的大播放键。
- 音频卡片自己的控件保留，与文件栏同时存在。
- 视频全屏、新窗口播放里同样是鼠标到底缘弹出文件栏 + 总控栏。**【补】**
- 「设置为封面」：直接以当前画面作封面（图片取视窗中心处，按封面比例截取；视频取当前帧），不必先加书签；音频没有。

## 2. 总控栏

- 默认高度一行。去掉左下、右下两行状态文字：书名与阅读进度并入顶部工具栏下方的名称区；当前媒体的文件名与时间在文件栏。
- **顶部名称区**：一行「书名 · 当前页 / 总页数 · 进度」，最小宽度加宽（约 320px），过长省略书名末尾；整块可点击，打开书架页（等同「书架」按钮）。
- **布局**（重新设计，17 个按钮 + 大播放键，左右对称）：**【议】**

```
左区 6：上一本 书首 书尾 下一本 │ 跨书 滚动速率
中区 5：播放模式 只播区段 【▶】 单文件 循环
右区 6：上一个媒体 下一个媒体 播放顺序 │ 播放速率 音量 新窗口播放
```

  - 「播放模式」收为一个二级按钮：图标显示当前模式，悬停 / 聚焦在上方弹出漫画、混合、影音三项，点击按钮轮换。
  - 「循环」现在三种模式都可用，从右区移到中区，与「只播区段」「单文件」同属运行开关。
- **变窄时**（总控栏自身最高两行，文件栏另算一行）：
  1. 放得下：一行；
  2. 放不下：左、右区各自把次要按钮收进本区的「⋯」弹出层，仍是一行。左区留上一本 / 下一本，右区留下一个媒体 / 音量；
  3. 仍放不下（约 420px 以下）：两行，中区一行，左、右区并排一行。
- 与当前模式无关的按钮变暗禁用、不隐藏不挪位（不变）。
- 底缘的鼠标唤起距离由 32px 加到 48px，其余三边不变。
- `T` 同时显示 / 隐藏顶部工具栏和底部总控栏（含文件栏）。

## 3. 选中媒体与外观

同意你的判断：不引入焦点（focus）状态，只有「播放选中」一个状态，图片没有任何状态。

- **选中**：点击画面 / 播放键、开始播放、上一个 / 下一个媒体切到、书签跳到它时成为选中媒体；暂停后仍是选中；中线离开视窗、选中了别的媒体或切书时取消。一个窗口最多一个。
- **外观**（视频、音频统一）：
  - 未选中：压暗，中央显示大播放键；
  - 选中：不压暗，不用描边。播放与暂停的区别只在播放键图标、进度条颜色和音频的跳动音柱。
- 去掉「当前媒体带强调色外框」和「暂停的视频变暗」。

## 4. 音频卡片、音频书签、缩略图

- **音频卡片**：封面不再作整块背景，改为卡片右侧的一张小图（像内嵌专辑图）；卡片为纯色底，去掉遮罩（亮边问题随之消失）。
- **占位封面**：所在的书没有封面时，用一张非暗色的默认占位图。**【议】** 占位图按文件名自动配色（浅色渐变 + 音符图形，代码生成，不加图片文件），不同文件一眼可分。
- **音频书签**（各书签列表）：去掉大音乐图标，不压暗，显示封面 / 占位图；右下角的小音乐图标 + 时间不变。
- **缩略图栏、全屏缩略图里的音频**：去掉大图标和遮罩，显示封面 / 占位图；小音乐图标 + 时长在上，文件名在最下。
- **缩略图的书签角标**（所有类型的页）：最多一个书签图标 + 数量；这一页有区段书签时图标为区段蓝色，不再并排显示多个图标。左侧的细标记不变。
- **成对的区段书签**（各书签列表）：平时不带蓝色边框，只保留互相呼应的标记；悬停 / 选中时两项一起蓝色高亮；作为最近书签时只高亮那一项（见 5.1）。

## 5. 书签

### 5.1 最近书签

- 把书签排成一条线：阅读列表里书的顺序 → 页序 → 页内位置（图片按位置，视频、音频按时间先后）。区段的起点和终点各算一项。
- 最近书签 = 当前阅读位置**之前**最近的一项；后面的不参与。视窗中心所在页是媒体时，位置取它的当前播放时间。
  - 例：播放到 6:30，最近的是本文件 5:23 的书签；4:20 的更远；上一个文件或图片的书签更远。
- 本书里前面没有书签：取阅读列表中前面最近一本有书签的书的最后一个。整个列表前面都没有：不高亮。**【补】**
- 区段不整段高亮，只高亮这一项。
- 用在：书签面板（只显示本书，前面没有则不高亮）、书架书签列表（自动滚到这一项）、全屏书签打开时的选中项、5.2 的默认选项。

### 5.2 添加区段书签

- 任何入口（长按 `Shift+F` / `Shift+Enter`、书签面板、文件栏、音频卡片）都先弹出「选择起点」：
  - 媒体：列出当前文件里当前时间之前的书签；
  - 图片：列出本书当前位置之前的图片书签；
  - 默认选中最近的一个，可直接回车 / 点「确定」；方向键或点击改选，`Esc` 取消。
- 终点的位置 / 时间取触发的那一刻，不取点确定的时刻；媒体不因弹窗暂停。**【补】**
- 所选起点已有区段：把它的终点移到这里（列表里标明）。区段书签（终点）不能作起点。**【补】**
- 前面没有可选书签：提示先添加普通书签。
- 图片书签与媒体书签互不配对、终点离起点太近按已存在处理（不变）。

### 5.3 区段可以嵌套

- 允许区段嵌套。**【议】** 同时允许交叉（由用户自选起点，交叉无法避免，禁止反而要解释为什么某些起点不能选）。
- 「只播放书签区段」按所有区段的**并集**进行：重叠、嵌套的区段合并成一段，不重复播放。进度条上并集以外变暗。
- 进度条：区段按嵌套深度分层画（最多 3 层）；悬停某个标记只高亮它这一对并提示两端时间；标记挤在一起时取离指针最近的；点击跳到该标记的时间。
- 缩略图栏左侧的细标记、全屏缩略图的区段范围：嵌套的区段向内缩进一级，最多 3 级。
- 书签列表里仍是起点、终点前后紧挨，按起点位置排序。

### 5.4 右键书签面板

- 顶部：「添加书签」「添加区段书签」两个不带文字的中等按钮（区段按钮用区段蓝色），旁边一个小的「设置为封面」图标按钮。鼠标仍落在「添加书签」上。
- 检查并统一：所有区段相关的颜色都用区段配色，不留橙色。

## 6. 阅读列表与删除当前书

- **阅读列表** = 书架页当前选中的页签（书架 / 书库 / 全部）+ 当前筛选 + 书籍排序。切到哪个页签，上一本 / 下一本、跨书运行、书签快捷键跨书就按哪个列表；选中「过期书籍」时沿用之前的列表。**【补】**
- 当前书不在这个列表里时，从它按排序应在的位置走到最近的一本（现有规则）。
- 书架书签列表也跟着这个列表走（现在固定是书架）。
- **删除当前书**（本窗口或别的窗口删除）：切到阅读列表里原顺序的下一本；没有下一本则上一本；列表空了回到书架页。

## 7. 混合模式：相邻媒体直接定位

运行中当前播放的是视频 / 音频，页序上紧挨的下一页也是视频 / 音频：播完直接定位到下一个（居中）并播放，不匀速滚动。图片与媒体之间仍按现在的方式滚动。

## 8. 拖动滚动

- 查明并消除卡顿（缩略图未加载完的缩略图栏最明显）。要求：
  - 拖动中每帧最多写一次滚动位置；
  - 缩略图占位尺寸固定，加载完成不引起重排；解码不占主线程；
  - 高速拖动 / 滑行时不发起新的缩略图读取，慢下来或停下再加载。
- 惯性上限加大：起步速度上限 8 → 20 px/ms，高速时衰减更慢，最快一甩约滑行 12000px（现在约 2600px）。
- **【议】** 滑行未停时同方向再甩，速度叠加（触屏系统的做法），超长列表可以越甩越快。

## 9. 添加：多选

保持现状，不做改动：文件在系统选择框里可多选；文件夹一次选一个（浏览器限制），多个文件夹靠从资源管理器拖入窗口或添加对话框。

## 10. 验收

- 每项有端到端或核心测试；规则类（最近书签、区段并集、阅读列表、删除后切书、惯性）写成纯函数放 `src/core/` 并测。
- 人工验收：拖动卡顿与新惯性手感、总控栏各宽度下的折叠、音频卡片与占位图观感、嵌套区段在进度条上的可读性、全屏下的文件栏。
- 完成后版本 2.5.0，README 两份与 dev-guidelines 同步，本文件删除。

## 11. 已确认

1. 视频画面内的浮动控件全部移到文件栏，画面内只留字幕和未选中时的大播放键。
2. 音频的图：有封面用书的封面，没有才用占位图。
3. 区段允许嵌套和交叉，只播区段按并集。
4. 书架书签列表跟随当前页签（书库 / 全部也显示书签），藏书很多时的性能要验证。
5. 多选文件夹不做，保持现状。
6. `T` 同时开关顶部工具栏和总控栏（含文件栏）。
7. 视频的文件栏也有「设置为封面」，取当前帧。
8. 快捷键长按添加区段书签时也弹出「选择起点」，回车即确认。
