# MangaView 需求：书签角标与搜索、视频 / 音频、区段书签、PotPlayer 书签、多窗口

状态：已在 2.3.0 全部实现（2026-11-26，分支 2.0）。第 14 节各项按文中的建议方案实现。
未写明之处一律按 `docs/dev-guidelines.zh-CN.md` 执行。文中「媒体」指视频和音频，「页」指书中的一个文件（图片、视频或音频）。
带 **[待确认 n]** 的条目按建议方案写入，对应第 14 节。

## 1. 范围

**做：**

1. 缩略图上的书签角标；全屏书签、全屏缩略图的搜索框与类型过滤。
2. 视频、音频文件作为页融入现有的纵向流式布局：播放器壳、统一音量、自动播放、播放顺序与循环、播放位置记忆。
3. 媒体书签、进度条书签标记；区段书签与「只播放书签区段」。
4. 媒体相关的封面、缩略图、恢复（文件搬家后的匹配）。
5. 自定义书籍封面与重置封面（对所有书生效，不限媒体）。
6. 「导入为单个作品」的命名规则；长名称的显示。
7. 窗口尺寸变化时阅读区的稳定性（含修复现有的缩放跳动）。
8. 快捷键调整。
9. 多窗口数据同步；从播放器一键在新窗口播放。
10. 导入 PotPlayer 书签文件（.pbf）并跟随其更新。

**不做（本轮）：**

- 第三方播放器或解码库：第一版只播放浏览器原生能播的格式（3.1）。开源播放器库只是界面外壳，解码仍靠浏览器，不会增加可播格式；真正扩展格式要用 ffmpeg.wasm 一类的软解，体积大、速度慢，留待以后评估。
- 独立的播放器页面、字幕（.srt / .ass）、歌词（.lrc）、倍速、画中画。
- 图片的自动滚动播放（区段书签的数据为它预留）。
- 向 .pbf 写回书签（不修改用户原文件）；读取 .pbf 内嵌的缩略图（实测为 72×72，太小）。
- 音频内嵌封面（要自写 ID3 / FLAC / MP4 三种标签解析，且多数文件没有）。
- 应用内编辑书签名称。

## 2. 书签角标、全屏界面的搜索与过滤

### 2.1 缩略图上的书签角标

- 缩略图栏和全屏缩略图中，有书签的页在缩略图一角显示书签角标；同一页有多个书签时角标带数量。
- 角标用绝对定位叠加，不改变缩略图尺寸和排布；添加、删除书签后只更新对应的那一格。
- 缩略图栏是正文的等比缩小长条：除角标外，在该页缩略图侧边按书签的页内位置画出细标记，区段书签也画出标记（4.4）；媒体页不画位置标记，只有角标。

### 2.2 搜索框

- 全屏缩略图、全屏书架书签的标题行各加一个搜索框。
- 匹配范围：
  - 全屏缩略图：文件名（含合并作品的卷文件夹名）。
  - 全屏书架书签：作品名、书签所在文件的文件名、书签名称（4.1）。作品名命中时显示该作品的全部书签。
- 输入即过滤，不匹配的项隐藏；键盘选择只在结果内移动。清空后恢复完整列表，选中项回到当前页 / 当前位置附近的书签。
- 打开全屏界面时焦点仍落在当前内容上，不落在搜索框；`/` 或 `Ctrl+F` 聚焦搜索框（与书架页一致）；搜索框内 `Esc` 先清空并回到列表，再按一次才关闭界面。
- 搜索词和类型过滤只在本次打开期间有效，关闭全屏界面即清空，不持久化、不影响上一本 / 下一本和书签跳转。
- 没有结果时提示「没有匹配的项」并给出一键清除，与「本来就没有书签」区分。

### 2.3 类型过滤

- 两个全屏界面的搜索框旁有「图片 / 视频 / 音频」三个开关（图标按钮），可多选，全不选等于不限。
- 书架页的筛选面板加同样的三个类型选项：书中含有任一所选类型的页即匹配。它是书架筛选条件的一部分：随条件持久化、可存入搜索预设、计入「清除筛选」和生效条件提示，并同样限定上一本 / 下一本与书架书签的范围。
- 书架封面上，含视频 / 音频的书显示类型角标。

## 3. 视频、音频

### 3.1 识别与格式

- 按扩展名识别。视频：mp4、m4v、webm、mkv、mov、ogv；音频：mp3、flac、wav、ogg、oga、opus、m4a、aac、weba。
- 「每个直接包含图片的文件夹算一本书」改为「直接包含图片、视频或音频」。只有视频或音频的文件夹也成书。刷新同样同步媒体文件的增删。
- 排序（文件名 / 修改时间 / 打乱）对所有类型的页一视同仁，图片和媒体按同一规则混排。
- 直接拖入的散落媒体文件并入散图图集（名称不变）。
- 文案里专指图片的说法（「没有图片」「N 张」等）改成对三种类型都成立的说法，四种语言同步。

### 3.2 不支持的文件，以及不重复探测

- **导入时提示**：所选内容里有浏览器播不了的媒体文件（按扩展名判断：avi、wmv、flv、rmvb、rm、ts、m2ts、mpg、mpeg、vob、3gp、asf、wma、ape、ac3、dts 等）时，导入结果里说明「有 N 个媒体文件的格式不受支持，未导入」并列出涉及的扩展名。这些文件不建立记录。刷新时不再重复提示。
- **扩展名受支持但实际播不了**（编码不支持，如部分 mkv 的 HEVC 画面、AC3 / DTS 音轨）：这要打开文件才知道。该页显示「浏览器无法播放此文件」占位，带「重试」，不影响其他页；画面能播但音轨不支持时照常播放画面。
- **只看文件名，不打开文件**：一个文件是不是内容、是否受支持，导入和刷新时都只凭扩展名判断。非内容文件和不支持的文件除了列目录本身，不产生任何读盘；刷新只比较文件名清单，不会因为「目录里有没导入过的文件」而去读它们。
- **一个文件只探测一次**：需要打开文件才能得到的结果——能否播放、帧尺寸、时长、缩略图（包括生成失败）、.pbf 的内容——连同文件的大小和修改时间一起记下来。文件没变就不再探测；失败的也不在每次启动、每次刷新时重试，只在用户点「重试」或文件变化后重做。
- 检查「文件有没有变」不主动遍历：只在该页本来就要被读取（进入视窗、播放、生成缩略图）时顺带比较。

### 3.3 布局

- 媒体页与图片页在同一条纵向流里，占一页的位置，不另开页面。
- 视频：宽度规则与图片相同（跟随「铺满 / 小图不放大」），高度按帧比例；高度超过阅读视窗时等比缩小到正好一屏并居中，保证整帧可见。封顶值随窗口变化的处理见 9.2。尺寸未知前用 16:9 占位，读到后记入书目记录，之后不再为排版读文件。
- 音频：固定高度的横条，宽度随阅读区并设上限，居中。内容为类型图标、文件名、播放器壳。
- 尺寸从占位变为实际值时不得把当前画面挤走（沿用图片加载的锚定方式）。
- 缩略图栏、全屏缩略图中：视频显示画面缩略图（3.10），音频显示固定样式的小块（图标 + 文件名）；两者都带类型角标，时长已知时显示时长。

### 3.4 播放器

- 原生 `<video>` / `<audio>` 元素负责播放，外面套一层自绘的壳提供控制；不显示浏览器自带的控制条（它的进度条画不了书签标记）。视频和音频共用同一套壳。
- 壳上的控件全部是图标按钮，名称放在提示和 aria-label 里：
  - 播放 / 暂停；
  - 进度条（书签与区段书签的标记，4.3、4.4），可点击、拖动定位；当前时间 / 总时长；
  - 静音、音量滑块；
  - 添加书签、添加区段书签；
  - 只播放书签区段（开关，4.5）；
  - 播放顺序（单集 / 列表 / 随机，一个按钮轮换）、循环（开关），见 3.7；
  - 新窗口播放（10.2）；
  - 全屏（仅视频）。
- 宽度不够时，次要控件收进一个弹出层，不换行、不溢出；状态变化（时间位数、按钮禁用）不引起其他控件移动。
- 视频的壳浮在画面底部，鼠标移开或播放中静止数秒后淡出，不参与布局；音频的壳常显。
- 全屏：全屏的是整个播放器（画面 + 壳），书签标记和全部快捷键在全屏中照常可用，`Esc` 退出。
- 鼠标：单击画面播放 / 暂停（媒体区域内不再触发左右半屏翻屏）；在画面上按住拖动仍是滚动正文；滚轮滚动正文，不调音量；中键自动滚动、右键书签面板照常。
- 只读方式播放：通过对象 URL 交给浏览器按需读取，不把媒体文件整体读进内存。

### 3.5 当前媒体

快捷键和「添加书签」作用的对象，定义为：

1. 本窗口正在播放的媒体；
2. 否则，中线在视窗内且离视窗中心最近的媒体（暂停的也算）；
3. 都没有则「无当前媒体」。

### 3.6 自动播放

- 设置项「自动播放」，默认开启，登记到 `ctx.prefs`。它只决定「滚到一个媒体时是否自动开始」，播完之后的行为由 3.7 决定。
- 开启时：滚动停稳（约 300 ms 无滚动）且本窗口没有媒体在播放，则播放中线在视窗内、离视窗中心最近的媒体。快速滚动经过不触发；已在播放的媒体不会被滚动中更靠近中心的媒体抢走。
- 正在播放的媒体中线离开视窗即暂停并记下位置（视频、音频相同；后台听用新窗口）。
- 用户手动暂停的媒体，在离开视窗再回来之前不自动播放。
- 启动或恢复阅读位置后，本窗口发生过用户操作（按键、点击、滚轮）之前不自动播放，避免一打开就出声。
- 一个窗口同时只有一个媒体在播放：开始播放另一个时，前一个暂停。不同窗口之间互不干预（新窗口播放的交接除外）。

### 3.7 播放顺序与循环

两个独立的控件，决定一个媒体播完之后做什么：

| 播放顺序 | 循环关 | 循环开 |
| --- | --- | --- |
| 单集 | 播完停下 | 重复播放当前媒体 |
| 列表 | 按页序播放下一个，最后一个播完停下 | 最后一个之后回到第一个 |
| 随机 | 随机且不重复，全部播过一遍后停下 | 一轮播完重新洗牌，继续 |

- 「列表」是当前书里全部可播放的媒体，按当前页序；图片跳过，无法播放的跳过。
- 切到下一个媒体时，把它滚到视窗内居中并从头播放（开启「只播放书签区段」时从它的第一个区段开始）。
- 默认：列表、循环关。两项设置持久化，视频、音频共用，跨窗口同步，登记到 `ctx.prefs`。
- 播放顺序按钮的图标随状态变化，三种状态图标不同。

### 3.8 音量

- 全应用一套音量和静音状态，所有视频、音频共用；静音后所有内容都静音。持久化，跨窗口即时同步。
- 调节入口：壳上的音量滑块与静音按钮，快捷键 `Q` / `E`、`;` / `'`（每次 5%，可按住连续调）。调节时短暂显示音量提示。

### 3.9 播放位置记忆

- 每个媒体记住上次的播放位置；用户滚到它或手动播放它时从该处继续。播到结尾（剩余不足 5 秒）时清除，下次从头播放。按 3.7 自动切换到的媒体从头播放。
- 只在暂停、离开视窗、切书、关闭窗口时保存，播放中至多每 10 秒保存一次；不在 `timeupdate` 路径上写存储。
- 随书目记录走：进入备份；媒体文件被移除时一并清掉。

### 3.10 缩略图与封面

- 视频页的缩略图：优先用该视频时间最早的书签画面；没有书签时取片长约 10% 处的画面，画面接近纯黑则再试 30%、50%，至多三次。（浏览器无法枚举关键帧，按时间点取帧，不保证恰好是关键帧。）
- 视频缩略图生成代价高于图片，生成后以压缩小图持久化；只为可见项生成，串行、空闲时进行，让位于正在播放和阅读的内容。图片页缩略图仍只在会话内存里缓存。
- 默认封面：按文件名顺序第一个有画面的页，图片用图片本身，视频用上述缩略图。全书只有音频时，用作品名生成文字封面（长名称换行、截断）。
- 封面的选取与恢复用的识别指纹（第 5 节）分开，互不影响。

### 3.11 硬盘与资源

- 导入、刷新只列目录，不为此打开媒体文件。时长、帧尺寸在该页首次进入视窗附近时才读取并缓存到书目记录。
- 视窗外的媒体元素释放（卸载源、释放解码器）；同一时间只有当前媒体持有解码资源，不预加载相邻媒体的内容。
- 读取元数据、截取缩略图有超时，超时按失败处理并让出名额；单个文件卡住不拖住其他页。

## 4. 书签的扩展

### 4.1 媒体书签的数据

- 媒体书签存入普通书签列表，与图片书签同一套数据、同一批界面（书签面板、书架书签、全屏书架书签）。
- 媒体书签记录所在文件和时间点（毫秒精度）；图片书签记录所在文件和页内位置，不变。
- 书签新增可选的「名称」字段，目前只来自 .pbf 导入（第 11 节），显示在提示和全屏书签的说明文字里，可被搜索。
- 排序：按页序；同一个媒体文件内按时间先后。

### 4.2 操作

- 长按 `F` / `Enter`、书签面板的「添加书签」、壳上的添加书签按钮：有当前媒体时，在它的当前播放时间加书签；否则按现有规则在屏幕中央的图片位置加书签。
- 同一媒体 2 秒内已有书签时提示已存在，不重复添加。
- 单击 `F` / `Enter`（`Shift` 反向）跳转书签对媒体书签同样有效：滚到该媒体并定位到书签时间；自动播放开启则从该处播放，关闭则停在该画面。书架书签常驻时跨书前进的规则不变。
- 媒体书签的缩略图：视频为书签时间点的画面；音频没有画面，显示固定样式的小块（图标 + 时间 + 名称）。

### 4.3 界面

- 书签列表中，视频、音频书签带各自的类型角标并显示时间点；图片书签不加角标。
- 进度条上按时间位置画出该文件全部书签的标记点。悬停标记点显示时间与名称（只提示），点击跳到该时间。标记点浮在进度条之上，不改变壳的布局；书签增删后即时更新。

### 4.4 区段书签

- 「区段书签」是加在一个普通书签之后、与它配成一对的附属书签；两者之间是一个「书签区段」，前面那个称为这一对的起点书签。一个书签最多带一个区段书签。
- 区段书签不是独立的书签：不计入书签数量，不是 `F` / `Enter` 跳转的停靠点，不在列表里单独占一项。
- 它记录的内容与普通书签相同（所在文件 + 页内位置或时间点），有自己的缩略图，生成规则相同。
- 区段之间不嵌套、不交叉：已有区段的范围内不能再建区段。区段内可以照常添加普通书签，它们不参与配对。
- 添加：长按 `Shift+F` / `Shift+Enter`，或书签面板、播放器壳上的「添加区段书签」按钮。取当前位置（判定方式同添加书签），按下面的顺序确定配给谁：
  1. 当前位置在某个已有区段之内：配给这个区段，把它的终点更新到当前位置。
  2. 否则向前找最近的一个「区段」或「不在任何区段内的普通书签」：
     - 最近的是区段：把它的终点更新到当前位置（延长）；
     - 最近的是普通书签：以它为起点新建区段。
  3. 前面什么都没有时提示，不添加。
- 同类型才配对：媒体只在同一个文件内按时间找；图片按当前页序找，可以跨页；图片书签与媒体书签互不配对。
- 更新终点时提示已更新，旧终点的缩略图换成新的。
- 配对确定后固定在起点书签上，不随之后添加的书签改变。
- 删除：删除区段书签（终点），起点书签变回普通书签；删除起点书签，它的区段书签一并删除。
- 区段书签必须在起点书签之后。图片的页序因排序改变而使它排到前面时，该区段暂不生效，数据保留。
- 从 .pbf 导入的书签没有区段书签，可以在应用内补加。区段书签进入备份。

**标记**

- 起点书签的标记是普通书签标记的变体，区段书签的标记与它成对（形状互为呼应，一眼能看出是一头一尾）；没有区段书签的普通书签标记不变。这套成对标记在所有出现书签标记的地方通用：书签列表、缩略图角标、缩略图栏的位置标记、进度条。
- 鼠标悬停或键盘聚焦到一对中的任意一个，另一个同样高亮（悬停只提示，不跳转）。

**书签列表**（书签面板、书架书签、全屏书架书签）

- 带区段书签的书签显示为一组：起点缩略图加一张较小的区段书签缩略图，各带自己的成对标记。点哪张跳到哪个位置。
- 区段书签的缩略图上有单独的删除入口。

**缩略图**

- 全屏缩略图和缩略图栏里，区段书签所在的页也标出来，用它的成对标记，与起点书签的标记区分。
- 全屏缩略图：悬停或聚焦到带起点书签或区段书签的页时，把这个区段覆盖的所有页的缩略图标出范围（起点页到区段书签所在页）；移开即消失。范围标记是叠加层，不改变排布。
- 缩略图栏：只在对应的页内位置画出起点和区段书签的标记，不画范围。

**进度条**

- 起点和区段书签都画出成对标记。悬停或聚焦其中任意一个时，高亮两者之间的区段，并提示两端的时间与名称；点击跳到该标记的时间。
- 开启「只播放书签区段」时区段常显（4.5）。

### 4.5 只播放书签区段

- 播放器壳上的开关，全局设置，持久化，跨窗口同步，登记到 `ctx.prefs`。
- 与播放顺序、循环互不冲突：本开关决定一个媒体内播放哪些部分，3.7 决定一个媒体播完之后做什么。
- 开启后，一个媒体内只播放它的书签区段，按时间先后：
  - 开始播放或自动切到该媒体时，从当前时间之后的第一个区段起点开始；
  - 播到区段末尾，跳到下一个区段的起点；
  - 最后一个区段播完，视为该媒体播完（单集循环即回到第一个区段）。
- 手动把进度拖到区段之外时不强行跳回，从该处正常播放，进入后面的区段后恢复按区段跳转。
- 没有区段的媒体：按 3.7 自动切换时跳过；用户手动播放它时整段播放 **[待确认 2]**。当前书一个区段都没有时，开关可以开，提示「本书没有书签区段」，照常播放。
- 开启时进度条上所有区段常显，区段以外的部分变暗。
- 图片的区段目前只记录和显示，没有播放行为。

## 5. 恢复与识别

- 不对媒体文件做全文件哈希。识别依据只有三样：文件名、精确字节大小（来自文件元数据，不读内容）、文件头部 64 KB 的摘要（与现有封面摘要是同一机制，只读这一小段）。
- 书（文件夹）的匹配沿用「文件夹名称 + 首个文件的指纹」：首个文件是媒体时，指纹为文件名 + 大小 + 头部摘要。含媒体的书另记录各媒体文件的大小，文件夹改名或首个文件对不上时，按「文件名 + 大小」的重合度辅助判断。
- 媒体文件的大小在后台空闲时逐个读取元数据得到，不阻塞导入。
- 判定等级不变：名称与指纹都一致的自动接回；只对上一项的列出来由用户确认；都对不上的保持过期。同名文件不同大小不自动匹配。
- 散图图集里的媒体文件按「相对目录 + 文件名」定位，并要求大小一致。
- 恢复只接回已有记录、不新增书等现有规则全部适用。
- 自定义封面不参与识别。

## 6. 自定义封面

- 书架卡片的操作里加「设置封面」，对所有书可用。点开后列出这本书的全部书签缩略图，点选其一即设为封面；底部有「重置封面」，恢复默认封面。
- 没有书签时提示先添加书签，不提供其他来源。音频书签没有画面，不可选作封面。
- 自定义封面是一份独立的压缩小图：之后删除该书签、刷新、恢复、重新导入都不改变它；进入备份。
- 源文件可读时按封面尺寸从书签位置重新截取，读不到时用现有的书签缩略图。
- 设置和重置只更新这一张卡片，其余卡片不动、不闪烁。

## 7. 导入为单个作品的命名

- 只拖入 / 选择了一个根文件夹：作品名直接用它的名称，不论内容是图片、视频还是音频，也不论内容在第几层子文件夹里。
- 拖入了多个根文件夹：作品名默认用第一个根文件夹的名称，「第一个」按文件名顺序 **[待确认 3]**。
- 根文件夹下只有一个带内容的子文件夹时也一样：仍按单文件夹的书导入，但作品名用根文件夹名。识别与恢复仍以实际存放内容的文件夹为准，搜索原文件夹名仍能找到。
- 用户已手动改过书名的书，再次导入时不覆盖。
- 普通「添加文件夹」的规则不变（每个直接包含内容的文件夹是一本书，以该文件夹命名）。

## 8. 长名称的显示

- 作品名、文件夹名、文件名出现的所有位置（书架卡片、工具栏书名、音频横条、全屏界面的说明文字、书签提示、通知）限制在一到两行内，超出省略；完整名称放在提示里，文本保持可选可复制。
- 文件名采用中间省略，保留开头和结尾（结尾常带集数、序号和扩展名）；作品名采用末尾省略。
- 名称长短不得改变所在控件和邻近元素的尺寸与位置。

## 9. 窗口尺寸变化时的稳定性

### 9.1 缩放时正文不跳（修复现有问题）

现状：调节窗口宽度时，阅读区内容大幅度来回跳动。要求：

- 阅读区的宽度或高度变化时（窗口缩放、侧栏停靠或调宽、进出全屏），视窗中心处的内容保持不动：同一页的同一相对位置仍在视窗中心，误差 1 px 以内。已停在书首 / 书尾的仍停在书首 / 书尾。
- 一次连续的缩放过程中，定位用的锚点在开始时取一次并沿用到停止，不在每次变化后从已经漂移的滚动位置重新推导。
- 每帧至多重排一次；滚动条的出现和消失不引起来回重排。
- 验收：窗口宽度从 A 逐步拉到 B 再回到 A，回到同一页的同一相对位置（1 px 内）；过程中锚点页在视窗里的位置单调变化，不来回跳。连续拖动 2 秒期间无可见的闪动。

### 9.2 视频的高度封顶

- 封顶值取阅读视窗的高度，但只在窗口尺寸停止变化约 200 ms 后才重新计算，拖动过程中占位高度不变；重算时按 9.1 锚定。
- 拖动过程中窗口变矮、视频超出视窗时，画面在原占位里临时等比缩小显示，不改变占位，停下后再重排。
- 图片的排版与窗口高度无关，保持现状。

## 10. 多窗口

### 10.1 数据同步

允许同时打开多个窗口（包括同一本书），要求：

- 任一窗口对书目、书签、标签、封面、书名、所在列表的改动，其他窗口在 1 秒内反映，只更新受影响的项。
- 不同窗口先后修改同一本书的不同内容，都要保留：写入时以存储中的最新记录为基础，只改本次变更的部分，不以本窗口的旧副本整本覆盖。验收：窗口 A、B 打开同一本书，各加一个书签，两边最终都显示两个。
- 删除一本书时，其他正在读它的窗口提示记录已删除并切到下一本；记录不会被其他窗口的后续保存写回。
- 设置类偏好（音量、静音、自动播放、播放顺序、循环、只播放书签区段、语言等）跨窗口即时同步；布局类偏好（侧栏、宽度）各窗口互不影响，以最后写入的为下次启动的值。
- 当前书和阅读位置各窗口独立；同一本书的位置以最后写入为准。
- 后台磁盘任务（启动时检查全部文件夹、生成封面与缩略图、读取 .pbf）在所有窗口中同时只有一个窗口执行，其他窗口不重复读盘；持有任务的窗口关闭后由别的窗口接手。
- 「还原默认设置」、导入备份（替换）、清空等全局操作后，其他窗口自动重新载入。
- 存储结构升级时，旧窗口让出连接并提示重新载入，不能卡住新窗口。

### 10.2 新窗口播放

- 入口：壳上的「新窗口播放」按钮，快捷键 `Z` / `/`（作用于当前媒体）。`/` 在书架页和全屏界面里仍是聚焦搜索框。
- 行为：打开一个新的 MangaView 窗口，直接定位到同一本书的同一个媒体并从当前时间继续播放；原窗口的该媒体暂停。新窗口是完整的应用，没有专门的界面模式；默认开成较小的窗口。
- 新窗口不做启动时的全量文件夹检查。
- 窗口在后台、最小化时播放继续，播放顺序与循环（3.7）照常生效。
- 浏览器拦截弹窗或拦截自动出声时，给出提示，新窗口里停在该位置等待点击播放。

## 11. PotPlayer 书签（.pbf）

### 11.1 格式（据样例）

UTF-16LE 带 BOM 的文本，`[Bookmark]` 小节下每行一条：`序号=毫秒*名称*内嵌图片的十六进制`，图片段可为空，末尾有一条内容为空的行。解析时第一个 `*` 之前是时间，最后一个 `*` 之后是图片，中间是名称；只取时间和名称。格式不符的行跳过，整个文件无法解析时忽略并不报错。

### 11.2 配对

- .pbf 与同一目录下主文件名相同的媒体文件配对（`X.flac` ↔ `X.pbf`），也接受 `X.flac.pbf`；视频、音频相同。
- 找不到对应媒体文件的 .pbf 不导入；同一主文件名对应多个媒体文件时不猜测，跳过。
- .pbf 本身不是页，不出现在任何列表里。
- 散落拖入的媒体文件，只与同一批拖入的 .pbf 配对。

### 11.3 导入与合并

- 导入、刷新时列目录已能看到 .pbf，不为此多读盘；.pbf 的内容在后台空闲时串行读取，打开某本书时优先读它的。
- 导入的书签进入普通书签列表，带名称，记下来源为 .pbf。与已有书签时间相差 1 秒内的视为同一个，不重复添加。
- 合并只增不删：.pbf 里新出现的条目加入；名称变了的更新名称；PotPlayer 里删掉的条目，MangaView 中保留。
- 在 MangaView 里删除过的 .pbf 书签，之后 .pbf 更新也不会被加回来（记住已处理过的条目）。

### 11.4 跟随更新

- 不新增检查时机：随现有的文件夹刷新进行（当前书在打开和切回窗口时，其余文件夹在后台空闲时，手动刷新时全部）。
- 检查只取 .pbf 的大小和修改时间，有变化才读内容并合并（3.2 的「只探测一次」）。

### 11.5 书签缩略图

- 导入时不截图。缩略图懒生成：书签在某个列表里可见时才排队，串行、空闲时进行，生成后持久化，不再重复读取。
- 同一个视频的多个待截书签在一次打开中依次截完。
- 生成前显示占位（类型图标 + 时间 + 名称）。音频书签始终用占位样式。

## 12. 快捷键

| 按键 | 现在 | 改为 |
| --- | --- | --- |
| `Shift+W` / `Shift+↑` | 向上滚动（同不带 Shift） | 上一作品 |
| `Shift+S` / `Shift+↓` | 向下滚动（同不带 Shift） | 下一作品 |
| `A` `D` / `←` `→` 单击 | 翻屏 | 不变 |
| `A` `D` / `←` `→` 长按 | 切到上 / 下一本 | 当前媒体快退 / 快进；无当前媒体时无功能 |
| `空格` | 向下滚动，`Shift` 向上 | 播放 / 暂停当前媒体 **[待确认 1]** |
| `Q` / `;` | 无 | 音量减 |
| `E` / `'` | 无 | 音量加 |
| `Z` / `/` | 无（`/` 在书架页为搜索） | 新窗口播放当前媒体 |
| 长按 `Shift+F` / `Shift+Enter` | 无单独功能 | 添加区段书签 |

- `Shift+W/S`、`Shift+↑/↓` 按下即切换一次，按住不连续触发。不带 Shift 的 `W` `S` `↑` `↓`（按住连续滚动）、`Page Up/Down`、`Home` / `End` 不变。
- 长按快进 / 快退：按住期间约每 250 ms 跳一次，步长随按住时长递增——第 1 秒内 2 秒，第 2 秒内 5 秒，第 3 秒内 10 秒，之后 30 秒封顶；视频、音频相同。期间显示累计偏移和目标时间，松开即停。作用于当前媒体，暂停中的也可以 **[待确认 4]**。
- `F` / `Enter` 的单击（跳转书签，`Shift` 反向）、长按（添加书签）不变，按第 4 节扩展到媒体。
- 全屏界面里 `空格` / `Enter` 仍是跳转到选中项；焦点在按钮上时 `空格` 仍是点按该按钮。
- 新增功能都有鼠标入口：播放 / 暂停、音量 / 静音、添加书签、添加区段书签、只播放书签区段、播放顺序、循环、新窗口播放、全屏都在播放器壳上；「添加区段书签」在书签面板里也有；进度条可点击、拖动定位。上一 / 下一作品沿用底部操作栏。
- 书架页、输入框、对话框内，这些键照常让路。
- 同步更新 `help.mjs` 的 `KEYS` / `MORE` 键位图和两份 README 的按键表。

5. **新窗口播放**（10.2）。
6. **.pbf 导入**（11）。

同步修改 `docs/dev-guidelines.zh-CN.md`（定位扩展到媒体；媒体的读盘约定；多窗口约定）、两份 README、`sw.js` 的 `shell` 列表。测试用自动生成的临时图片、短视频和音频，以及自造的 .pbf；不使用真实文件。

需人工验收：机械硬盘上的大体积视频库（打开、定位、缩略图生成时的读盘表现）；已安装应用与普通标签页两种环境下新窗口的自动出声；后台窗口的连续播放；真实窗口拖动缩放时的观感。

## 14. 待确认

以下按建议方案实现，有异议再改：

1. **空格在纯图片的书里将不再有任何作用。** 空格只做播放 / 暂停，`Shift+空格` 的向上滚动也随之取消。备选：书里没有媒体时空格仍然滚动。
2. **开启「只播放书签区段」时没有区段的媒体**：自动切换时跳过，手动点它时整段播放。
3. **多个根文件夹时的「第一个」**：按文件名顺序取，不按拖入顺序（浏览器给出的拖入顺序不稳定）。
4. **长按 A / D 对暂停中的当前媒体也生效。**
