# 2.7 需求（过程文档，落地后删除）

在 2.6（后台播放、播放列表、画中画窗口）之上的调整。未写到之处按 docs/dev-guidelines.zh-CN.md 与 README.zh-CN.md 的现有行为。
分四组：A 书签显示；B 主窗口播放；C1 播放列表模型；C2 画中画窗口界面与书架按钮（在 C1 合并之后做）。各组只做自己的部分，另外几组的内容只作背景。

## A 书签显示

### A1 书签列表里的区段书签（书签面板、书架书签、全屏书签、「选择起点」）
- 取消「一个区段只占一格、区段书签是起点缩略图左下角的小图」。
- 起点和区段书签各占一格，大小与普通书签相同，**按位置排序**：与其他书签一起按页序、页内位置（媒体按时间）排，区段内的其他书签夹在两者之间。
- 两项各带互相呼应的区段配色标记，平时不描边；悬停或选中其中一项时两项一起以区段配色高亮；最近书签是其中一项时只高亮那一项。
- 点哪项跳到哪里（媒体跳到对应时间）；两项各有自己的删除、改名按钮；全屏书签的方向键以项为单位，区段书签是单独的一项。
- 区段暂不生效（区段书签排到起点之前）时：区段书签那一项变灰、不画标记，起点按普通书签显示。
- 最近书签、选择起点、嵌套与交叉、重命名、文件详情框（指在区段书签那一项上时指针是区段书签那一端）等现有规则保持。
- 参考：2.5.0（`git show 76db057:src/marks/tile.mjs` 等）就是两项各占一格的做法，只是当时区段书签紧挨起点；现在改为按位置排序。

### A2 进度条上的区段
- 回到更简约的样子：起点与区段书签是**一对方括号**，各在自己的时间点上；**没有顶线，不按嵌套分层**。参考 `git show 38eac7a^:src/media/media.css` 与同一提交的 src/media/marks.mjs。
- 悬停 / 聚焦一对中的任意一个：两个方括号一起高亮，两者之间的一段在轨道上以区段配色显示，提示两端的时间与名称；点击跳到该标记的时间。标记挤在一起时取离指针最近的（现有规则）。
- 「只播放书签区段」开着时区段的并集常显、之外变暗（现有规则）。
- 适用于所有画这条进度条的地方：文件栏、音频卡片、文件详情框、画中画窗口。

## B 主窗口播放

### B1 全屏跟随当前曲目
视频全屏期间当前曲目换了（播完接续、上一个 / 下一个、列表点选）：新曲目是视频时全屏画面换成它；是音频时退出全屏。

### B2 横向拖动定位只对当前曲目有效
只有当前曲目（选中的媒体）能在画面 / 字幕区上横向拖动快进快退；其他媒体上横向拖动没有效果（不定位、不算点击），竖向照常滚动。

### B3 文件栏
- 标题行的文件名**居中**（现在靠左）；右侧的按钮照旧。
- 「停止」按钮去掉（由 C1 组连同 queue.stop 一起删除，B 组不动它）。
- 释放规则：当前曲目**正在播放**（含等待播放）时文件栏显示它；**暂停**时，只有它在本书且中线在视窗内才显示它，否则文件栏回到视窗中心所在的页。曲目和播放列表不因此取消：回到它所在处文件栏又显示它，画中画窗口里照常可以继续播放。
- 「当前文件」（长按 A / D 快进快退、智能空格的对象）就是文件栏显示的文件，随上面的规则变化：暂停的曲目滚出视窗后，空格开始自动滚动。

### B4 跳到媒体书签即播放
点击视频、音频的书签（书签面板、书架书签、全屏书签）或单击 F / Enter 跳到它：把该媒体滚到视窗中央、定位到书签时间并**开始后台播放**，不再取决于「自动播放」设置。

### B5 画中画开着时的页内行为
- 显示位置跟随上一次的明确选择：画中画窗口开着且画面在画中画里时，以任何方式开始播放新的曲目（点文件本体、播放键、文件栏播放键、空格、书签跳转），画面直接进画中画，页内不显示。自动滚动播放的媒体仍在页内显示。用户点页内占位把画面收回页内之后，新的曲目在页内显示，直到再次按画中画入口。
- 页内占位不再是全黑：视频显示画面搬走那一刻的一帧（压暗），上面是「正在画中画播放，点击此处显示」；从未在页内显示过的曲目用它的缩略图（没有再用纯色）。音频卡片照现在的占位方式。
- 修复：点击页内占位只把画面收回页内，不触发点击翻屏等其他点击逻辑。

### B6 字幕字号
字幕的字号稍大一些（约 15%–20%），视频（含全屏）与音频卡片一致；最多 3 行等规则不变。画中画里字幕的位置由 C2 组调整。

## C1 播放列表模型（src/media/queue.mjs、src/core/playlist.mjs 及相关）

### C1.1 列表是有序的项
- 列表是若干项（书 + 文件）的有序序列，可以跨多本书；只在本窗口内存里（临时列表）。
- **替换**（列表换成某本书的全部可播放视频、音频，按页序）：以任何方式在阅读区开始播放一个不在列表里的文件；跨书接续或切换进入一本不在列表里的书；载入收藏列表（换成收藏的内容）。
- 开始播放一个已在列表里的文件不改列表（包括点文件本体）；切换循环范围、过滤也不改列表。
- **追加**：`addBook(book)` 把这本书可播放的视频、音频按页序追加到列表末尾，已在列表里的不重复；不播放、不改变当前曲目；返回追加的项数。
- **移除**：从列表删掉该项；移除当前曲目时切到后面最近的可接续项（保持播放 / 暂停），没有可接续项时停止播放并取消当前曲目。
- 暂停 / 继续、列表内切换、自动滚动、自动播放都不改列表（现有规则）。

### C1.2 过滤
- 类型（音频、视频，可多选，全不选即不限）加「只含书签」（文件上至少有一个书签）。偏好跨窗口同步、「还原默认设置」重置。
- 被过滤的项**留在列表里**，标记为已过滤：播完接续、上一个 / 下一个都跳过它们；仍然可以直接点它播放、移除、定位。
- 总控栏的「只播放书签区段」对接续的影响保持现有规则。

### C1.3 循环范围
- 单文件 / 列表（原「本书」，默认）/ 跨书，都循环。「列表」：播完末项回到第一项。
- 「跨书」：列表播完后，取阅读列表里末项所在书的下一本有可接续媒体的书（最后一本之后回到第一本）：这本书的项已在列表里时跳到列表里它的第一个可接续项，列表不变；否则列表替换为那本书。
- 上一个 / 下一个：在列表里按顺序移动、跳过被过滤的项。在列表两端：单文件、列表范围首尾相接；跨书范围进入上一本（它的最后一个可接续项）/ 下一本（第一个），规则同上（已在列表里就不替换）。

### C1.4 删除的功能
- 随机播放整个去掉：偏好、接口、按钮、相关逻辑与测试。
- 「停止」整个去掉：queue.stop 公开接口、文件栏标题行的「停止」按钮、画中画窗口的「停止」按钮。

### C1.5 收藏列表
- 把当前列表存成收藏：只存没有被过滤的项，按当前顺序；存的是书的 id 与文件名。收藏之后不随临时列表变化，只能改名、删除；想改内容就另存一个新的。
- 载入：用收藏的内容替换临时列表并从第一项开始播放；之后对临时列表的操作与收藏无关。找不到的书、文件（已删除、过期）跳过；一项都找不到时提示、不替换。
- 持久化，跨窗口同步，随备份导出与恢复（按开发约定里存储、多窗口、备份的做法）。
- 接口（ctx.media.queue 上或单独的模块，自定）：列出收藏（名称、项数）、保存（名称，省略时给默认名）、载入、改名、删除；变化时发事件。

### C1.6 给界面的数据
列表的每一项带：所在书、文件、类型、是否当前曲目、是否被过滤、书签情况（没有 / 有书签 / 有区段书签）。画中画窗口的界面本组只做最小改动（去掉随机、停止按钮，适配接口变化，保证测试通过），新界面由 C2 组做。

## C2 画中画窗口界面与书架按钮（C1 合并后）

### C2.1 布局
- 默认窗口为方形（约 480×480）。
- 自上而下：内容区、标题行、操作面板（播放 / 暂停 + 进度条 + 时间；按钮行）。
- 标题行：文件名，末尾三个按钮依次为「固定 / 隐藏操作面板」「播放列表」「收藏列表」。
- 按钮行：上一个、下一个、循环范围、过滤，**定位在最右**。没有随机、停止。
- 过滤是一个按钮，悬停展开二级按钮：音频、视频、只含书签；有任何过滤生效时按钮显示为按下。
- 操作面板：固定（默认）时常显；不固定时收起、内容区占满，鼠标移到窗口下部时浮在内容区上弹出，移开淡出。状态记住。
- 内容区上按住横向拖动即快进 / 快退，与主窗口同一套逻辑，提示浮层显示在画中画窗口里。
- 字幕离内容区底部留出间距，不贴边。
- 窗口变小时的收起规则相应更新，任何尺寸不溢出。

### C2.2 播放列表
- 默认收起，位于窗口最右侧：鼠标靠近右缘时浮动弹出、移开收起；点标题行的「播放列表」按钮固定打开 / 关闭（固定时停靠右侧，内容相应变窄）。状态记住。
- 每一项前面有一个书签标记位：有书签显示书签图标，有区段书签时用区段配色（蓝色），只显示一个标记；没有书签留空位。
- 被过滤的项弱化显示但仍可读、可点；非当前项的默认样式比现在更清楚（现在太弱）；当前曲目高亮。
- 列表跨多本书时，每本书的项前有一行书名小标题。
- 悬停 / 键盘选中时的文件详情框带一张缩略图（视频用与缩略图栏相同的图，音频用它的图）；只有画中画列表的详情框带图，其他地方的详情框不变。
- 每项的「定位」「移除」照旧。

### C2.3 收藏列表按钮
在「播放列表」按钮右边。打开一个菜单：第一项「保存当前列表」（就地输入名称，有默认名）；其下是已收藏的列表（名称、项数），点击即载入并播放，每个有改名（就地编辑）和删除。

### C2.4 书架
含视频、音频的书，卡片上直接有一个「添加到播放列表」按钮（不在「更多」菜单里）：点击把整本书的媒体追加到播放列表（不是替换、不播放），提示追加了多少项（都已在列表里时也提示）。浏览器不支持画中画时不显示这个按钮。
