# MangaView 2.4 需求：总控栏、播放模式、字幕、结构整理

通用约定见 docs/dev-guidelines.zh-CN.md；媒体、书签的既有规则见 docs/requirements-media.zh-CN.md，本文与其冲突处以本文为准。

## 1. 代码结构整理（先于功能进行，不改行为）

1. 源码移入 `src/` 并按领域分目录；登记类列表（sw.js 的 shell、图标 sprite、安装顺序）一项一行、按字母序；核心测试按模块拆分；统一测试入口 `tests/run.mjs`。
2. 拆分大文件：`app.mjs`（启动装配 / 导入与拖放 / 键鼠输入 / 阅读区外壳）、`shelf.mjs`（卡片 / 筛选与预设 / 恢复 / 批量）、`bookmarks.mjs`（数据操作 / 面板 / 书架书签栏 / 媒体标记）、`overview.mjs`。单个文件一个职责，纯逻辑与界面分开。
3. 拆分完成后用 prettier 一次性格式化全部源码（开发时用 `npx` 运行，不进仓库依赖），之后新代码照此格式。

## 2. 书架

### 2.1 书的操作按钮
卡片上只放 4 个按钮：**编辑标签、移到书库 / 书架、删除、更多（⋯）**。「更多」弹出菜单：重命名、设置封面、复制书名。
- 源文件夹找不到的书：「恢复」顶替「编辑标签」的位置，编辑标签进菜单。
- 已失效的书：恢复、删除、更多（重命名、设置封面）。
- 菜单用现有 `.menu-pop` 样式，键盘可达；按钮位置不随状态移动。

### 2.2 添加
浏览器没有能同时多选文件夹和文件的系统选择框（文件夹选择框一次只能选一个，文件选择框选不了文件夹），只有拖放可以一次放入多个文件夹和文件。因此：
- 「添加」按钮：点击先开系统的文件夹选择框；选完进入**添加对话框**，列出待添加项（每项可移除），可继续用「＋文件夹」「＋文件」追加，也可往对话框里拖放。
- 对话框底部两个按钮：**添加为多个作品**（默认焦点、主按钮样式）和**添加为单个作品**（次要、较小）。多个作品：文件夹按现有规则各自成书，零散文件进散图图集。单个作品：全部并成一本，命名沿用现有规则（一个根文件夹用其名，多个取文件名顺序第一个）。
- 「添加到散图图集」按钮：先开文件选择框（可多选），同样进入对话框，可追加文件夹；确认按钮只有「添加到散图图集」，文件夹里的文件（含子文件夹）全部并入图集。
- 原「导入为单个作品」按钮取消（由对话框的次要按钮取代）；拖放到窗口的三个区域保持不变，不经过对话框。
- 待添加项只记句柄，确认后才扫描，不重复读盘。

## 3. 设置封面
- 修复书签截图互相重叠。
- 去掉「点选一个书签作为封面」的说明文字。

## 4. 区段书签的显示
- 书签列表（书签面板、书架书签栏、全屏书签）里，起点和终点作为两个同样大小的项**前后紧挨**显示，不再叠放。
- 悬停或聚焦其中任何一个，两个一起高亮（与缩略图上的做法一致）。
- 终点可以点击，跳到终点位置（媒体跳到终点时间）。单独删除的规则不变。
- 区段书签换一种与普通书签明显不同的配色，全应用统一：书签列表、缩略图角标与区段范围、媒体进度条上的标记与区段。

## 5. 书签名称
- 媒体书签都有名称，存为完整字符串：
  - 应用内新增：`<文件名>-书签N`，N 为该文件内的下一个序号；
  - .pbf 导入：`<文件名>-<pbf 里的名称>`；pbf 里的原名另存，用于跟随 pbf 的改名。
  - `<文件名>` 不含路径、不含扩展名（默认，见 13.6）；音频、视频同一规则。
- 所有书签（含图片书签）可手动重命名：选中项上的铅笔按钮或 F2，就地编辑。手动改过的名称不被 pbf 覆盖。图片书签没有默认名称，仍显示「第 N 页」。
- 旧的媒体书签读入时按同样规则补上名称。
- 音频没有画面：所在的书有封面时，音频书签的缩略图、音频页的缩略图、音频播放面板都用书的封面作背景（每次显示时取当前封面，不存进书签或页记录，封面换了跟着变），名称叠在上面；没有封面时沿用现在的文字样式。
- 媒体书签的名称在书签项上可见（图片书签仍只显示缩略图）。

## 6. 单个文件的播放面板
总控栏接管列表级的控制后，每个媒体自己的面板只保留与该文件有关的内容：**播放 / 暂停、进度条（含书签标记）、时间、文件名、字幕、添加书签、添加区段书签**，视频另有全屏。音量、播放顺序、循环、只播区段、新窗口播放移到总控栏。

- **文件名**只显示最末一段，不带路径（完整路径放 tooltip）。
- **状态要一眼可辨**：
  - 当前媒体（空格和总控栏操作的对象）有强调色外框；
  - 正在播放：播放键为强调色实心、进度条为强调色、音频卡片底色提亮并显示跳动的音柱图标；
  - 未播放：进度条和按钮为灰阶，底色中性；视频暂停时画面压暗并在中央显示大的播放按钮。
- **音频卡片**做大：横向占满阅读区（两侧留边距），不设最大宽度；高度足够放文件名、进度条和 3 行字幕，字幕区始终占位（有无字幕高度不变）。书有封面时以封面作卡片背景（像内嵌的专辑图，压暗以保证文字对比度），见第 5 节。

### 6.1 字幕
- 外挂字幕：`.srt` `.vtt` `.ass` `.ssa` `.lrc`。只取文字和时间，不做特效、定位、字体样式；统一的基础样式（白字、半透明深色底）。
- 匹配：与媒体同一文件夹、文件名以媒体的主文件名开头：`片名.srt`、`片名.zh.srt`、`片名.chs.ass`。多个时可在字幕按钮的菜单里选，默认取完全同名的，其次按文件名顺序第一个；选择按媒体记住。
- **不需要另外保存句柄**：文件夹导入的书在扫描、刷新时本来就要列目录，顺带记下字幕文件名，不增加读盘；字幕文件本身只在该媒体第一次播放时读一次并缓存。散图图集没有文件夹句柄，字幕要和媒体一起选入（或之后再添加进图集），按主文件名匹配。字幕文件不算页，不出现在正文和计数里。
- 编码：先按 BOM 和 UTF-8 解码，失败再尝试 GB18030、Big5、Shift_JIS、EUC-KR。
- 显示：视频叠在画面底部（全屏、新窗口播放同样显示），音频显示在卡片的字幕区，最多 3 行。
- 字幕开关：面板上的字幕按钮，全局记住；没有字幕的媒体按钮禁用。
- 视频文件内嵌的字幕轨浏览器不开放给网页，不支持。

## 7. 总控栏

取代现在的底部操作栏（上一本 / 顶部 / 底部 / 下一本），出现方式不变（底缘呼出，移开收起，不常驻）。高度约为顶栏一行的两倍（约 84px）。只用图标和短数字，文字放 tooltip。

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  ⏮本 ⤒ ⤓ ⏭本 跨书 1.0×   │  区段   ( ▶ )   单页  │   ⏮  ⏭   顺序  循环   1.0×   🔊   ⧉  │
│  12 / 240 · 5%             │  [ 漫画 | 混合 | 影音 ] │   03 song.flac · 01:23 / 04:56      │
└──────────────────────────────────────────────────────────────────────────────────────────┘
        左：阅读                      中：通用                        右：媒体
```

| 区 | 第一行 | 第二行 |
| --- | --- | --- |
| 左（阅读） | 上一本、到顶部、到底部、下一本、跨书开关、滚动速率 | 页码与进度（现有内容） |
| 中（通用） | 只播区段开关、**大的播放 / 暂停**、单文件模式开关 | 三段切换：漫画 / 混合 / 影音 |
| 右（媒体） | 上一个媒体、下一个媒体、播放顺序（单集 / 列表 / 随机轮换）、循环、播放速率、音量、新窗口播放 | 当前媒体文件名 · 时间 |

- 主次：大播放键用强调色实心，是唯一的主按钮；模式切换次之；其余为普通图标按钮；第二行为小号灰字。
- 速率显示为数字（`1.0×`），音量显示为图标。指针悬停或键盘聚焦时在按钮上方弹出小面板（滑杆 + 常用档位；音量另有静音），移开收起；在按钮上滚轮直接调整；点击速率数字回到 1.0×，点击音量图标静音。
- 与当前模式无关的控件变暗并禁用，不隐藏、不移动：漫画模式下右区全部和中区无关项；影音模式下滚动速率；混合模式下播放顺序；书里没有媒体时右区全部。
- 窄窗口：次要按钮（到顶部、到底部、播放顺序、循环、新窗口播放）收进各区的「⋯」弹出层；约 360px 宽时仍不溢出。
- 新窗口播放的窗口里同样有总控栏。

## 8. 播放模式

三种模式，默认混合；模式、速率、只播区段、单文件模式、跨书都记住并跨窗口同步。「运行中」指大播放键处于播放状态，每个窗口独立、不记忆。空格 = 大播放键。

| 模式 | 按下播放后 | 遇到媒体 | 到书末 |
| --- | --- | --- | --- |
| 漫画 | 匀速向下滚动 | 当普通页滚过，不播放 | 停止；循环开着则回到开头继续 |
| 混合（默认） | 匀速向下滚动 | 媒体到达视窗中央时停住，播完后继续滚动 | 同上 |
| 影音 | 不滚动，播放当前媒体 | 播完按「播放顺序 × 循环」切到下一个并滚到居中（现有规则） | 现有规则 |

- **单个媒体自己的播放键**：混合、影音模式下等同于大播放键并把该媒体设为当前媒体（混合模式下播完接着往下滚）；漫画模式下只播这一个文件，播完即停。
- 运行中用户手动滚动、翻屏不会停止运行，从新位置继续；混合模式下正在播放的媒体被滚出视窗则停播并继续滚动。
- 混合模式始终按页的顺序进行，播放顺序不适用；循环 = 整本循环。
- 影音模式下书里没有媒体：大播放键禁用。

### 8.0 跨书
总控栏的「跨书」开关，默认关闭，记住并跨窗口同步。它决定播放和书签快捷键的范围是「当前这本书」还是「阅读列表」（书架当前的排序与筛选范围，与上一本 / 下一本一致）。
- 关闭：运行到书末即停（循环开着则回到本书开头）；影音模式的列表、随机只在本书的媒体里进行；F / Enter / Shift 组合等书签快捷键只在本书的书签之间跳，到头不再进入别的书。
- 开启：运行到书末自动进入下一本并继续（循环开着则到阅读列表最后一本后回到第一本）；影音模式播完本书的媒体后进入下一本有媒体的书；书签快捷键可以跳到别的书的书签（现有的跨书行为）。
- 只限制自动播放和快捷键：在书签栏、书架书签栏、全屏书签里点击任何书的书签照常跳转；上一本 / 下一本按钮和 Shift+W / S 不受影响。

### 8.1 未运行时（手动浏览）的自动播放
- 漫画模式：任何媒体都不自动播放。
- 混合、影音模式：**只有视频**在进入播放范围时自动播放（仍受设置里「自动播放」开关控制）；音频不因滚动、翻屏进入视野而播放。
- 音频只在这些情况下自动开始：点击音频书签、播放顺序 / 循环自动切到它、运行中轮到它。
- 用 A / D / ← / → 翻屏时，如果翻过去之后有视频进入播放范围，这一次翻屏直接落在「该视频居中」的位置（一次滚动到位，不先翻屏再校正）。滚轮、拖动、滚动条不做这种对齐。漫画模式不对齐。

### 8.2 只播放区段
开启后图片和媒体都只走区段：
- 滚动只经过图片区段，到区段终点直接跳到下一个区段的起点；
- 媒体只播放它的区段（现有规则）；没有区段的媒体在混合、影音模式下被跳过，除非它整个处在某个图片区段之内（此时整段播放）；
- 整本书没有任何区段时提示并不启动。

### 8.3 速率
- 滚动速率：0.25×–4×。1.0× = 每秒滚过视窗高度的 10%。滚动按帧间实际时间推进并累计小数位移，低速下不抖动。
- 播放速率：0.5×–3×，作用于所有媒体，变速不变调。

### 8.4 单文件模式
阅读区一次只显示一个文件（图片按窗口完整显示，视频、音频为各自的面板）。两侧的书签栏、缩略图栏照常可用，阅读位置、书签、当前媒体的判定不变。
- 建议做法：不另盖一层，而是让正文里每一页占满一屏并启用滚动吸附。这样翻页、位置记忆、书签跳转、播放器、缩略图联动全部沿用现有实现，退出时停在同一页。实现中若证明不可行，再退回「悬浮单层」的做法。
- 翻页：A / D / ← / →、滚轮、点击左右半屏都是上一个 / 下一个文件。
- 运行中：漫画模式按间隔自动换页，1.0× = 5 秒一张，间隔 = 5 秒 ÷ 滚动速率；混合模式图片按间隔、媒体播完再换；影音模式只在媒体之间切换。

## 9. 拖动滚动
- 鼠标按住拖动来滚动的效果做成全应用统一的一套：正文、缩略图栏、书签面板、书架书签栏、全屏缩略图 / 书签、书架列表、设置、帮助等所有可滚动区域。
- 松手后带惯性（速度按时间指数衰减），再次按下、滚轮、按键立即停止。
- 只对鼠标生效（触屏用系统自带的）；超过几像素才算拖动，拖动结束不触发点击。
- 不参与拖动的只有真正可交互的控件：按钮、滑杆、进度条、输入框、可选中的文字。播放器面板的空白处可以拖动。

## 10. 快捷键
- 空格：大播放键（任何书里都有效，取代「纯图片的书里空格无作用」）。
- 长按 A / D 快进快退、Z 和 / 新窗口播放等其余键位不变。
- F2：重命名选中的书签。

1. 结构：目录与登记点整理 → 拆分大文件（并行 3 路）→ 统一格式。

3. 功能第二批：总控栏与三种模式、自动播放规则、翻屏居中；之后单文件模式。

## 12. 需人工验收
真实窗口里的滚动顺滑度与惯性手感、低速自动滚动是否抖动、长时间混合模式运行、真实字幕文件的编码识别、全屏下的字幕。

## 13. 已确认的方案
1. **添加对话框**（2.2）：因为系统选择框不能多选文件夹，改为「先选一个，再在对话框里追加」。已接受。
2. **模式与自动播放**（8、8.1）：单个媒体的播放键在混合模式下等同总控播放；漫画模式下手动浏览不自动播放任何媒体；设置里的「自动播放」开关保留。
3. **单文件模式**用「每页一屏 + 滚动吸附」而不是悬浮层（8.4）。
4. **代码格式**：现有代码一行多条语句，是合并冲突的主要原因之一。拆分完成后用 prettier 一次性格式化全部源码（只在开发时用 `npx` 运行，不进仓库依赖），以后新代码照此格式。
5. **字幕格式**含歌词 `.lrc`（6.1）。
6. **书签名里的文件名不含扩展名**；视频的 pbf 书签也按同一规则命名（5）。
7. **封面作背景**：音频书签的缩略图、音频页的缩略图、音频播放面板都用书的封面（用户决定：重复也比没有图好）。
8. **书架卡片留在外面的三个按钮**：编辑标签、移到书库 / 书架、删除（2.1）。
