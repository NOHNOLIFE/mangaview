# MangaView 2.6 需求

过程文档：全部落地并并入 README、开发约定后删除。未说明之处按 docs/dev-guidelines.zh-CN.md。

叫法：**自动滚动**（总控栏大按钮开始的托管运行，原"运行 / 播放"）、**后台播放**（单个文件自己的播放）、**播放列表**（后台播放的列表）、**当前曲目**（后台播放正在播或暂停着的文件，即选中媒体）。播放模式仍叫漫画、混合、影音。

## 1. 顶栏与全屏界面（A 组）

- 顶栏的名称区做成一个大的块级按钮（按钮样式，点击 / Enter 打开书架页），取消工具栏里的「书架」按钮；`B` 键不变。按钮文字不可选中，完整书名在提示里。
- 全屏书签、全屏缩略图标题行：书架按钮与切换视图（网格 / 瀑布流）按钮交换位置；书架按钮做成橙色、更宽的按钮。
- 两个全屏界面里的 WASD 等操作提示文字去掉。

## 2. 书签列表与缩略图（A 组）

- **区段书签在书签列表里的样子**（书签面板、书架书签、全屏书签）：回到一个区段只占一格——区段书签是起点缩略图左下角的一张小图，起点和小图各带互相呼应的区段标记；悬停任一张两张一起高亮，点哪张跳到哪里，小图有自己的删除按钮；区段暂不生效时小图变灰、不画标记。最初的实现见 `git show bf6374d^` 的 src/ 与 README；最近书签、选择起点、嵌套与交叉、重命名等现有规则保持，最近书签是区段书签时只高亮小图。全屏书签的方向键导航以格为单位。
- **音频缩略图**（缩略图栏、全屏缩略图）：与书签列表里的音频书签同一种样子（共用绘制），没有重命名、删除按钮，书签角标靠右。缩略图栏里音频、视频缩略图的大小和比例与全屏缩略图一致，不压低高度。
- **缩略图栏不再显示视窗对应的区域**。
- **点击缩略图**：视频、音频直接定位到该文件（在阅读区居中），不按点击处的位移换算；图片仍按位移定位。不因此选中或播放。
- **文件详情框**：缩略图栏、全屏缩略图里的视频、音频，以及各书签列表（书签面板、书架书签、全屏书签、选择起点）里的视频、音频书签，悬停或键盘聚焦时立即弹出，取代原来的 tooltip：
  - 内容：文件名、类型、播放进度（上次播放位置 / 时长；正在播放时实时更新；时长未知时不读文件，只显示已知的部分）、一条进度条，条上画出该文件的全部书签与区段。
  - 书签上弹出的：同一文件的各书签内容相同，只是当前这个书签在进度条上用额外的醒目标记指出，并显示它的时间和名称。
  - 不可交互、不挡住所指的格子、夹在窗口内，显示在 `<dialog>` 之上（popover / top layer）；移开即消失。
  - 做成可复用的模块（事件委托，适用于虚拟列表），供第 6 节的播放列表使用；接口写在文件开头的注释里。

## 3. 总控栏（B 组）

- 左、右区的「⋯」弹层紧贴在「⋯」按钮正上方（与播放模式、速率的小面板同一种定位），悬停或键盘聚焦即展开，移开收起。
- 速率按钮：去掉「×」，与其他按钮同宽；速率统一按 0.1 一档（滑杆、档位、滚轮、方向键），显示一位小数即真实值。滚动速率 0.2–4.0，播放速率 0.5–3.0；已保存的旧值读入时取整到 0.1 并夹在范围内。
- 字幕按钮统一放到总控栏右区（原「新窗口播放」的位置），作用于文件栏显示的那个媒体：开 / 关字幕；多个字幕时弹出选择菜单；没有字幕或不是媒体时变灰。文件栏和音频卡片上不再有字幕按钮。

## 4. 文件栏与音频卡片（B 组）

- 文件栏改为两行：上面一行是标题（文件名不带扩展名，过长省略中间，完整路径在提示里，可选中复制），下面一行是播放 / 暂停、进度条、时间和右侧按钮，进度条因此变宽。标题行右侧留给第 6 节的按钮。音频卡片的标题同样不带扩展名。
- 右侧按钮（文件栏与音频卡片一致）：只直接显示「添加书签」「添加区段书签」，其余收进「⋯」；这种文件的按钮总数不超过 3 个时全部直接显示。即图片：书签、区段、设置为封面；视频：书签、区段、「⋯」（设置为封面、全屏）；音频：书签、区段。按钮位固定，不随文件类型跳动；「⋯」与总控栏的同款（悬停展开）。
- 时间（当前 / 总时长）处悬停或键盘聚焦时，原位换成「快退」「快进」两个按钮，宽度不变：点按一次 2 秒；长按与长按 `A` / `D` 的递增步长一致（同一份逻辑），显示同样的提示浮层。
- 音频卡片上的「添加区段书签」图标用普通颜色，不用区段蓝；文件栏同。
- 音频没有字幕文件时，选中且播放中在字幕区显示阶梯音柱动画（纯 CSS，不分析音频）；暂停时静止，系统设了减少动态效果时静止；有字幕时不显示。

## 5. 媒体画面（B 组）

- **横向拖动快进 / 快退**：在音频卡片的字幕区、视频画面上按住鼠标横向拖动即定位。
  - 方向在移动超过阈值后一次判定并锁定：明显横向才是定位，否则是原有的拖动滚动；锁定后本次不再改判，定位手势不滚动、不触发点击。
  - 拖动中显示提示浮层（偏移量与目标时间，按整秒变化，不抖动），松手才定位（不在拖动中连续读盘）；`Esc` 取消。
  - 位移与时间的换算、方向判定做成纯逻辑并有测试；拖过全宽约为时长的四分之一，限制在 30 秒到 5 分钟之间，且不超过时长。
- **未选中视频的压暗**：默认压得更黑（明显暗于现在）；视窗中心所在的那个视频、鼠标悬停或键盘聚焦的视频恢复到现在未选中的亮度；选中的不压暗。音频不变。
- **修复视频全屏**：全屏后该视频居中、铺满，其他视频、页面不出现在画面里；退出后回到进入前的阅读位置。

## 6. 后台播放、画中画与自动滚动（C 组，A、B 合并后分三步进行）

一个窗口只有一套播放状态：当前曲目、播放进度、播放列表。同时只有一个媒体在播放；开始播放另一个媒体时才停掉原来的；媒体不因离开视窗、切书而暂停或取消选中。当前曲目的画面有两个显示位置：页内，或画中画窗口（6.7）。主窗口保持精简，完整的播放列表操作在画中画窗口里。

### 6.1 后台播放

- 触发：在阅读区点文件本体（视频画面、音频卡片、它自己的播放键）、文件栏的播放键、画中画窗口里的播放列表项、书签跳转带起的播放。
- 不滚动、不跳转、不抢焦点，只播放视频、音频，不管图片；当前曲目滚出视窗、切到别的书都继续播放。没有打开画中画窗口时同样如此。
- 当前曲目即选中媒体：点击或开始播放时成为选中；选中了别的、「停止」、文件不存在时取消。
- 播完后按播放列表与循环范围接下一个，从头（开着「只播放书签区段」时按现有规则）播放；画面留在原来的显示位置（页内的不跳转，画中画的仍在画中画）。
- 实现上，当前曲目的媒体元素脱离正文的虚拟列表存活（离开视窗、切书仍持有源，所在页回到视窗时画面回到页里），并且可以在页内与画中画窗口之间搬动而不重新加载、不中断；其余媒体仍是离开视窗即卸载。

### 6.2 播放列表

- 内容：当前曲目所在书里可播放的视频、音频，按页序；只在本窗口内存里，不持久化。
- 重建的时机：在阅读区点文件本体开始播放它；切换循环范围或类型开关；用户以其他方式（文件栏播放键、空格、书签、「画中画」入口）开始播放一个不在列表里的文件。暂停 / 继续、列表内切换、自动滚动、自动播放都不重建。
- 循环范围：单文件 / 本书（默认）/ 跨书，都循环。跨书：本书的列表播完后进入阅读列表里下一本有可播放媒体的书，列表换成那本，最后一本之后回到第一本。
- 随机：不重复地播完一轮再重新洗牌；自动滚动不受它影响。
- 类型开关（音频、视频，可多选，全不选即不限）：只影响接续播放谁和列表里显示谁；用户直接点的文件照常播放。
- 范围、随机、类型是设置类偏好；它们的按钮和列表本身都在画中画窗口里（6.7），主窗口不设播放列表面板。不支持画中画的浏览器按已保存的偏好（默认本书循环、不随机、不限类型）接续。
- 「停止」：结束后台播放——停止播放、清空列表、取消选中，文件栏回到视窗中心所在的页。

### 6.3 文件栏、快捷键作用的对象

- 文件栏：有当前曲目时始终显示它（不在视窗、在别的书里也一样），否则显示视窗中心所在的页。标题行右端的按钮：「定位」（跳到当前曲目所在的页，必要时切书；显示的不是当前曲目时禁用）、「画中画」（6.7）、「停止」（没有当前曲目时禁用）。
- 书签快捷键（长按 `F` / `Shift+F`）、右键书签面板：当前曲目在本书且中线在视窗内时作用于它，否则作用于视窗中心所在的页。
- 长按 `A` / `D` 快进快退：作用于文件栏显示的媒体。
- `空格`：自动滚动运行中即停止；否则文件栏显示的是视频、音频就播放 / 暂停它；否则开始自动滚动。`Shift+空格` 固定是自动滚动的开关。
- 「上一个 / 下一个媒体」：有当前曲目时在播放列表里切换（不跳转，保持播放或暂停）；没有时在本书里定位到上一个 / 下一个媒体并居中、不播放；自动滚动运行中由自动滚动切换。
- `Z`：等同文件栏的「画中画」按钮。

### 6.4 自动滚动

- 总控栏大按钮改名「自动滚动」并换图标；只有它开始的运行才会自动滚动、跳转画面。
- 漫画模式：只滚图片，视频、音频页不进入画面——滚到图片段的末尾直接跳到下一段图片的开头（单文件模式下换页时跳过媒体页）；不碰任何媒体，后台播放照常。
- 混合模式：现有行为（滚到媒体停下播放，播完继续）。开始时选中媒体在视窗内就从它开始，否则取视窗内离中心最近的媒体，没有则直接滚动；遇到媒体之前不打断后台播放。
- 影音模式：现有行为（不滚动，逐个居中播放，跳过图片）。
- 自动滚动播放的媒体成为当前曲目（顶掉原来的，画面在页内），但不读写播放列表；它播完后由自动滚动决定下一步，不走播放列表。
- 手动操作：运行中点任何媒体的播放 / 暂停——是自动滚动正在播的那个，则暂停并停止自动滚动；是别的媒体，则停止自动滚动并后台播放它。与自动滚动无关的后台曲目（漫画模式下，或混合模式尚未遇到媒体时）暂停、播完接续都不影响自动滚动。手动滚动、翻屏不停止自动滚动（现有规则）。
- 循环：总控栏的「循环」与「跨书」合并成一个三态按钮：单文件循环 / 本书循环（默认）/ 跨书循环，没有"不循环"。本书：到书末回到书首；跨书：进入阅读列表的下一本，最后一本之后回到第一本；单文件：混合、影音模式下反复播放当前媒体，对图片按本书循环。单击 `F` / `Enter` 的跨书跳转跟随"跨书循环"。旧偏好读入：原来开着跨书的为跨书循环，其余为本书循环。
- 总控栏右区不再随播放模式禁用（后台播放与模式无关）；本书没有媒体且没有当前曲目时才禁用。

### 6.5 自动播放

- 设置里的「自动播放」保留，默认关闭。
- 开启时：未在自动滚动、混合 / 影音模式、没有任何媒体在播放（含后台），滚动停稳后播放视窗中心最近的视频。由它开始的视频离开视窗即暂停并取消选中，播完不接续，不重建播放列表；用户手动接管（点它播放 / 暂停）后按后台播放对待。
- 翻屏对齐视频仍只在开启自动播放时生效。

### 6.6 删除

- 「播放顺序」按钮与对应偏好（随机移到画中画窗口）。
- 新窗口播放：总控栏按钮、`Z` / `/` 键位、`?play=` 启动参数、相关模块与测试、文档里的说明。

### 6.7 画中画窗口

用文档画中画（Document Picture-in-Picture）开一个始终置顶的小窗口，让后台播放的内容看得见，并在里面完成全部播放列表操作。它不是另一套播放：曲目、进度、列表与主窗口是同一份，只是画面显示在哪里不同。

- **入口**：文件栏标题行的「画中画」按钮、音频卡片按钮行上的同一个按钮、`Z` 键。
  - 作用的文件是视频、音频（文件栏显示的那个；音频卡片上的作用于该卡片）：它成为当前曲目，画面搬进画中画窗口并开始播放（已在播放的不中断、进度不变）；窗口没开就打开。
  - 文件栏显示的是图片：只打开窗口（显示现有的曲目与列表，没有时给一句说明）。
  - 画面已在画中画里的曲目再按一次入口：关闭画中画窗口。
  - 浏览器不支持该接口时不显示入口，其余功能不受影响。
- **两个显示位置**：
  - 画面在画中画时，页内原位置显示「正在画中画播放」的占位；点占位把画面收回页内。
  - 在阅读区点击任何媒体即在页内播放它（它成为当前曲目，画面在页内）；画中画窗口不关闭，内容区显示占位（说明正在主窗口播放，带「在画中画显示」按钮），进度、列表、控件照常同步。自动滚动播放的媒体同理。
  - 在画中画窗口里切换曲目（列表项、上一个 / 下一个、播完接续）时画面留在画中画。
  - 搬动是同一个媒体元素在两个文档之间移动：不重新读文件、不从头播放，播放中的不出现可察觉的中断。
- **窗口内容**（自上而下）：内容区（视频画面，音频是它的图；字幕照常显示）、文件名、播放 / 暂停、进度条（书签与区段标记，可点击拖动）与时间、一行按钮（上一个、下一个、定位、循环范围、随机、音频 / 视频类型开关、停止），其下是播放列表。
  - 列表项：只显示文件名，当前曲目高亮，打开窗口时滚到它；悬停 / 聚焦显示文件详情框（窗口放不下时退回 tooltip）；点击只播放、不让主窗口跳转；每项有「定位」（主窗口跳到该文件所在的页，必要时切书）和「移除」（只对本次列表有效；移除当前曲目时接着播下一项，列表空了即结束后台播放）。列表很长时只在自己的区域里滚动。
  - 窗口里的按键：`空格` 播放 / 暂停，`←` `→` / `A` `D` 点按 2 秒、长按递增快进快退，`↑` `↓` 在列表里移动、`Enter` 播放，`Q` / `E` 音量。
  - 默认大小约 420×520；窗口变小时先压缩列表区，内容区保持画面比例，任何尺寸都不溢出。四种语言、深色样式与主窗口一致。
- **关闭**：窗口自己的关闭按钮、再按入口、主窗口刷新或关闭。关闭时画面回到页内，播放不中断（继续后台播放）。
- 实现与测试：窗口里的界面做成可以装进任意文档 / 容器的模块，无头浏览器不支持真实画中画窗口时，自动化测试把它装进普通容器或普通弹出窗口来测；真实画中画窗口列入人工验收。每个浏览器能同时开几个画中画窗口、多个 MangaView 窗口之间如何相互影响，按实测结果处理并写进 README。
