## 功能

- **打开本地文件**：用选择器或直接拖入文件夹、散图。每个直接包含图片、视频或音频的文件夹算一本书。
- **视频与音频**：浏览器能直接播放的视频和音频与图片排在同一条长条里，自带播放控件，全应用共用一套音量，可以自动播放。
- **添加为单个作品**：分卷存放的作品可以把多个文件夹合成一本书，连续阅读。
- **为长条漫画设计**：每本书是一条连续的纵向长条，图片之间不吸附、不停顿，超长条漫也能顺畅阅读。
- **大图库流畅**：只创建和解码可见页面，并限制同时读取的数量。机械硬盘上的数千张图片也能流畅浏览。
- **缩略图导航**：鼠标移到窗口右缘时弹出，也可以常驻在正文旁边；还可以全屏总览整本书。点击缩略图的任意位置，就跳到图中对应的画面，超长图内部同样准确。
- **书架与书库**：正在读的放书架，其余放书库。以纯封面显示，可在普通网格和瀑布流之间切换，鼠标悬停或用方向键选中时显示书名和操作按钮。
- **搜索、筛选与预设**：按书名、路径、标签、页数、是否有书签、含有的类型（图片 / 视频 / 音频）筛选，常用条件可存为预设。
- **标签**：可为任意书添加自定义标签，输入时联想已有标签，每个标签自动配色；点击标签或在搜索框输入 `#标签` 即可筛选。
- **书签**：长按 `F` 为当前位置添加书签，长按 `Shift+F` 用区段书签标出一段范围。书签列表显示画面缩略图，因为没人记得住文件名；缩略图上也标出哪些页有书签。
- **排序**：按文件名或修改时间正序、反序排列，或打乱顺序。可设为统一默认，也可单独设置某本书。
- **记住每本书的阅读位置**，刷新文件夹时同步新增或删除的文件。
- **文件搬家不丢记录**：找不到文件夹的书会归入「过期书籍」，封面、标签和书签都保留，之后可以重新关联。
- **备份**：所有应用数据可导出为一个文件，在另一台电脑上导入。
- **可安装、可离线**：可以安装为应用，首次加载后断网也能使用。
- **四种语言**：界面按浏览器语言自动显示中文、English、日本語或한국어。

## 开始使用

1. 用最新版桌面 **Chrome** 或 **Edge** 打开 **https://nohnolife.github.io/mangaview/** 。
2. *（可选）* 安装为应用：点击地址栏右端的安装图标，或在浏览器菜单中选择「安装 MangaView」。安装后有独立窗口，可固定到任务栏，断网也能使用。
3. 点「添加」选择文件夹，或把图片、视频、音频拖进窗口。

新版本会自动更新，不需要下载、解压或任何配置。

## 使用说明

在欢迎页、工具栏或书架页头点「添加」选择文件夹，或点「添加到散图图集」选择文件（可多选），选完进入添加对话框：列出待添加的文件夹和文件（可逐项移除），可以用「＋文件夹」「＋文件」继续追加，也可以把多个文件夹和文件一起拖进对话框；同一个文件夹或文件只列一次，点确认后才扫描。确认按钮：

- **添加为多个作品**（默认）：每个文件夹按通常的规则各自成书，零散文件加入散图图集；
- **添加为单个作品**：所选内容合成一本（见「添加为单个作品」），列表里有文件夹时可用；
- 从「添加到散图图集」进入时只有 **添加到散图图集** 一个按钮：文件夹里（含子文件夹）的文件也全部加入散图图集。

文件选择框也可以选字幕文件（.srt .vtt .ass .ssa .lrc）。

也可以直接拖到窗口任意位置，不经过对话框。只拖入文件（图片、视频或音频，没有文件夹）时，松开即加入散图图集。拖入内容含文件夹时，覆盖层下方并排有「添加为单个作品」和「添加到散图图集」两块区域；放到「添加到散图图集」上，拖入的所有图片、视频和音频（包括文件夹里的）都作为散图加入散图图集，不按文件夹建书。鼠标移到窗口顶缘（或按 **T**）唤出工具栏。

### 工具栏与总控栏

鼠标移到窗口顶缘稍作停留，工具栏会在阅读区顶部居中弹出：一行图标，鼠标悬停显示名称，窗口较窄时自动换行；书名和阅读进度显示在它下方。也可以按 **T**，或按 Tab 聚焦左上角的菜单按钮后按 Enter。

鼠标移到窗口底缘则在阅读区底部居中弹出总控栏（新窗口播放打开的窗口里也有），分左、中、右三区，每区下面一行是状态文字：

- **左区（阅读）**：「上一本」「回到书首」「滚到书尾」「下一本」、「跨书」开关、滚动速率；下面一行是当前位置（当前页 / 总页数 · 进度）。已在书首 / 书尾时对应按钮变灰；切书只在这里，工具栏里没有上 / 下一本。书架页设了筛选条件时，上一本 / 下一本只在筛选结果内切换，按钮上带一个小圆点提示。
- **中区（运行）**：「只播放书签区段」开关、大播放键、「单文件模式」开关；下面一行是播放模式：漫画、混合（默认）、影音。大播放键和 `空格` 一样开始 / 暂停运行，运行的内容见下文「播放模式」；运行停下（到书末、媒体播完不再继续等）时大播放键自动回到未运行状态。
- **右区（媒体）**：「上一个媒体」「下一个媒体」、播放顺序、循环、播放速率、音量、新窗口播放；下面一行是当前媒体的文件名和时间。上一个 / 下一个按播放顺序找（随机时「上一个」回到刚才播过的那个），滚到视窗中央；正在播放时接着播放它，否则只定位。没开循环时，列表首尾对应的按钮变灰。

速率和音量按钮在悬停或键盘聚焦时于上方弹出小面板（滑杆和常用档位，音量另有静音），在按钮上滚轮或按方向键逐档调整；点击速率按钮回到 1.0×，点击音量按钮静音 / 取消静音。滚动速率 0.25×–4×，播放速率 0.5×–3×（变速不变调，作用于所有视频、音频）。与当前模式无关的按钮变暗禁用，但不隐藏、不挪位：漫画模式下右区除「循环」外全部禁用，混合模式下播放顺序禁用，影音模式下滚动速率禁用；书里没有视频、音频时右区除「循环」外全部禁用（影音模式下大播放键也禁用）。「循环」在任何模式下都可用：漫画、混合模式下是整本循环（开着「跨书」时是整个阅读列表循环），悬停提示里写明。窗口较窄时，次要按钮收进左、右两区的「⋯」弹出层，再窄时三区分行排列。

两者在鼠标移开后淡出收起，可以在 **设置 → 工具栏** 分别关闭边缘弹出，**T** 键仍然可用。单击正文只翻屏（左半屏前一屏、右半屏后一屏），点在视频、音频上则是播放 / 暂停；触屏上点正文顶部可以开关工具栏。

**播放模式**：按下大播放键（或 `空格`）即开始运行，每个窗口各自运行、不记忆；模式、速率、只播区段、跨书都会记住并在所有窗口同步。

- **漫画**：匀速向下滚动，视频、音频当普通页滚过、不播放。
- **混合**（默认）：匀速向下滚动；视频、音频的中线到达视窗中央时停住并播放（只播区段、播放位置记忆照常），播完接着往下滚。始终按页的顺序进行，播放顺序不适用；循环即整本循环。
- **影音**：不滚动，播放当前媒体（视窗里没有媒体时取视窗之后最近的一个，滚到居中再播放）；播完按播放顺序与循环切到下一个并滚到居中。书里没有媒体时大播放键禁用。

滚动速率 1.0× 为每秒滚过视窗高度的 10%，按帧间实际时间推进，低速下也平稳。漫画、混合模式到书末停止，开着「循环」则回到书首继续。运行中暂停：滚动停在原处，或正在播放的媒体暂停；再按从原处接着。运行中用手滚动、翻屏、拖动都不会停止运行，从新的位置接着走；混合模式下正在播放的媒体被滚出视窗即停播，从新位置继续滚动；切到别的书照常运行。窗口转到后台时滚动暂停，回到前台继续（媒体照常播放）。

**跨书**（左区开关，默认关闭）决定运行和书签快捷键的范围是本书还是阅读列表（书架当前的排序与筛选范围，与上一本 / 下一本一致）。关闭时：到书末即停（或循环回本书开头），影音模式的列表、随机只在本书的媒体里进行，单击 `F` / `Enter` 只在本书的书签之间跳。开启时：到书末进入下一本，从书首接着运行（开着循环则最后一本之后回到第一本）；影音模式播完本书的媒体后进入下一本有媒体的书；书架书签常驻时单击 `F` / `Enter` 沿书架书签跨书跳。点击书签栏、书架书签栏、全屏书签里的书签，上一本 / 下一本按钮和 `Shift+W` / `Shift+S` 不受跨书开关影响。

**单文件模式**：打开中区的「单文件模式」开关后，阅读区一次只显示一个文件：图片按窗口完整显示（长条漫的长图也整张缩进窗口；关闭「铺满宽度」时小图按原尺寸显示，不放大），视频按窗口完整显示，音频卡片居中。`A` / `D` / `←` / `→`、`W` / `S` / `↑` / `↓`（按住连续翻页）、`Page Up` / `Page Down`、滚轮（一格一页，转得再快也不会一下翻过好几页）和单击左 / 右半屏都是上一个 / 下一个文件；按住拖动松手后停在最近的一页。`Home` / `End`、切书、书签、缩略图栏和全屏缩略图照常使用，点书签或缩略图跳到对应的文件。进入和退出都停在同一页，退出后回到这一页在长条里的位置（没翻页时回到进入前的位置；比窗口高的页从页首开始，其余的页居中）；阅读位置和书签在两种显示方式下通用。开关记住，并在所有窗口同步。

单文件模式下运行时不连续滚动，而是换页：漫画模式按间隔换到下一页（1.0× 为每页 5 秒，间隔 = 5 秒 ÷ 滚动速率），视频、音频页也只是按间隔翻过、不播放；混合模式图片按间隔，视频、音频页播完（只播区段照常）再换页；影音模式只在媒体之间切换（按播放顺序与循环，切到下一个媒体所在的页）。开启「只播放书签区段」时只经过图片区段内的页和应播的媒体。到书末、循环、跨书与长条相同；运行中手动翻页不打断运行，从新的一页重新计时，暂停后继续也从当前页重新计时；窗口转到后台时计时暂停。运行中进入或退出单文件模式不停止运行，按新的方式接着走。

### 书架、书库和标签

点「书架」按钮或按 **B** 打开全屏页面，有四个列表（再点一次当前列表的页签，或再按 **B**，回到阅读界面）：

- **书架**：正在读的书。新添加的文件夹、重新添加的文件夹都会放到这里。
- **书库**：其余的书，用于管理大量藏书。书架页正显示书库时，添加或拖入的书放到书库。
- **全部**：两者合在一起，方便搜索全部内容。
- **过期书籍**：只在有书找不到文件夹时出现，见下文。

「上一本 / 下一本」在当前书所在的列表（书架或书库）内切换。书架页开着时导入新书不会切换正在读的书，只提示导入了几本。

打开书架时，焦点落在正在读的书上并滚动到它的位置。鼠标悬停和方向键选中是同一个状态，选中的封面显示书名、进度和标签，以及四个按钮：编辑标签、移到书库 / 书架、删除记录、更多（⋯，弹出菜单：编辑书名、设置封面、复制书名）；源文件夹找不到的书第一个按钮换成「恢复」，编辑标签移进菜单；过期书为恢复、删除记录、更多（编辑书名、设置封面）。按钮位置不随状态变化。菜单用 `↑` `↓` 选择、回车执行，`Esc` 关闭并回到「更多」；`Enter` 打开，`Delete` 删除记录（会先确认）。有书签的书在封面左下角显示书签数。工具条最右侧的按钮在普通网格（默认，封面等大对齐）和瀑布流（按封面比例）之间切换。工具条按钮只显示图标，鼠标悬停可看说明。书名、文件夹名、文件名过长时（书架卡片、工具栏、音频卡片、全屏界面的说明文字、书签提示和通知里都一样）限制在一到两行内省略显示：文件名省略中间、保留开头和结尾，书名省略末尾；完整名称在悬停提示里，文字仍可选中复制，名称长短不影响其他元素的位置。

**搜索与筛选**：搜索框匹配书名、文件夹路径、标签，以及合并作品各卷的文件夹名；输入 `#标签` 按标签筛选，`/` 或 `Ctrl+F` 可直接跳到搜索框。有筛选时，搜索框右侧显示结果数。「筛选」按钮展开筛选面板：页数范围、「包含书签」、类型（图片 / 视频 / 音频，可多选，书中含有任一所选类型的页即符合）和标签（多个标签需同时满足，标签多时可以搜索）。面板收起时，生效的条件显示在下方；搜索框右边的「清除筛选」按钮一键清除全部条件。筛选条件会保存下来，在书架、书库和全部之间切换时保持不变；上一本 / 下一本和书架书签也只在筛选结果内进行。

**搜索预设**：把当前筛选条件存为预设，在预设菜单里点选即可应用，也可以重命名、删除或用当前条件更新；应用后再改动条件，预设按钮上会出现一个小圆点（提示文字标出「已修改」）。

**书籍排序**：排序菜单可以按添加时间（默认反序，即新添加的在前）、文件夹时间、名称排序，均可正反序（正序：从旧到新 / A→Z）；书架、书库、全部共用这个设置，上一本 / 下一本和书架书签也按这个顺序。浏览器读不到文件夹本身的修改时间，「文件夹时间」取文件夹中最新一张图片的修改时间，选用时才在后台计算（只读文件信息，不读图片），尚未算出的排在最后。

**批量操作**菜单：复制列表中的书名；「全部移入书架 / 书库」作用于当前筛选出的所有结果；「清空书架 / 书库」删除该列表中的全部书目（不受筛选影响），会先弹出确认，不会删除原图。

卡片「更多」菜单里的「编辑书名」可以改书名，只改显示的名称，不改文件夹，搜索原文件夹名仍能找到；留空即恢复原名。编辑标签时输入即在输入框下方浮出联想的已有标签（`↑` `↓` 选择，选中后也可用 `←` `→`，回车添加，`Esc` 先收起联想），输入框为空时列出最近用过和常用的标签。标签颜色按名称自动生成，同名标签在任何地方颜色都一样。

**自定义封面**：卡片「更多」菜单里的「设置封面」列出这本书所有书签的缩略图，点选一个即以该书签处的画面作封面（能读到原图时按封面比例重新截取，读不到时用书签缩略图）；书还没有书签时提示先添加书签。也可以不经书签直接设封面：右键书签面板顶部的「设置为封面」小按钮以当前画面作这本书的封面——视窗中心是图片时按封面比例截取视窗中心处，是视频时取它的当前帧，是音频时按钮不可用；完成后有简短提示。底部的「重置封面」恢复默认封面。自定义封面是单独保存的一张小图，之后删除那个书签、刷新、恢复或重新导入都不会改变它，也随备份导出；设置和重置只更新这一张卡片。识别文件夹仍只看默认封面。

### 添加为单个作品

一部作品分成多个文件夹（例如每卷一个）时，可以合成一本书连续阅读：在添加对话框里选好文件夹后点「添加为单个作品」，或拖入时把文件夹放到覆盖层下方的「添加为单个作品」区域，所选文件夹及其下各个带图片的文件夹合成一本，按路径顺序排列。

- 同一组文件夹再次导入时，更新原来那本书而不是重复添加：新增的卷追加进来，已不存在的卷移除，书签和进度保留。
- 同一个文件夹可以既是一本独立的书，又是一本或多本合并作品中的一卷，刷新或重新导入时各处同步更新。
- 书名用所选（拖入）的文件夹名称；选了多个文件夹时，用按文件名顺序排第一的那个。
- 只有一个带图片的文件夹时按普通的书导入（识别和恢复仍以这个文件夹为准），但书名用所选的根文件夹名，搜索原文件夹名仍能找到；编辑过书名的书再次导入时不覆盖。散图加入散图图集。

### 散图图集

散图图集只有一个：「添加到散图图集」选择的文件和文件夹、添加对话框里与文件夹一起选的零散文件、直接拖入的图片，以及拖到「添加到散图图集」区域的所有图片都加入它。同名的不同图片可以共存，同一个文件不会重复加入。部分图片找不到时图集照常可读，找不到的图显示为无法读取；用「定位原文件」（图集过期时用卡片上的「恢复」）选择存放这些图片的文件夹（层级不限），按相对路径和文件名逐张找回。

### 视频与音频

浏览器能直接播放的视频（mp4、m4v、webm、mkv、mov、ogv）和音频（mp3、flac、wav、ogg、oga、opus、m4a、aac、weba）与图片一样按扩展名识别，作为页排在同一条纵向长条里，排序规则（文件名、修改时间、打乱）一视同仁。只有视频或音频的文件夹也算一本书；直接拖入的视频、音频并入散图图集。

- **不支持的格式**：avi、wmv、flv、rmvb、ts、mpg、wma、ape 等浏览器播不了的媒体文件不导入，导入结果里会说明数量并列出扩展名；刷新时不再提示。扩展名受支持但实际播不了的文件（如部分 HEVC 编码的 mkv），该页显示「浏览器无法播放此文件」和「重试」，不影响其他页；这个结果连同文件的大小和修改时间记下来，文件没变就不再尝试，点「重试」或文件变化后才重新尝试。
- **布局**：视频的宽度规则与图片相同（跟随「铺满宽度」），高度按画面比例；比阅读区还高时等比缩小到正好一屏并居中，保证整个画面可见（调整窗口大小时，停下约 0.2 秒后才按新高度重排，期间画面在原位置临时缩小）。尺寸在第一次显示时读到并记下，之前按 16:9 占位，读到后不会把当前画面挤走。音频是铺满宽度、固定高度的纯色卡片：类型图标和文件名、预留的 3 行字幕区（有无字幕高度都不变）、播放控件，右侧是一张方形小图（像内嵌的专辑图）。所在的书有封面时小图是书的当前封面（自定义封面优先），封面换了已显示的卡片跟着变；没有封面时是按文件名自动配色的浅色占位图（渐变加音符，同名文件同色）。音频卡片、音频书签和缩略图里的音频用的是同一张图。
- **播放控件**：每个媒体自己的面板只放针对这个文件的控件：播放 / 暂停、可点击和拖动的进度条（画有书签标记）、当前时间 / 总时长、字幕、添加书签、添加区段书签，视频另有全屏（全屏的是画面连同控件，快捷键照常可用）；音量、播放顺序、循环、只播放书签区段、新窗口播放等对整个列表生效的控件在总控栏。控件都是图标，悬停看说明；宽度不够时，次要控件收进「更多」弹出层。文件名只显示最后一段，完整路径在悬停提示里。视频的控件浮在画面底部，鼠标移开或播放中静止几秒后淡出；音频的控件常显。单击画面或媒体自己的播放键，等同按总控栏的大播放键并把这个媒体设为当前媒体（混合模式下从它开始，播完接着往下滚；漫画模式下则只播放这一个文件，播完即停，不按播放顺序切换）；按住拖动仍是滚动（面板上除按钮、进度条、文件名以外的空白处也可以拖），在画面上转滚轮也是滚动正文，不调音量。
- **状态**：当前媒体带强调色外框。播放中的媒体播放键和进度条为强调色，音频卡片底色提亮、描边带强调色并显示跳动的音柱（系统设了减少动态效果时静止）；未播放的为灰色，暂停的视频画面变暗并在中央显示大播放键。
- **当前媒体**：快捷键和总控栏作用的对象是本窗口最近选定的媒体（按过它的播放键、开始播放或用上一个 / 下一个切到的，仍在播放或仍在视窗内时）；否则是正在播放的媒体；都没有时是中线在视窗内、离视窗中心最近的那个（暂停的也算）。一个窗口同时只播放一个媒体。
- **自动播放**（**设置 → 阅读**，默认开启）：没有运行时，混合、影音模式下滚动停下约 0.3 秒、且没有媒体在播放时，播放离视窗中心最近的视频；快速滚过不会触发。音频不会因为滚动、翻屏进入视野而播放，只在点击音频书签、播放顺序 / 循环切到它、运行中轮到它时开始；漫画模式下任何媒体都不自动播放。用 `A` / `D` / `←` / `→` 翻屏时，翻过去之后有视频进入播放范围的，这一次直接落在该视频居中的位置（滚轮、拖动、滚动条不做这种对齐；漫画模式和关闭自动播放时也不对齐）。播放中的媒体中线离开视窗即暂停；手动暂停的媒体在离开视窗再回来之前不会自动播放。打开应用或切换书籍后，要先有一次按键、点击或滚轮操作才会自动播放，避免一打开就出声。
- **音量**：全应用一套音量和静音，所有视频、音频共用，会记住，并在所有窗口同步。在总控栏的音量按钮上调节，或 `Q` / `;` 减、`E` / `'` 加，每次 5%，按住连续调，调节时短暂显示音量。
- **播放顺序与循环**：总控栏上的「播放顺序」按钮在列表（默认）、随机、单集之间轮换，图标随之变化；「循环」是开关。播放顺序只在影音模式下生效（混合模式按页序，漫画模式不播放）。影音模式下一个媒体播完后：列表按页序播放下一个视频或音频（跳过图片和播不了的），最后一个播完停下，开循环则回到第一个；随机不重复地播放，全部播过一遍后停下，开循环则重新洗牌继续；单集播完停下，开循环则重复播放。切到下一个媒体时把它滚到视窗中央、从头播放。两项设置会记住，在所有窗口同步。
- **播放位置**：每个媒体记住上次播到哪里，滚到它或手动播放时从那里继续；播到结尾（剩余不足 5 秒）则下次从头开始，按播放顺序自动切到的媒体也从头播放。位置随书目保存（在暂停、离开视窗、切书、关闭窗口时，播放中至多每 10 秒一次），也随备份导出。
- **快进 / 快退**：长按 `D` / `→` 快进、长按 `A` / `←` 快退当前媒体（暂停中的也可以），约每 0.25 秒跳一次，步长随按住时间增大（2 秒、5 秒、10 秒，之后每次 30 秒），同时显示累计偏移和目标时间，松开即停。单击仍是翻屏。
- **新窗口播放**：总控栏上的「新窗口播放」按钮，或 `Z` / `/`（作用于当前媒体），打开一个较小的新窗口，定位到同一本书的同一个媒体并从当前时间接着播放，原窗口里的它随之暂停。新窗口就是完整的应用，只是不做启动时的文件夹检查；窗口在后台或最小化时照常播放，播放顺序与循环照常生效。浏览器拦截了弹出窗口时会提示（允许本站弹出窗口后重试），原窗口照常播放；浏览器不让新窗口自动出声时，新窗口提示并停在该位置，点击即可播放。
- **字幕**：只支持外挂字幕文件：`.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc`（歌词）；视频文件内嵌的字幕轨浏览器不开放给网页，不支持。字幕与同一文件夹里、文件名以媒体主文件名接 "." 开头的媒体配对（`片名.mp4` 对 `片名.srt`、`片名.zh.srt`、`片名.chs.ass`，不区分大小写）；导入和刷新时列目录顺带记下，不打开文件，字幕文件不算页、不计数。散图图集里的媒体与同一批选入或拖入的字幕配对，之后单独加入图集的字幕也会配上已有的同名媒体。只取文字和时间，样式、特效、定位、绘图一律去掉，统一显示为半透明深色底上的白字，最多 3 行：视频叠在画面底部（全屏、新窗口播放同样显示），音频显示在卡片里。播放控件上的「字幕」按钮开 / 关字幕（会记住，在所有窗口同步）；一个媒体有多个字幕时按钮弹出菜单，可选「关闭」或其中一个，选择按媒体记住，没选过的默认用与媒体完全同名的，其次按文件名顺序第一个；没有字幕的媒体按钮变灰。字幕文件在该媒体第一次要显示字幕时才读取，本次会话内缓存，文件大小或修改时间变了才重新读取；编码先看 BOM，再按 UTF-8，不是时依次尝试 GB18030、Big5、Shift_JIS、EUC-KR（顺序随界面语言调整）。读不到时简短提示，不影响播放。字幕的文件名和选择随备份导出。
- **读盘**：导入和刷新只看文件名，不打开媒体文件。只有出现在视窗里的媒体才交给浏览器按需读取（不整体读进内存），离开视窗即释放；相邻的媒体不预先加载。
- **缩略图与封面**：缩略图栏和全屏缩略图里，视频显示真实画面：优先用该视频时间最早的书签处的画面，没有书签时取片长约 10% 处，画面接近纯黑时再试 30%、50%。画面压缩成小图保存，只为看得到的视频在空闲时逐个生成（有视频、音频在播放或正文在读图时让路），文件没变就直接使用；播放不了的视频不反复尝试，仍显示类型图标小块。音频整块显示音频卡片上的那张图（书的封面或占位图，不压暗、没有大图标），左上角是小音乐图标和时长，文件名在最下方；封面换了跟着变。书架的默认封面取按文件名顺序第一个有画面的页（图片或视频）；全书只有音频时，用作品名生成文字封面。含视频、音频的书在封面右上角显示类型角标。

### 书签

- **长按 `F` 或 `Enter`**：在屏幕中央位置添加书签。按住时会出现逐渐填满的圆环，提示正在添加；提前松开则按单击处理。
- **单击 `F` 或 `Enter`**：跳到下一个书签，到最后一个后回到第一个；加 `Shift` 则反向，跳到上一个。
- **长按 `Shift+F` 或 `Shift+Enter`**：添加区段书签（见下文）。
- **右键单击**：在鼠标处打开书签面板，顶部是「添加书签」「添加区段书签」两个图标按钮（区段按钮为区段配色，名称和长按的快捷键在悬停提示里）和一个小的「设置为封面」按钮，「添加书签」正好在鼠标下方。离当前阅读位置最近的书签与鼠标悬停同样高亮。点击书签跳过去并关闭面板，鼠标悬停不会跳转；按 **Esc** 或点击面板外关闭，位置不变。

书签附带一张画面缩略图，并且记录的是所在文件而不是滚动位置，所以重新排序后依然有效。

**视频和音频的书签**：有当前媒体（正在播放的，或离视窗中心最近的）时，长按 `F` / `Enter`、书签面板的「添加书签」或播放控件上的书签按钮，都在它的当前播放时间加书签；同一媒体 2 秒内已有书签时提示已存在。书签按页序排列，同一个视频、音频里按时间先后。单击 `F` / `Enter` 跳到媒体书签时，把该媒体滚到视窗中央并定位到书签时间，开着自动播放就从那里播放，否则停在那个画面。书签列表里，视频、音频书签带类型角标和时间点，名称叠在缩略图下沿；视频书签的缩略图是书签时刻的画面（在播放器里添加时直接截取，否则在列表里出现时才在后台逐个截取并保存），音频书签显示音频的图（书的封面或占位图，不压暗、没有大图标），不能选作封面。进度条上按时间画出这个文件的全部书签，悬停显示时间，点击跳过去。

**PotPlayer 书签**：视频、音频旁边有 PotPlayer 的书签文件（`.pbf`）时一并导入：它与同一文件夹里主文件名相同的媒体配对（`X.flac` 对 `X.pbf`，也认 `X.flac.pbf`；同一主文件名有多个媒体文件时不导入），直接拖入的媒体只与同一批拖入的 `.pbf` 配对；`.pbf` 本身不是页。导入的书签与其他书签一样进入书签列表，名称为「<文件名>-<PotPlayer 里的名称>」（PotPlayer 里没有名称的按应用内规则编号，见下文「书签名称」）。`.pbf` 在后台空闲时读取；之后随文件夹检查（打开、切回窗口、手动刷新）只比较它的大小和修改时间，有变化才重新读取并合并：新条目加入，PotPlayer 里改了名称的跟着改（在 MangaView 里手动改过名称的不被覆盖），与已有书签相差不到 1 秒的不重复添加；PotPlayer 里删掉的条目在 MangaView 中保留，在 MangaView 里删掉的也不会再被加回。导入时不截图，视频书签的画面在书签列表里出现时才生成。

**区段书签**：区段书签与它前面的一个书签配成一对，两者之间是一个书签区段。添加时取屏幕中央的位置：位置在某个区段之内，就把这个区段的终点移到这里；否则配给前面最近的一个区段（延长它的终点）或不在任何区段内的普通书签（以它为起点新建区段）；前面什么都没有时只提示、不添加。终点离起点不到半屏时按“这里已有书签”处理。区段之间不嵌套、不交叉，区段内仍可以照常添加普通书签，它们不参与配对；配对一经确定就固定在起点书签上，不随之后添加的书签改变。从 PotPlayer 导入的书签也可以在应用内补加区段书签，区段书签随备份导出。区段书签不计入书签数，也不是单击 `F` / `Enter` 的停靠点；在书签列表（书签面板、书架书签、全屏书签）里，起点和区段书签是前后紧挨、同样大小的两项，各带一个互相呼应的区段配色（蓝色）标记，平时不描边；悬停或选中任意一项时两项一起以区段配色高亮（作为离阅读位置最近的书签时只高亮那一项），点哪项跳到哪里（媒体跳到对应的时间），各有自己的删除按钮；全屏书签里用方向键移动时，区段书签也是单独的一项。删除区段书签，起点变回普通书签；删除起点，区段书签一并删除。重新排序使区段书签排到起点之前时，这个区段暂不生效（区段书签那一项变灰、不画标记），数据保留，排回来即恢复。缩略图角标、页内细标记、全屏缩略图的区段范围、进度条上的区段标记和区段、书签面板的「添加区段书签」按钮、长按添加区段书签的进度环都用同一个区段配色。视频、音频的区段书签只在同一个文件内按时间配对（取当前播放时间，离起点不到 2 秒按“这里已有书签”处理），播放控件上也有「添加区段书签」按钮；图片书签与媒体书签互不配对。进度条上起点和区段书签画成一对方括号，悬停或聚焦任意一个时高亮两者之间的区段，并提示两端的时间。

**书签名称**：视频、音频书签都有名称，叠在缩略图下沿，也出现在提示、进度条标记和全屏书签的搜索里。应用内添加的名称为「<文件名>-书签N」（文件名不含路径和扩展名，N 接着这个文件里已有的最大序号，「书签」一词按添加时的界面语言），旧版本留下的媒体书签打开时自动补上名称。图片书签没有默认名称，仍只显示缩略图（读屏为「第 N 页」）。任何书签都可以重命名：在书签面板、书架书签、全屏书签里选中（悬停或键盘选中）后按 `F2`，或点它上面的铅笔按钮，就地编辑；`Enter` 确认，`Esc` 取消，清空后确认则恢复默认（媒体书签恢复为自动名称，图片书签恢复为没有名称）。改过名的图片书签也显示名称。

**只播放书签区段**：总控栏上的开关，会记住并在所有窗口同步。开启后运行只走区段：漫画、混合模式的滚动只经过图片区段，到区段终点直接跳到下一个区段的起点；一个媒体内只播放它的书签区段：从当前时间之后的第一个区段开始，播完一段跳到下一段，最后一段播完即算这个媒体播完（单集循环时回到第一段）。混合、影音模式下没有区段的媒体被跳过，除非它整个处在某个图片区段之内（此时整段播放）；手动播放它们则整段播放。手动把进度拖到区段之外时照常播放，进入后面的区段后恢复跳转。进度条上区段常显，区段以外变暗。本书一个区段都没有时开关仍可打开，并提示「本书没有书签区段」；此时按大播放键同样提示，不开始运行。

**书架书签**：与缩略图栏的用法相同，按书架顺序集中显示书架上所有书的书签（不含书库和过期书籍；书架页有筛选时只含筛选结果，此时列表为空会提示清除或更换筛选条件）。默认不常驻：鼠标移到窗口左缘稍作停留即浮动弹出、移开后淡出收起（**设置 → 阅读** 可关闭左缘弹出）。点工具栏的「书架书签」按钮可以把它常驻在左侧，正文相应变窄；拖动列表右边缘可以调整宽度。鼠标悬停不会跳转，点击书签才跳过去，必要时自动打开那本书。列表紧凑显示，每本书一组缩略图（当前书的一组高亮，离当前阅读位置最近的书签与鼠标悬停同样高亮），不显示书名和文件名；切换书籍、跳转书签或列表弹出时，列表自动滚到当前书的书签（当前书没有书签则不动；鼠标在列表上或刚手动滚动过时不自动滚动）；顶部整行的「全屏书签」按钮打开全屏书架书签。常驻期间、总控栏的「跨书」开启时，单击 `F` / `Enter`（加 `Shift` 反向）也按这个列表前进，本书后面没有书签时跳到下一本书的第一个书签，最后回到开头；跨书关闭时只在本书内循环。当前书在书库中时仍只在本书内循环。

**专注模式**（默认开启，可在 **设置 → 阅读** 关闭）：常驻的书架书签列表和缩略图栏在鼠标没有悬停、也没有用键盘进入时隐藏内容，但仍然占位、不收起，底色与阅读区相同，减少干扰。鼠标移上去即恢复显示。显示和隐藏都是带短暂延迟的淡入淡出，鼠标快速划过时不会闪。

### 缩略图栏

鼠标移到窗口右缘稍作停留，缩略图栏会浮在正文上方弹出，移开后自动收起（**设置 → 阅读** 可关闭）。点工具栏的缩略图按钮可以把它设为常驻：常驻时它停靠在右侧，正文相应变窄，不会被遮挡（正文宽度变化、调整窗口大小或进出全屏时，视窗中央的内容保持不动，已在书首 / 书尾的仍停在书首 / 书尾）。拖动缩略图栏左边缘可以调整宽度。栏顶整行是「全屏缩略图」按钮，并显示页数。

有书签的页在缩略图右上角显示书签角标（只有一个书签图标，同一页有多个书签时带数量；这一页有区段的起点或区段书签时图标为区段配色），缩略图左侧按书签在页内的位置画出细标记：普通书签是一道短线，区段的起点和区段书签是一对方括号，鼠标指向其中一头所在的页时两头一起高亮。增删书签只更新受影响的那几页。

缩略图缓存在本次会话的内存里（上限 64 MB，不写入磁盘）：同一本书再次打开全屏缩略图，或切到别的书再回来，都不必重新读取原图，直到关闭应用。

**全屏缩略图**：点缩略图栏顶部的按钮，或按 `V` / `]` 打开整本书的全屏总览，再按一次或按 `Esc` 关闭。页面默认排成规整的网格，标题行的按钮可以切换为按页面比例排列的瀑布流（两个全屏界面共用这个选择）；右侧是加宽的滚动条，适合页数很多的书快速浏览和定位。打开时选中当前页，当前页始终带高亮描边（不缩小，与移动中的选中项区分）；`A` `D` / `←` `→` 按页序移动，`W` `S` / `↑` `↓` 在同一列上下移动，也支持 `Page Up` / `Page Down`、`Home` / `End`。点击缩略图或按 `空格` / `Enter` 跳到该页顶部并关闭。有书签的页同样带书签角标；选中（悬停或键盘）带区段起点或区段书签的页时，标出这个区段覆盖的所有页，移开即消失。

**全屏界面里的搜索**：两个全屏界面的标题行都有搜索框，输入即过滤，键盘只在结果内移动。全屏缩略图匹配文件名（合并作品含卷的文件夹名）；全屏书架书签匹配作品名和书签所在文件的文件名，作品名命中时显示该作品的全部书签。搜索框旁有「图片 / 视频 / 音频」三个开关，可多选，全不选即不限（全屏书架书签按书签所在页的类型）。打开时焦点仍在当前内容上，`/` 或 `Ctrl+F` 聚焦搜索框；在搜索框里按 `Esc` 先清空并回到列表，再按一次才关闭。没有结果时提示「没有匹配的项」并给出一键清除（连同类型开关）。搜索词和类型只在本次打开期间有效，关闭即清空，不影响上一本 / 下一本和书签跳转。

**全屏书架书签**：点书架书签列表顶部的按钮，或按 `C` / `[` 打开，全屏显示书架上所有书签，按书分组并以书名作小标题（当前书高亮），同样可以切换网格和瀑布流。打开时选中当前位置附近的书签；`A` `D` / `←` `→` 按顺序移动，`W` `S` / `↑` `↓` 移到上 / 下一行横向最近的书签；点击或 `空格` / `Enter` 跳过去，必要时自动切换书籍。在一个全屏界面里按 `V` / `]` 或 `C` / `[` 可直接切换到另一个。

两个全屏界面的标题行都有书架按钮（也可以按 `B`）：书架盖在全屏界面上层打开，全屏界面不关闭。在书架里切换书籍，全屏缩略图随之换成新书；关闭书架后回到原来的全屏界面。全屏界面只在跳转到某一页 / 书签，或主动关闭时才关闭。

### 排序

在「排序」里选「当前文件夹／书本」，只为当前这本书设置顺序；选「统一默认排序」则修改默认顺序。「跟随默认排序」会取消这本书的单独设置。每次选择「打乱顺序」都会重新洗牌，但重新打开同一本书时保持原来的乱序。按修改时间排序时，按需读取文件的修改时间；重新导入文件夹可以刷新这些时间。

### 刷新文件夹

MangaView 会在三种情况下检查文件夹里文件的增删（第一种可在「设置」中关闭）：

- 每次打开应用或刷新页面时，先检查当前这本书，其余仍有访问权限的文件夹在浏览器空闲时逐个在后台检查，不与阅读抢硬盘；同时开着多个窗口时，其余文件夹只由其中一个窗口检查一次；
- 切回应用窗口时，检查当前这本书；
- 点「刷新」按钮（工具栏「书架」按钮右侧和书架页上各有一个）时，检查全部文件夹，并可为当前书重新请求授权。

刷新不会发现新增的子文件夹，需要重新添加上一级文件夹。

### 过期书籍与文件搬家

找不到文件夹的书**永远不会**被自动删除，因为浏览器无法区分“文件夹已删除”和“移动硬盘未连接”。一本书的文件夹**全部**找不到时，它会归入「过期书籍」，封面、标签、书签和进度都保留；重新连接硬盘并刷新后会自动回到原来的列表。合并作品只有部分卷找不到时，书照常可读，缺失的卷暂时隐藏，书架卡片上有一个小提示，找回后自动恢复，也可以点卡片上的「恢复」重新关联。只有你手动删除时，记录才会被删除。

浏览器不会提供文件夹在磁盘上的完整路径，所以文件搬家后，MangaView 以**文件夹名称**加**首个文件**（按文件名排序的第一个文件，不论图片、视频还是音频；与封面画面、自定义封面无关）的指纹来识别书。指纹是文件名、精确大小和文件开头 64 KB 的摘要，不读整个文件。含视频、音频的书另在后台记下各媒体文件的大小（只读文件信息）：文件夹改名或首个文件对不上时，媒体文件的「文件名 + 大小」大多对得上的也会列出来由你确认，同名但大小不同的不会自动接回；散图图集里的视频、音频按相对路径和文件名找回时还要求大小一致。合并作品按每一卷分别匹配：

- **重新添加上一级文件夹**：文件夹名称和封面都一致的过期书或缺失的卷会自动接回原记录，不会重复添加。
- **批量恢复…**（在「过期书籍」中）：选择存放这些书的文件夹，层级不限。完全匹配的直接恢复；可能匹配的（改了名但封面相同，或同名但封面不同）列出来由你勾选；其余保持过期。散图图集里失效的图片也一并找回。恢复只接回已有的记录，**不会新增书**：文件夹里没有对应记录的内容一律忽略。恢复单本书或「定位原文件」时，所选文件夹里其他失效的书和散图也会一并接回。
- **单本「恢复」**：选择这本书的文件夹。不匹配时也可以「强制恢复」，保留标签、书签和进度；整本过期的合并作品一卷都对不上时，按所选文件夹重建，相对路径相同的卷保留书签和进度；合并作品只缺一卷时，可以把所选文件夹强制接到这一卷，其他卷不受影响；缺多卷时不猜测，提示没有找到匹配的文件夹。

### 多个窗口

可以同时打开多个 MangaView 窗口（浏览器标签页或已安装应用的窗口），包括同一本书：

- 在一个窗口里对书目、书签、标签、封面、书名、所在列表的改动，其他窗口在 1 秒内跟着更新，只更新受影响的项。不同窗口修改同一本书的不同内容（例如各加一个书签）都会保留。
- 一个窗口删除了某本书，正在读它的其他窗口会提示并切到下一本，这本书的记录不会被写回。
- 设置（设置面板里的各项、语言、默认排序、音量和静音、播放顺序、循环、只播放书签区段，以及总控栏的播放模式、滚动速率、播放速率、单文件模式、跨书）在所有窗口即时生效；缩略图栏和书架书签是否常驻、宽度、列表样式等布局各窗口互不影响，下次打开时用最后改动的那个。
- 每个窗口有自己的当前书和阅读位置；同一本书的阅读位置以最后保存的为准。视频、音频可以用「新窗口播放」放到单独的小窗口里接着播。
- 启动时检查全部文件夹、生成封面等后台读盘只由一个窗口进行，其他窗口不重复读硬盘；这个窗口关闭，或转到后台而另一个窗口在前台时，由别的窗口接手。
- 「还原默认设置」、导入备份、清除全部数据后，其他窗口自动重新载入。
- 新版本改变了存储结构时，仍开着的旧窗口会让出存储并提示重新载入，不会卡住新窗口。

### 数据与权限

图片、视频和音频只在本机读取，不会上传，也不会复制。浏览器里保存书目索引、只读文件句柄、排序设置、阅读位置、标签、书签、搜索预设，以及压缩后的小缩略图（封面、书签和视频画面，从不保存原文件）；清除站点数据会清空这些内容。

「设置 → 数据」显示存储占用，可以把全部数据导出为一个 JSON 文件，也可以导入（与现有数据合并或替换）。文件里不含图片和文件夹访问权限，在另一台电脑上导入后，书会显示在「过期书籍」里，用「批量恢复…」重新关联即可。备份格式为 2：仍可导入旧版导出的备份，但旧版应用无法导入新版备份。存储占用接近浏览器配额时，会提示删除不再需要的旧书记录。

设置面板底部的「还原默认设置」把设置项和界面布局（侧栏、宽度、默认排序等）恢复默认并重新载入页面，书籍、书签、标签、阅读进度和搜索预设都不受影响。

- 重新打开时如果浏览器收回了访问权限，用「重新授权」。
- 浏览器更新后，之前保存的文件夹访问可能整体失效（浏览器不再响应这些授权，重新选择同一个文件夹却正常）。这是浏览器的行为，网页应用拿不到磁盘路径，无法自行重新打开文件夹。MangaView 启动时会在几秒内判断出来（只问浏览器，不读硬盘，所以不会和机械硬盘读得慢混淆），并显示一条提示，说明是浏览器更新所致。点提示里的「批量恢复…」，选择存放漫画的上级文件夹，单文件夹书、合并作品的各卷、散图图集都会接回原记录，标签、书签和进度保留；选择框会开在上次恢复时的位置。硬盘只是读得慢时，图片在等待一段时间后显示「图片无法显示」，稍后会重试。
- 如果文件已经移动，用「定位原文件」。
- 不支持文件句柄的浏览器，重启后需要重新选择原文件。

## 从 v1 升级

原来位于 `/mangaview/dist/` 的旧版已被 v2 取代。v1 不保存阅读记录，因此没有数据需要迁移。

- 访问旧地址或打开已安装的 v1 应用时，会自动跳转到新版。
- 如果安装过 v1，请从地址栏安装 v2，然后在 `chrome://apps`（Edge 为 `edge://apps`）卸载旧版应用。

## 开发

没有构建步骤，也没有第三方依赖，全部是以静态文件提供的原生 ES 模块。

### 本地运行

仅用于开发调试；日常阅读请直接使用在线版。

- **Windows**：安装 [Python 3](https://www.python.org/) 后，双击仓库根目录的 `local_run.bat`。它会在 http://127.0.0.1:4173/ 启动服务并打开浏览器，关闭命令行窗口即停止。
- **任意平台**：在仓库根目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173/ 。

不支持直接双击 `index.html` 打开，因为安装、离线和文件访问都需要安全上下文（HTTPS 或 localhost）。

测试需要 Node 22.12+，统一从 `tests/run.mjs` 运行：

```sh
# 全部测试：先跑核心测试，再逐个串行跑无头 Chrome / Edge 端到端测试，失败的自动单独重跑一次，最后列出通过 / 失败清单
node tests/run.mjs "<chrome.exe 或 msedge.exe 的路径>"
# 只跑文件名包含给定名称的端到端测试（核心测试照常先跑）
node tests/run.mjs "<路径>" shelf media
# 只跑核心测试（纯逻辑，tests/core/*.test.mjs）
node tests/run.mjs
```

端到端测试（`tests/browser.mjs`、`tests/*.browser.mjs`）各自使用临时浏览器配置和自动生成的测试图片；视频、音频由 `tests/media-fixtures.mjs` 在测试页里现场生成。

以下几项自动化测试覆盖不到，需要人工验收：

- 安装后断网冷启动；
- 从真实机械硬盘（不要用 SSD 代替）导入数千张图片，并在滚动中切换书本；
- Windows 上用中键自动滚动连续读过长图；
- 已安装应用的实际窗口边框；
- 多个真实窗口在前台、后台、最小化之间切换时，后台读盘任务的交接；
- 机械硬盘上的大体积视频库（打开、定位、生成视频缩略图时的读盘表现）、真实窗口拖动缩放时视频的观感、视频的真实全屏；
- 低速自动滚动的平稳度、拖动滚动的惯性手感；
- 长时间的混合模式运行，运行中窗口转到后台再回来；
- 已安装应用与普通标签页两种环境下新窗口播放的自动出声；
- 真实字幕文件的编码识别、全屏下的字幕；
- 真实的系统选择框，以及往添加对话框里拖入真实文件夹。

### 发布

1. **同时**修改 `index.html` 的 `<title>` 和 `sw.js` 的 `cacheName` 中的版本号（有测试检查两者一致）。
2. 推送到 `main`，GitHub Pages 从仓库根目录提供服务。

已打开的窗口继续使用启动时的版本。新版在后台下载完成，并且旧窗口全部关闭后才会切换；下载失败或离线时继续使用当前版本。只要可能还有 v1 用户，就保留 `dist/`。
