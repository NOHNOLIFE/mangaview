## 功能

- **打开本地文件**：用选择器或直接拖入文件夹、散图。每个直接包含图片的文件夹算一本书。
- **为长条漫画设计**：每本书是一条连续的纵向长条，图片之间不吸附、不停顿，超长条漫也能顺畅阅读。
- **大图库流畅**：只创建和解码可见页面，并限制同时读取的数量。机械硬盘上的数千张图片也能流畅浏览。
- **缩略图导航**：鼠标移到窗口右缘时弹出，也可以常驻在正文旁边。点击缩略图的任意位置，就跳到图中对应的画面，超长图内部同样准确。
- **书架与书库**：正在读的放书架，其余放书库。两者都以纯封面瀑布流显示，鼠标悬停时显示书名和操作按钮。
- **标签**：可为任意书添加自定义标签，每个标签自动配色；点击标签或在搜索框输入 `#标签` 即可筛选。
- **书签**：长按 `G` 为当前位置添加书签。书签列表显示画面缩略图，因为没人记得住文件名。
- **排序**：按文件名或修改时间正序、反序排列，或打乱顺序。可设为统一默认，也可单独设置某本书。
- **记住每本书的阅读位置**，刷新文件夹时同步新增或删除的图片。
- **文件搬家不丢记录**：找不到文件夹的书会归入「过期书籍」，封面、标签和书签都保留，之后可以重新关联。
- **备份**：所有应用数据可导出为一个文件，在另一台电脑上导入。
- **可安装、可离线**：可以安装为应用，首次加载后断网也能使用。
- **四种语言**：界面按浏览器语言自动显示中文、English、日本語或한국어。

## 开始使用

1. 用最新版桌面 **Chrome** 或 **Edge** 打开 **https://nohnolife.github.io/mangaview/** 。
2. *（可选）* 安装为应用：点击地址栏右端的安装图标，或在浏览器菜单中选择「安装 MangaView」。安装后有独立窗口，可固定到任务栏，断网也能使用。
3. 打开文件夹，或把图片拖进窗口。

新版本会自动更新，不需要下载、解压或任何配置。

## 使用说明

在欢迎页打开文件夹或图片，也可以拖到窗口任意位置。鼠标移到窗口左缘（或停在左上角菜单按钮上、或按 **T**）唤出工具面板。

### 鼠标

| 操作 | 效果 |
| --- | --- |
| 滚轮 / 按住左键拖动 | 滚动 |
| 中键 | 浏览器原生自动滚动（需系统和浏览器支持） |
| 单击上方 15% | 回到书首；已在书首时切换上一本 |
| 单击下方 15% | 滚到书尾；已在书尾时切换下一本 |
| 单击中部左 / 右半屏 | 前一屏 / 后一屏 |
| 鼠标移到窗口左缘 | 弹出工具面板 |
| 鼠标移到窗口右缘 | 弹出缩略图栏 |
| 点击缩略图 | 跳到对应画面位置 |
| 右键 | 打开书签面板 |

### 键盘

| 按键 | 效果 |
| --- | --- |
| `空格` / `↓` | 向下滚动，按住持续滚动 |
| `Shift+空格` / `↑` | 向上滚动 |
| `F` / `→` | 后一屏 |
| `D` / `←` | 前一屏 |
| `G` / `Enter` | 单击：跳到下一个书签；长按：添加书签 |
| `Home` / `End` | 书首 / 书尾，再按一次切换上 / 下一本 |
| `Page Up` / `Page Down` | 上一本 / 下一本 |
| `Delete` | 删除当前书的记录 |
| `Ctrl+C` | 复制书架当前筛选出的书名 |
| `T` | 显示 / 隐藏工具面板 |
| `Esc` | 收起工具面板和缩略图栏 |

在应用内点工具栏的键盘按钮也能看到这份列表。

### 工具面板

工具面板从窗口左缘滑出，鼠标移开后自动收起。顶部是书名和阅读进度，下面的按钮可以排成单列或双列（**设置 → 工具栏**）。在同一处也可以关闭左缘自动弹出，左上角菜单按钮和 **T** 键仍然可用。

### 书架、书库和标签

点「书架」按钮打开全屏页面，有四个列表：

- **书架**：正在读的书。新打开的文件夹、重新打开的文件夹都会放到这里；「上一本 / 下一本」在这个列表内切换。
- **书库**：其余的书，用于管理大量藏书。
- **所有书籍**：两者合在一起，方便搜索全部内容。
- **过期书籍**：只在有书找不到文件夹时出现，见下文。

搜索框匹配书名、文件夹路径和标签。输入 `#标签` 按标签筛选，或在标签栏点选标签（多个标签需同时满足）。「全部移入书架 / 书库」作用于当前筛选出的所有结果。鼠标悬停或聚焦封面时显示书名、进度和标签，以及编辑标签、移动、复制书名、删除记录的按钮。标签颜色按名称自动生成，同名标签在任何地方颜色都一样。

### 书签

- **长按 `G` 或 `Enter`**：在屏幕中央位置添加书签。按住时会出现逐渐填满的圆环，提示正在添加；提前松开则按单击处理。
- **单击 `G` 或 `Enter`**：跳到下一个书签，到最后一个后回到第一个。
- **右键单击**：在鼠标处打开书签面板。鼠标移到哪个书签上就立即跳到那里；移出面板即关闭并停在新位置，按 **Esc** 关闭并回到原来的位置。面板打开时「添加书签」按钮正好在鼠标下方。

书签附带一张画面缩略图，并且记录的是所在图片而不是滚动位置，所以重新排序后依然有效。

### 缩略图栏

鼠标移到窗口右缘，缩略图栏会浮在正文上方弹出，移开后自动收起。点工具栏的缩略图按钮可以把它设为常驻：常驻时它停靠在右侧，正文相应变窄，不会被遮挡。拖动缩略图栏左边缘可以调整宽度。

### 排序

在「排序」里选「当前文件夹／书本」，只为当前这本书设置顺序；选「统一默认排序」则修改默认顺序。「跟随默认排序」会取消这本书的单独设置。每次选择「打乱图片」都会重新洗牌，但重新打开同一本书时保持原来的乱序。按修改时间排序时，按需读取文件的修改时间；重新导入文件夹可以刷新这些时间。

### 刷新文件夹

MangaView 会在三种情况下检查文件夹里图片的增删（第一种可在「设置」中关闭）：

- 每次打开应用或刷新页面时，检查所有仍有访问权限的文件夹；
- 切回应用窗口时，检查当前这本书；
- 点「刷新」按钮（工具栏「书架」按钮右侧和书架页上各有一个）时，检查全部文件夹，并可为当前书重新请求授权。

刷新不会发现新增的子文件夹，需要重新打开上一级文件夹。

### 过期书籍与文件搬家

找不到文件夹的书**永远不会**被自动删除，因为浏览器无法区分“文件夹已删除”和“移动硬盘未连接”。这类书会归入「过期书籍」，封面、标签、书签和进度都保留；重新连接硬盘并刷新后会自动回到原来的列表。只有你手动删除时，记录才会被删除。

浏览器不会提供文件夹在磁盘上的完整路径，所以文件搬家后，MangaView 以**文件夹名称**加**封面**（按文件名排序的第一张图）的内容摘要来识别书：

- **重新打开上一级文件夹**：文件夹名称和封面都一致的过期书会自动接回原记录，不会重复添加。
- **批量恢复…**（在「过期书籍」中）：选择存放这些书的文件夹，层级不限。完全匹配的直接恢复；可能匹配的（改了名但封面相同，或同名但封面不同）列出来由你勾选；其余保持过期。
- **单本「恢复」**：选择这本书的文件夹。不匹配时也可以「强制恢复」，保留标签、书签和进度。

### 数据与权限

图片只在本机读取，不会上传，也不会复制。浏览器里保存书目索引、只读文件句柄、排序设置、阅读位置、标签、书签，以及压缩后的小缩略图（封面和书签，从不保存原图）；清除站点数据会清空这些内容。

「设置 → 数据」可以把全部数据导出为一个 JSON 文件，也可以导入（与现有数据合并或替换）。文件里不含图片和文件夹访问权限，在另一台电脑上导入后，书会显示在「过期书籍」里，用「批量恢复…」重新关联即可。

- 重新打开时如果浏览器收回了访问权限，用「重新授权」。
- 如果文件已经移动，用「定位原文件」。
- 不支持文件句柄的浏览器，重启后需要重新选择原文件。

## 从 v1 升级

原来位于 `/mangaview/dist/` 的旧版已被 v2 取代。v1 不保存阅读记录，因此没有数据需要迁移。

- 访问旧地址或打开已安装的 v1 应用时，会自动跳转到新版。
- 如果安装过 v1，请从地址栏安装 v2，然后在 `chrome://apps`（Edge 为 `edge://apps`）卸载旧版应用。

## 开发

没有构建步骤，也没有第三方依赖，全部是以静态文件提供的原生 ES 模块。

### 本地运行

仅用于开发调试；日常阅读请直接使用在线版。

- **Windows**：安装 [Python 3](https://www.python.org/) 后，双击仓库根目录的 `local_run.bat`。它会在 http://127.0.0.1:4173/ 启动服务并打开浏览器，关闭命令行窗口即停止。
- **任意平台**：在仓库根目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173/ 。

不支持直接双击 `index.html` 打开，因为安装、离线和文件访问都需要安全上下文（HTTPS 或 localhost）。

### 项目结构

| 路径 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 页面结构、图标与样式 |
| `app.mjs` | 核心逻辑：书目、输入、排序、刷新、键盘；安装各功能模块 |
| `shelf.mjs`、`shelf.css` | 书架、书库、过期书籍、标签、恢复 |
| `match.mjs` | 过期书与文件夹的匹配、标签配色 |
| `toolbar.mjs`、`toolbar.css` | 左侧工具面板 |
| `bookmarks.mjs`、`bookmarks.css` | 书签 |
| `settings.mjs`、`backup.mjs`、`settings.css` | 设置面板、导出与导入 |
| `thumbs.mjs` | 压缩缩略图 |
| `view.mjs` | 虚拟化正文、缩略图栏、图片加载队列 |
| `model.mjs` | 排序与布局计算 |
| `sources.mjs` | 目录扫描与文件访问 |
| `store.mjs` | IndexedDB 存储 |
| `lang.mjs` | 内置翻译 |
| `sw.js` | 离线缓存 |
| `dist/` | 供 v1 用户迁移的过渡文件 |

node --test tests/core.test.mjs
# 无头 Chrome / Edge 端到端测试（每个都使用临时配置和自动生成的测试图片）：

node tests/toolbar.browser.mjs "<路径>"
node tests/bookmarks.browser.mjs "<路径>"

以下几项自动化测试覆盖不到，需要人工验收：

- 安装后断网冷启动；
- 从真实机械硬盘（不要用 SSD 代替）导入数千张图片，并在滚动中切换书本；
- Windows 上用中键自动滚动连续读过长图；
- 已安装应用的实际窗口边框。

### 发布

1. **同时**修改 `index.html` 的 `<title>` 和 `sw.js` 的 `cacheName` 中的版本号（有测试检查两者一致）。
2. 推送到 `main`，GitHub Pages 从仓库根目录提供服务。

已打开的窗口继续使用启动时的版本。新版在后台下载完成，并且旧窗口全部关闭后才会切换；下载失败或离线时继续使用当前版本。只要可能还有 v1 用户，就保留 `dist/`。
