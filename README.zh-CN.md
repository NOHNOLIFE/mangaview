## 功能

- **打开本地文件**：用选择器或直接拖入文件夹、散图。每个直接包含图片、视频或音频的文件夹算一本书。
- **视频与音频**：浏览器能直接播放的视频和音频与图片排在同一条长条里，播放控件在底部的文件栏里，翻页、切书时照常后台播放，画中画小窗口里显示画面和播放列表，全应用共用一套音量，可以开启自动播放。
- **添加为单个作品**：分卷存放的作品可以把多个文件夹合成一本书，连续阅读。
- **为长条漫画设计**：每本书是一条连续的纵向长条，图片之间不吸附、不停顿，超长条漫也能顺畅阅读。
- **大图库流畅**：只创建和解码可见页面，并限制同时读取的数量。机械硬盘上的数千张图片也能流畅浏览。
- **缩略图导航**：鼠标移到窗口右缘时弹出，也可以常驻在正文旁边；还可以全屏总览整本书。点击缩略图的任意位置，就跳到图中对应的画面，超长图内部同样准确。
- **书架与书库**：正在读的放书架，其余放书库。以纯封面显示，可在普通网格和瀑布流之间切换，鼠标悬停或用方向键选中时显示书名和操作按钮。
- **搜索、筛选与预设**：按书名、路径、标签、页数、是否有书签、含有的类型（图片 / 视频 / 音频）筛选，常用条件可存为预设。
- **标签**：可为任意书添加自定义标签，输入时联想已有标签，每个标签自动配色；点击标签或在搜索框输入 `#标签` 即可筛选。
- **书签**：长按 `F` 为当前位置添加书签，长按 `Shift+F` 用区段书签标出一段范围。书签列表显示画面缩略图，因为没人记得住文件名；缩略图上也标出哪些页有书签。
- **排序**：按文件名或修改时间正序、反序排列，或打乱顺序。可设为统一默认，也可单独设置某本书。
- **记住每本书的阅读位置**，刷新文件夹时同步新增或删除的文件。
- **文件搬家不丢记录**：找不到文件夹的书会归入「过期书籍」，封面、标签和书签都保留，之后可以重新关联。
- **备份**：所有应用数据可导出为一个文件，在另一台电脑上导入。
- **可安装、可离线**：可以安装为应用，首次加载后断网也能使用。
- **四种语言**：界面按浏览器语言自动显示中文、English、日本語或한국어。

## 开始使用

1. 用最新版桌面 **Chrome** 或 **Edge** 打开 **https://nohnolife.github.io/mangaview/** 。
2. *（可选）* 安装为应用：点击地址栏右端的安装图标，或在浏览器菜单中选择「安装 MangaView」。安装后有独立窗口，可固定到任务栏，断网也能使用。
3. 点「添加」选择文件夹，或把图片、视频、音频拖进窗口。

新版本会自动更新，不需要下载、解压或任何配置。

## 使用说明

在欢迎页、工具栏或书架页头点「添加」选择文件夹，或点「添加到散图图集」选择文件（可多选），选完进入添加对话框：列出待添加的文件夹和文件（可逐项移除），可以用「＋文件夹」「＋文件」继续追加，也可以把多个文件夹和文件一起拖进对话框；同一个文件夹或文件只列一次，点确认后才扫描。确认按钮：

- **添加为多个作品**（默认）：每个文件夹按通常的规则各自成书，零散文件加入散图图集；
- **添加为单个作品**：所选内容合成一本（见「添加为单个作品」），列表里有文件夹时可用；
- 从「添加到散图图集」进入时只有 **添加到散图图集** 一个按钮：文件夹里（含子文件夹）的文件也全部加入散图图集。

文件选择框也可以选字幕文件（.srt .vtt .ass .ssa .lrc）。

也可以直接拖到窗口任意位置，不经过对话框。只拖入文件（图片、视频或音频，没有文件夹）时，松开即加入散图图集。拖入内容含文件夹时，覆盖层下方并排有「添加为单个作品」和「添加到散图图集」两块区域；放到「添加到散图图集」上，拖入的所有图片、视频和音频（包括文件夹里的）都作为散图加入散图图集，不按文件夹建书。鼠标移到窗口顶缘（或按 **T**）唤出工具栏。

按住左键拖动在所有能滚动的地方都可用：正文、缩略图栏、书架、书签列表、全屏缩略图 / 全屏书签、设置、帮助和各个列表，横向能滚的也能横向拖。拖动过的这一下不算点击（不翻屏、不打开书或书签）；在按钮、封面、书签上按下照样可以拖。输入框、滑杆、进度条、调宽边缘和书名等可选中的文字上按下时照旧操作或选中文字，不拖动。

松手后按速度继续滑行：慢拖的手感与触屏一致，甩得越快滑得越远（最快一甩约一万两千像素）；滑行没停时同方向再甩一次，速度叠加，长列表可以越甩越快；反方向甩则按新的一甩滑行，点击、滚轮或按键即停。缩略图栏、全屏缩略图在高速拖动、滑行时先不读新的缩略图，慢下来或停下再读；还没读到的缩略图先占着固定大小的位置，拖动、滑行中读到的不会让列表跳动，停下后才按真实比例排好。

### 工具栏与总控栏

鼠标移到窗口顶缘稍作停留，工具栏会在阅读区顶部居中弹出：一行图标，鼠标悬停显示名称，窗口较窄时自动换行。工具栏下方是名称区：一个大的按钮，左侧是书架图标，一行显示「书名 · 当前页 / 总页数 · 进度」，书名过长时省略末尾（完整书名在悬停提示里）；点击它（或聚焦后按 Enter）打开书架页，工具栏里没有单独的「书架」按钮。也可以按 **T**，或按 Tab 聚焦左上角的菜单按钮后按 Enter。

鼠标移到窗口底缘则在阅读区底部居中弹出总控栏（视频全屏时也一样），三区那一行的上方是文件栏（见下文）。总控栏默认一行，分左、中、右三区：

- **左区（阅读）**：「上一本」「回到书首」「滚到书尾」「下一本」，滚动速率。已在书首 / 书尾时对应按钮变灰；切书只在这里，工具栏里没有上 / 下一本。书架页设了筛选条件时，上一本 / 下一本只在筛选结果内切换，按钮上带一个小圆点提示。
- **中区（自动滚动）**：播放模式、「只播放书签区段」开关、「自动滚动」大按钮（正中）、「单文件模式」开关、「循环」。播放模式按钮的图标是当前模式，悬停或键盘聚焦时在上方弹出漫画、混合（默认）、影音三项，点一项切换；直接点击按钮依次轮换，方向键逐个切换。「自动滚动」和 `Shift+空格` 一样开始 / 停止，内容见下文「播放模式」；运行中显示暂停图标，停下（媒体被别处暂停、没有可走的内容等）时自动回到未运行状态。「循环」是一个三态按钮：单文件循环、本书循环（默认）、跨书循环，点击依次轮换，每态一个图标，悬停提示写明当前态；没有"不循环"，自动滚动一直进行到手动停止。
- **右区（媒体）**：「上一个媒体」「下一个媒体」，播放速率、音量、字幕。有当前曲目（见「视频与音频」的「后台播放」）时，上一个 / 下一个在播放列表里切换，不滚动、不跳转，保持播放或暂停；没有时按页序找（首尾相接），滚到视窗中央，只定位、不播放；自动滚动运行中由自动滚动切过去接着播放。「字幕」作用于文件栏显示的媒体：只有一个字幕时开 / 关，有多个时弹出菜单；当前文件不是媒体或没有字幕时变灰。

速率按钮显示当前倍数（一位小数，如 1.0、1.5），与其他按钮同宽。速率和音量按钮在悬停或键盘聚焦时于正上方弹出小面板（滑杆和常用档位，音量另有静音），在按钮上滚轮或按方向键逐档调整；速率的滑杆、档位、滚轮和方向键都以 0.1 为一档。点击速率按钮回到 1.0，点击音量按钮静音 / 取消静音。滚动速率 0.2–4.0，播放速率 0.5–3.0（变速不变调，作用于所有视频、音频）；旧版本存下的速率取到 0.1 并限制在范围内。用不上的按钮变暗禁用，但不隐藏、不挪位：书里没有视频、音频且没有当前曲目时右区（字幕除外）禁用，书里没有视频、音频时影音模式下的「自动滚动」也禁用；影音模式下滚动速率禁用；漫画模式下书里没有图片时「自动滚动」禁用。禁用的「自动滚动」在悬停提示里写明原因。右区不随播放模式禁用。中区的开关在任何模式下都可用。窗口较窄时，左区只留「上一本」「下一本」，右区只留「下一个媒体」「音量」，其余按钮收进各区末尾的「⋯」弹出层（悬停、键盘聚焦或点击即在按钮正上方弹出，与速率面板的位置相同），仍是一行；再窄时分成两行：中区一行，左、右区并排一行。

**文件栏**：总控栏上方的两行，与总控栏一起弹出、收起，作用于当前文件（见「视频与音频」的「当前文件」：在播放的当前曲目——不在视窗里、在别的书里也一样；暂停的当前曲目只在本书、中线在视窗内时；否则是视窗中心所在的页）。上面一行是文件名，在行的正中：只显示最后一段、不带扩展名（过长时省略中间，完整路径在悬停提示里）。视频、音频的文件名可以点击（鼠标为手形，悬停或键盘聚焦时高亮，也可以按 `Enter`）：跳到这个文件所在的页并放到视窗中央，必要时切书，不影响播放；图片的文件名是普通文字，可以选中复制。行的右端是「画中画」（见「视频与音频」的「画中画」）。下面一行是播放 / 暂停（后台播放它，等同媒体自己的播放键）、可点击和拖动的进度条（画有书签和区段标记）和当前时间 / 总时长，图片时留空；鼠标悬停或键盘聚焦在时间上时，它原位换成「快退」「快进」两个按钮（宽度不变）：点按一次跳 2 秒，按住与长按 `A` / `D` 一样连续快退 / 快进并显示同样的提示。最右边是三个固定的按钮位，只有图标，悬停看说明：添加书签、添加区段书签直接显示，其余按钮收进第三个位的「⋯」（悬停即弹出）；某种文件的按钮不超过三个时全部直接显示。图片为添加书签、添加区段书签、设置为封面；视频为添加书签、添加区段书签和「⋯」（设置为封面、全屏）；音频为添加书签、添加区段书签（第三个位留空）。按钮位置不随文件类型跳动；添加区段书签用普通颜色。窗口变窄时不溢出：先缩短文件名，再缩短进度条。文件栏只在显示时更新。

由边缘弹出的工具栏和总控栏在鼠标移开后淡出收起。底缘的触发范围比其他三边宽一些（48px，其余 32px），更容易唤出总控栏。**T** 同时显示或收起两者（只显示了其中一个时，按 **T** 两者都显示），这样打开的不会因鼠标移动而收起，再按 **T** 或 **Esc** 收起。可以在 **设置 → 工具栏** 分别关闭顶缘、底缘弹出，**T** 键仍然可用。单击正文只翻屏（左半屏前一屏、右半屏后一屏），点在视频画面、音频卡片上则是后台播放 / 暂停它；触屏上点正文顶部可以开关工具栏。

**播放模式**：按下「自动滚动」（或 `Shift+空格`）即开始，每个窗口各自运行、不记忆；模式、速率、只播区段、循环都会记住并在所有窗口同步。只有自动滚动会滚动、跳转画面；后台播放（见「视频与音频」）与它分开，不受播放模式影响。

- **漫画**：只滚图片，匀速向下滚动；视频、音频页不进入画面：连续的图片是一段，滚到一段的末尾（末尾到达视窗底）直接跳到下一段图片的开头；比视窗还矮的一段停在它的开头，停留的时间相当于按滚动速率滚过它的高度。不播放、不暂停任何媒体，后台播放照常。书里没有图片时「自动滚动」禁用。
- **混合**（默认）：匀速向下滚动；视频、音频的中线到达视窗中央时停住并播放（只播区段、播放位置记忆照常），播完接着往下滚；紧挨着的下一页也是视频、音频时，播完直接定位到它（居中）接着播放，不再滚过去。始终按页的顺序进行。开始时当前曲目在视窗内就从它开始（在播放的接着播），否则从视窗内离中心最近的媒体开始，没有则直接滚动；遇到媒体之前不打断后台播放。
- **影音**：不滚动，从视窗里的媒体开始播放（规则同混合模式；视窗里没有媒体时取视窗之后最近的一个，滚到居中再播放）；播完按页序切到下一个并滚到居中。书里没有媒体时「自动滚动」禁用。

自动滚动播放的媒体成为当前曲目（顶掉原来的，画面在页内），但不读写播放列表，播完由自动滚动决定下一步。运行中点任何媒体的播放 / 暂停：是自动滚动正在播的那个，则暂停它并停止自动滚动；是别的媒体，则停止自动滚动并后台播放它；与自动滚动无关的后台曲目（漫画模式下，或混合模式尚未遇到媒体时）暂停、播完接续都不影响自动滚动。

**循环**（中区的三态按钮，默认本书循环）：本书循环到书末回到书首继续（影音模式下最后一个媒体播完回到第一个）；跨书循环到书末进入阅读列表（见「书架、书库和标签」，与上一本 / 下一本一致）的下一本，从书首继续，最后一本之后回到第一本（漫画模式跳过没有图片的书，影音模式跳过没有媒体的书）；单文件循环在混合、影音模式下反复播放当前的视频、音频（开着「只播放书签区段」时反复播它的区段），图片仍按本书循环。单击 `F` / `Enter` 的跨书跳转也跟随跨书循环（见「书架书签」）。上一本 / 下一本按钮、`Shift+W` / `Shift+S`、点击书签栏和书架书签里的书签不受循环影响。

滚动速率 1.0× 为每秒滚过视窗高度的 10%，按帧间实际时间推进，低速下也平稳。运行中暂停：滚动停在原处，或正在播放的媒体暂停；再按从原处接着。运行中用手滚动、翻屏、拖动都不会停止运行，从新的位置接着走；混合模式下正在播放的媒体被滚出视窗时从新位置继续滚动（它作为当前曲目照常播放，播完不再接续）；切到别的书照常运行。窗口转到后台时滚动暂停，回到前台继续（媒体照常播放）。

**单文件模式**：打开中区的「单文件模式」开关后，阅读区一次只显示一个文件：图片按窗口完整显示（长条漫的长图也整张缩进窗口；关闭「铺满宽度」时小图按原尺寸显示，不放大），视频按窗口完整显示，音频卡片居中。`A` / `D` / `←` / `→`、`W` / `S` / `↑` / `↓`（按住连续翻页）、`Page Up` / `Page Down`、滚轮（一格一页，转得再快也不会一下翻过好几页）和单击左 / 右半屏都是上一个 / 下一个文件；按住拖动松手后停在最近的一页。`Home` / `End`、切书、书签、缩略图栏和全屏缩略图照常使用，点书签或缩略图跳到对应的文件。进入和退出都停在同一页，退出后回到这一页在长条里的位置（没翻页时回到进入前的位置；比窗口高的页从页首开始，其余的页居中）；阅读位置和书签在两种显示方式下通用。开关记住，并在所有窗口同步。

单文件模式下运行时不连续滚动，而是换页：漫画模式按间隔换到下一张图片（1.0× 为每页 5 秒，间隔 = 5 秒 ÷ 滚动速率），跳过视频、音频页；混合模式图片按间隔，视频、音频页播完（只播区段照常）再换页；影音模式只在媒体之间切换（按页序，切到下一个媒体所在的页）。开启「只播放书签区段」时只经过图片区段内的页和应播的媒体。书末的循环与长条相同；运行中手动翻页不打断运行，从新的一页重新计时，暂停后继续也从当前页重新计时；窗口转到后台时计时暂停。运行中进入或退出单文件模式不停止运行，按新的方式接着走。

### 书架、书库和标签

点工具栏下方的名称区或按 **B** 打开全屏页面，有四个列表（再点一次当前列表的页签，或再按 **B**，回到阅读界面）：

- **书架**：正在读的书。新添加的文件夹、重新添加的文件夹都会放到这里。
- **书库**：其余的书，用于管理大量藏书。书架页正显示书库时，添加或拖入的书放到书库。
- **全部**：两者合在一起，方便搜索全部内容。
- **过期书籍**：只在有书找不到文件夹时出现，见下文。

**阅读列表**：书架页当前选中的列表（书架、书库或全部；选中「过期书籍」时沿用之前选中的那个）里符合筛选条件的书，按书籍排序。上一本 / 下一本、跨书循环、书签快捷键跨书和书架书签都按它；正在读的书不在其中时，从它按排序应在的位置走到最近的一本。选中哪个列表各窗口独立，下次打开时用最后选中的那个。书架页开着时导入新书不会切换正在读的书，只提示导入了几本。

删除正在读的书（`Delete`、卡片上的删除按钮、清空书架 / 书库、删除全部过期书，或在别的窗口删除）后，切到阅读列表里原来排在它后面的一本，没有则前面的一本；列表空了回到书架页（一本书都没有时是欢迎页）。

打开书架时，焦点落在正在读的书上并滚动到它的位置。鼠标悬停和方向键选中是同一个状态，选中的封面显示书名、进度和标签，以及四个按钮：编辑标签、移到书库 / 书架、删除记录、更多（⋯，弹出菜单：编辑书名、设置封面、复制书名）；源文件夹找不到的书第一个按钮换成「恢复」，编辑标签移进菜单；过期书为恢复、删除记录、更多（编辑书名、设置封面）。含视频、音频的书在这一行按钮下方另有「添加到播放列表」：把整本书的视频、音频追加到播放列表末尾（不替换、不播放，已在列表里的不重复），提示追加了多少个文件（都已在列表里时也提示）；浏览器不支持画中画时没有这个按钮。按钮位置不随状态变化。菜单用 `↑` `↓` 选择、回车执行，`Esc` 关闭并回到「更多」；`Enter` 打开，`Delete` 删除记录（会先确认）。有书签的书在封面左下角显示书签数。工具条最右侧的按钮在普通网格（默认，封面等大对齐）和瀑布流（按封面比例）之间切换。工具条按钮只显示图标，鼠标悬停可看说明。书名、文件夹名、文件名过长时（书架卡片、工具栏、音频卡片、全屏界面的说明文字、书签提示和通知里都一样）限制在一到两行内省略显示：文件名省略中间、保留开头和结尾，书名省略末尾；完整名称在悬停提示里，文字仍可选中复制（顶栏名称区这类按钮上的除外），名称长短不影响其他元素的位置。

**搜索与筛选**：搜索框匹配书名、文件夹路径、标签，以及合并作品各卷的文件夹名；输入 `#标签` 按标签筛选，`/` 或 `Ctrl+F` 可直接跳到搜索框。有筛选时，搜索框右侧显示结果数。「筛选」按钮展开筛选面板：页数范围、「包含书签」、类型（图片 / 视频 / 音频，可多选，书中含有任一所选类型的页即符合）和标签（多个标签需同时满足，标签多时可以搜索）。面板收起时，生效的条件显示在下方；搜索框右边的「清除筛选」按钮一键清除全部条件。筛选条件会保存下来，在书架、书库和全部之间切换时保持不变；上一本 / 下一本和书架书签也只在筛选结果内进行。

**搜索预设**：把当前筛选条件存为预设，在预设菜单里点选即可应用，也可以重命名、删除或用当前条件更新；应用后再改动条件，预设按钮上会出现一个小圆点（提示文字标出「已修改」）。

**书籍排序**：排序菜单可以按添加时间（默认反序，即新添加的在前）、文件夹时间、名称排序，均可正反序（正序：从旧到新 / A→Z）；书架、书库、全部共用这个设置，上一本 / 下一本和书架书签也按这个顺序。浏览器读不到文件夹本身的修改时间，「文件夹时间」取文件夹中最新一张图片的修改时间，选用时才在后台计算（只读文件信息，不读图片），尚未算出的排在最后。

**批量操作**菜单：复制列表中的书名；「全部移入书架 / 书库」作用于当前筛选出的所有结果；「清空书架 / 书库」删除该列表中的全部书目（不受筛选影响），会先弹出确认，不会删除原图。

卡片「更多」菜单里的「编辑书名」可以改书名，只改显示的名称，不改文件夹，搜索原文件夹名仍能找到；留空即恢复原名。编辑标签时输入即在输入框下方浮出联想的已有标签（`↑` `↓` 选择，选中后也可用 `←` `→`，回车添加，`Esc` 先收起联想），输入框为空时列出最近用过和常用的标签。标签颜色按名称自动生成，同名标签在任何地方颜色都一样。

**自定义封面**：卡片「更多」菜单里的「设置封面」列出这本书所有书签的缩略图，点选一个即以该书签处的画面作封面（能读到原图时按封面比例重新截取，读不到时用书签缩略图）；书还没有书签时提示先添加书签。也可以不经书签直接设封面：右键书签面板顶部的「设置为封面」小按钮或文件栏上的「设置为封面」以当前画面作这本书的封面——视窗中心是图片时按封面比例截取视窗中心处，是视频时取它的当前帧，是音频时按钮不可用；完成后有简短提示。底部的「重置封面」恢复默认封面。自定义封面是单独保存的一张小图，之后删除那个书签、刷新、恢复或重新导入都不会改变它，也随备份导出；设置和重置只更新这一张卡片。识别文件夹仍只看默认封面。

### 添加为单个作品

一部作品分成多个文件夹（例如每卷一个）时，可以合成一本书连续阅读：在添加对话框里选好文件夹后点「添加为单个作品」，或拖入时把文件夹放到覆盖层下方的「添加为单个作品」区域，所选文件夹及其下各个带图片的文件夹合成一本，按路径顺序排列。

- 同一组文件夹再次导入时，更新原来那本书而不是重复添加：新增的卷追加进来，已不存在的卷移除，书签和进度保留。
- 同一个文件夹可以既是一本独立的书，又是一本或多本合并作品中的一卷，刷新或重新导入时各处同步更新。
- 书名用所选（拖入）的文件夹名称；选了多个文件夹时，用按文件名顺序排第一的那个。
- 只有一个带图片的文件夹时按普通的书导入（识别和恢复仍以这个文件夹为准），但书名用所选的根文件夹名，搜索原文件夹名仍能找到；编辑过书名的书再次导入时不覆盖。散图加入散图图集。

### 散图图集

散图图集只有一个：「添加到散图图集」选择的文件和文件夹、添加对话框里与文件夹一起选的零散文件、直接拖入的图片，以及拖到「添加到散图图集」区域的所有图片都加入它。同名的不同图片可以共存，同一个文件不会重复加入。部分图片找不到时图集照常可读，找不到的图显示为无法读取；用「定位原文件」（图集过期时用卡片上的「恢复」）选择存放这些图片的文件夹（层级不限），按相对路径和文件名逐张找回。

### 视频与音频

浏览器能直接播放的视频（mp4、m4v、webm、mkv、mov、ogv）和音频（mp3、flac、wav、ogg、oga、opus、m4a、aac、weba）与图片一样按扩展名识别，作为页排在同一条纵向长条里，排序规则（文件名、修改时间、打乱）一视同仁。只有视频或音频的文件夹也算一本书；直接拖入的视频、音频并入散图图集。

- **不支持的格式**：avi、wmv、flv、rmvb、ts、mpg、wma、ape 等浏览器播不了的媒体文件不导入，导入结果里会说明数量并列出扩展名；刷新时不再提示。扩展名受支持但实际播不了的文件（如部分 HEVC 编码的 mkv），该页显示「浏览器无法播放此文件」和「重试」，不影响其他页；这个结果连同文件的大小和修改时间记下来，文件没变就不再尝试，点「重试」或文件变化后才重新尝试。
- **布局**：视频的宽度规则与图片相同（跟随「铺满宽度」），高度按画面比例；比阅读区还高时等比缩小到正好一屏并居中，保证整个画面可见（调整窗口大小时，停下约 0.2 秒后才按新高度重排，期间画面在原位置临时缩小）。尺寸在第一次显示时读到并记下，之前按 16:9 占位，读到后不会把当前画面挤走。视频画面内没有控件，只有字幕和未选中时中央的大播放键。音频是铺满宽度、固定高度的纯色卡片：类型图标和文件名、预留的 3 行字幕区（有无字幕高度都不变）、播放控件，右侧是一张方形小图（像内嵌的专辑图）。所在的书有封面时小图是书的当前封面（自定义封面优先），封面换了已显示的卡片跟着变；没有封面时是按文件名自动配色的浅色占位图（渐变加音符，同名文件同色）。音频卡片、音频书签和缩略图里的音频用的是同一张图。
- **播放控件**：针对单个文件的控件在底部的文件栏里（见「工具栏与总控栏」）：播放 / 暂停、进度条、时间（悬停换成快退 / 快进）、添加书签、添加区段书签，视频另有设置为封面和全屏。音频卡片的标题同样不带扩展名；卡片自己也常显一行控件：播放 / 暂停、可点击和拖动的进度条（画有书签标记）、当前时间 / 总时长（悬停同样换成快退 / 快进）、添加书签、添加区段书签、画中画，与文件栏同时存在、状态同步；卡片宽度不够时，次要控件收进「更多」弹出层。字幕、音量、循环、只播放书签区段等在总控栏。控件都是图标，悬停看说明。单击画面、大播放键或媒体自己的播放键是后台播放 / 暂停它（见下文「后台播放」），不启动自动滚动、不滚动画面，与播放模式无关；按住竖向拖动仍是滚动（卡片上除按钮、进度条、文件名以外的空白处也可以拖），在画面上转滚轮也是滚动正文，不调音量。
- **全屏**：文件栏「⋯」里的全屏按钮让这个视频铺满整个屏幕（并成为当前曲目），画面按屏幕完整显示、居中（竖的视频也一样，旁边不露出其他页），其余照常：鼠标移到底缘弹出文件栏和总控栏，快捷键、字幕照常可用；全屏期间滚轮、竖向拖动都不滚动正文，横向拖动照常快进 / 快退。全屏期间当前曲目换了（播完接续、上一个 / 下一个、在画中画的列表里点选）：新曲目是视频时全屏画面换成它（别的书里的也一样，主窗口不切书），是音频时退出全屏。再按一次或按 `Esc` 退出，回到进入前的阅读位置。
- **当前曲目**：每个窗口最多一个当前曲目（即选中的媒体），一个窗口同时只播放一个媒体。单击画面或播放键、开始播放（包括播放列表接续、自动滚动中轮到它、自动播放）、用上一个 / 下一个媒体切到、跳到它的书签时成为当前曲目；暂停后仍是；滚出视窗、切换书籍都不取消，选中了别的媒体、从播放列表移除它而列表里没有可接续的项（见「播放列表」）或文件读不到时才取消（自动播放开始、还没被手动操作过的视频例外，见「自动播放」）。图片没有这种状态。视频、音频外观统一：未选中时压暗（音频卡片连同右侧小图），中央显示大播放键；选中时不压暗、不描边。未选中的视频在视窗中心、鼠标悬停或键盘聚焦时是普通的压暗程度，其余的压得更暗，便于看出当前文件。播放与暂停只在播放键图标、进度条颜色（播放中为强调色）和音频的跳动音柱（系统设了减少动态效果时静止）上有区别。没有字幕（或字幕关着）的音频选中时，字幕区显示一组阶梯状的音柱：播放中跳动，暂停或系统设了减少动态效果时静止；有字幕时显示字幕。浏览器播不了的媒体不显示大播放键。
- **当前文件**：即文件栏显示的文件。当前曲目正在播放（含等待播放）时是它（不在视窗里、在别的书里也一样）；暂停时只在它就在本书、中线在视窗内时是它，否则回到视窗中心所在的页（图片、视频或音频）。曲目和播放列表不因此取消：回到它所在处文件栏又显示它，画中画窗口里照常可以继续播放（播放起来文件栏随即显示它）。文件栏、长按 `A` / `D` 快进快退、`空格` 都作用于它（文件栏显示的是图片时，快进快退无效果）：暂停的曲目滚出视窗后，`空格` 开始自动滚动（视窗中心是视频、音频时播放它）。书签快捷键（长按 `F` / `Shift+F`）和右键书签面板只在当前曲目就在本书、中线在视窗内时作用于它，否则作用于视窗中心所在的页。
- **后台播放**：单击画面、卡片或播放键，文件栏的播放键，`空格`，以及书签跳转带起的播放，都只是播放这个文件：不滚动、不跳转、不抢焦点。当前曲目滚出视窗、切到别的书都继续播放（滚开时文件在后台保持打开，回到它所在的页时画面无缝回到页里，不重新读取、不中断）；开始播放另一个媒体时才停掉原来的。播完按播放列表接着播下一个，从头（开着「只播放书签区段」时按区段）播放，主窗口不滚动、不跳转。「只播放书签区段」、播放位置记忆、字幕、进度条上的书签标记、音量和播放速率对它照常生效，包括它不在视窗里、在别的书里的时候；窗口转到后台时照常接续。点文件栏的文件名跳到它所在的页（必要时切书）。
- **播放列表**：若干个视频、音频文件的有序列表，可以跨多本书；只在本窗口内存里，不保存（要留下来就存成收藏列表，见下）。以任何方式（点文件本体、播放键、文件栏的播放键、`空格`、书签）开始播放一个不在列表里的文件时，列表换成它所在书的全部可播放视频、音频（按页序）；开始播放已在列表里的文件不改列表；暂停 / 继续、列表内切换、切换循环范围或过滤、自动滚动、自动播放都不改列表。
  - 过滤：音频、视频（可多选，全不选即不限）和「只含书签」（文件上至少有一个书签）。被过滤的项仍留在列表里，只是播完接续、上一个 / 下一个跳过它们；直接点它照常播放，也可以移除、定位。
  - 循环范围有单文件、列表（默认）、跨书三种，都循环：列表范围播完最后一项回到第一项；跨书在列表播完后进入阅读列表里末项所在书的下一本有可播放媒体的书（最后一本之后回到第一本），那本书的项已在列表里时跳到它在列表里的第一项、列表不变，否则列表换成那本书。上一个 / 下一个在列表两端：单文件、列表范围首尾相接；跨书范围进入上一本（它的最后一项）/ 下一本（第一项），规则同上。
  - 移除一项只从本次列表里删掉它；移除的是当前曲目时接着播它后面最近的可接续项，没有可接续的项时停止播放、取消当前曲目，文件栏回到视窗中心所在的页。
  - 循环范围和过滤会记住并在所有窗口同步（默认列表循环、不过滤），「还原默认设置」恢复默认；它们的按钮和列表本身在画中画窗口里（见下），主窗口不设播放列表面板，不支持画中画的浏览器按已保存的设置接续。
  - **收藏列表**：可以把当前列表存成收藏（只存没有被过滤的项，按当前顺序，默认以第一项所在的书命名）。收藏之后不随临时列表变化，只能改名、删除，想改内容就另存一个新的。载入收藏即用它的内容替换当前列表并从第一项开始播放；已删除、过期的书和找不到的文件跳过，一项都找不到时提示、列表不变。收藏列表保存在本机、在所有窗口同步，随备份导出（导入时与本机的合并），不受「还原默认设置」影响。
- **画中画**：一个始终置顶的小窗口（浏览器的文档画中画，Chrome / Edge 116 起），显示后台播放的画面，并在里面完成全部播放列表操作。它不是另一套播放：曲目、进度、列表与主窗口是同一份，只是画面显示在哪里不同。
  - 入口：文件栏标题行的「画中画」、音频卡片按钮行上的同一个按钮、`Z` 键。作用于文件栏显示的文件（音频卡片上的作用于该卡片）：视频、音频成为当前曲目，画面搬进画中画窗口并开始播放（已在播放的不中断、进度不变），窗口没开就打开；文件栏显示的是图片时只打开窗口（显示现有的曲目与列表，没有时给一句说明）。画面已在画中画里的曲目再按一次入口即关闭窗口（打开着的窗口按钮显示为按下）。浏览器不支持时没有这些入口，其余功能不受影响。
  - 两个显示位置，跟随上一次的明确选择：按画中画入口（或窗口里的「在画中画显示」）选的是画中画，点页内占位选的是页内。画面在画中画时，以任何方式开始播放新的曲目（点文件本体、播放键、文件栏的播放键、`空格`、书签跳转），画面直接进画中画，页内不显示；点页内占位把画面收回页内之后，新的曲目在页内播放，直到再次按画中画入口。自动滚动播放的媒体总在页内显示（不改变上面的选择），视频全屏时也在页内。画面在页内时画中画窗口不关闭，内容区显示占位（说明正在主窗口播放，带「在画中画显示」按钮），进度、列表、按钮照常同步。在画中画窗口里切换曲目（列表项、上一个 / 下一个、播完接续）时画面留在原来的位置。搬动的是同一个媒体元素：不重新读取文件、不从头播放、不中断。
  - 页内占位：视频是画面搬走那一刻的一帧（压暗），上面是「正在画中画播放，点击此处显示」；从未在页内显示过的曲目用它的缩略图（还没有缩略图时是黑底）。音频卡片在字幕区显示同样的说明。点占位只把画面收回页内，不翻屏、不暂停。
  - 窗口内容自上而下：内容区（视频按画面比例完整显示，音频显示它的图；字幕照常，离底边留出间距），其下是功能栏：标题行（当前曲目的文件名，在行的正中，与文件栏的文件名一样点击即在主窗口定位到它；右端是「固定」）、播放行（播放 / 暂停与进度条（画有书签和区段，可点击拖动）、时间（悬停换成快退 / 快进））、按钮行（左边是上一个、下一个、循环范围（单文件 / 列表 / 跨书，点击轮换，图标随之变化）、只播放书签区段，右边是过滤和收藏列表）。三行左右对齐。画中画窗口的标题是当前曲目的文件名，没有曲目时是应用名。「过滤」悬停（或键盘聚焦、点击）即在上方弹出音频、视频、只含书签三个开关，有任何过滤生效时它显示为按下；「只播放书签区段」与总控栏的是同一个开关，图标、说明相同，两边同步。按钮只有图标，悬停看说明，状态与主窗口、其他窗口改动的设置同步。在内容区上按住横向拖动即快进 / 快退当前曲目（规则同主窗口的「拖动定位」），提示显示在画中画窗口里。
  - 操作面板默认固定、常显。点「固定操作面板」取消固定后，标题行与操作面板收起、内容区占满窗口；鼠标移到窗口下部时它们浮在内容区上弹出（字幕随之让到上方），移开即淡出。再点一次恢复固定，固定与否会记住。
  - 「固定」同时固定功能栏和播放列表：固定时功能栏停靠在内容区下方、播放列表停靠在窗口右侧；不固定（默认）时两者都收起、内容区占满窗口：鼠标移到窗口下部稍停即浮出功能栏，靠近右缘稍停即浮出播放列表，移开稍等淡出，快速划过不会弹出；在功能栏所在的高度靠近右缘不会弹出列表（功能栏最右的按钮点得到）。选择会记住。切换「固定」时画面大小不变，窗口相应放大或缩小（窗口已到屏幕边缘或尺寸上限时由画面让出空间）。窗口很窄时固定的列表仍按浮出的方式显示。
  - 播放列表只显示文件名（不带扩展名），每项前有一个书签标记位，与缩略图上的书签角标一样：有书签时显示书签图标，多于一个时带数量，有区段书签时是区段的蓝色，没有书签留空；当前曲目高亮，打开窗口时滚到它；被过滤的项也在其中，颜色变淡但仍可读、可点。列表跨多本书时，每本书的项前有一行书名小标题。列表很长时只在自己的区域里滚动（只画看得到的部分，数百项也不卡）。悬停或键盘选中显示带缩略图的文件详情框（视频是缩略图栏里的同一张画面，还没有时在空闲时生成；音频是它的图；窗口太小放不下时改为悬停提示）。点击只播放、主窗口不跳转；每项的「定位」（主窗口跳到该文件所在的页，必要时切书）和「移除」（见上文「播放列表」）只在悬停或选中的项上显示，叠在这一行的右端，不占文件名的宽度。
  - 「收藏列表」按钮打开一个菜单：第一项「保存当前列表」，点击后就地输入名称（默认名见上文「收藏列表」），回车保存、`Esc` 取消；其下是已收藏的列表（名称、文件数），点击即载入并播放，每个都可以就地改名、删除。
  - 窗口里的按键：`空格` 播放 / 暂停，`←` `→` / `A` `D` 点按 2 秒、按住递增快退 / 快进，`↑` `↓` 在列表里选择（列表收起时临时浮出）、`Enter` 播放，`Q` / `E` 调音量。这些按键只作用于画中画窗口，不会触发主窗口的快捷键。
  - 默认是约 480×480 的方形窗口，可以拖动调整；窗口变窄时先收起时间、按钮行的按钮等分缩小（固定的播放列表改为浮出），变矮时依次收起按钮行和标题行，内容区始终保持画面比例，任何尺寸都不溢出。语言、深色样式与主窗口一致。
  - 关闭：窗口自己的关闭按钮、再按一次入口、刷新或关闭主窗口（画中画随之关闭）。关闭时画面回到页内，播放不中断（继续后台播放）。
- **自动播放**（**设置 → 阅读**，默认关闭）：开启后，没有自动滚动时，混合、影音模式下滚动停下约 0.3 秒、且没有任何媒体在播放（包括后台播放）时，播放离视窗中心最近的视频；快速滚过不会触发。音频不会因为滚动、翻屏进入视野而播放，只在点击音频书签、影音模式切到它、自动滚动中轮到它时开始；漫画模式下任何媒体都不自动播放。用 `A` / `D` / `←` / `→` 翻屏时，翻过去之后有视频进入播放范围的，这一次直接落在该视频居中的位置（滚轮、拖动、滚动条不做这种对齐；漫画模式和关闭自动播放时也不对齐）。由自动播放开始的视频中线离开视窗或切书即暂停并取消，播完不接续，也不重建播放列表；手动点它播放 / 暂停之后按后台播放对待。手动暂停的媒体在离开视窗再回来之前不会自动播放。打开应用或切换书籍后，要先有一次按键、点击或滚轮操作才会自动播放，避免一打开就出声。
- **音量**：全应用一套音量和静音，所有视频、音频共用，会记住，并在所有窗口同步。在总控栏的音量按钮上调节，或 `Q` / `;` 减、`E` / `'` 加，每次 5%，按住连续调，调节时短暂显示音量。
- **播完之后**：后台播放的按播放列表接续（见上）。自动滚动播放的由自动滚动决定：影音模式按页序播放下一个视频或音频（跳过图片和播不了的），滚到视窗中央、从头播放，末尾与重复由总控栏的「循环」决定（见「播放模式」）；混合模式按页序往下滚。自动播放开始的播完即停。
- **播放位置**：每个媒体记住上次播到哪里，滚到它或手动播放时从那里继续；播到结尾（剩余不足 5 秒）则下次从头开始，自动切到的媒体也从头播放。位置随书目保存（在暂停、离开视窗、切书、关闭窗口时，播放中至多每 10 秒一次），也随备份导出。
- **快进 / 快退**：长按 `D` / `→` 快进、长按 `A` / `←` 快退文件栏显示的媒体（暂停中的、不在视窗里的也可以），约每 0.25 秒跳一次，步长随按住时间增大（2 秒、5 秒、10 秒，之后每次 30 秒），同时显示累计偏移和目标时间，松开即停。单击仍是翻屏。
- **拖动定位**：在当前曲目（选中的媒体）的视频画面、音频卡片的字幕区或画中画窗口的内容区上按住横向拖动即快进 / 快退；其他媒体上横向拖动没有效果（不定位、不算点击），竖向照常滚动。先移动一小段判断方向，之后锁定：横向是定位（不滚动、不算点击、松手不滑行），竖向照常滚动。拖动中显示偏移和目标时间（按整秒变化，在两秒交界处不来回跳），松手才定位，`Esc` 取消。拖过整个媒体宽度约等于时长的 1/4，至少 30 秒、最多 5 分钟，不超过时长；不会超出开头和结尾。
- **字幕**：只支持外挂字幕文件：`.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc`（歌词）；视频文件内嵌的字幕轨浏览器不开放给网页，不支持。字幕与同一文件夹里、文件名以媒体主文件名接 "." 开头的媒体配对（`片名.mp4` 对 `片名.srt`、`片名.zh.srt`、`片名.chs.ass`，不区分大小写）；导入和刷新时列目录顺带记下，不打开文件，字幕文件不算页、不计数。散图图集里的媒体与同一批选入或拖入的字幕配对，之后单独加入图集的字幕也会配上已有的同名媒体。只取文字和时间，样式、特效、定位、绘图一律去掉，统一显示为半透明深色底上的白字，最多 3 行：视频叠在画面底部（全屏同样显示），音频显示在卡片里。总控栏右区的「字幕」按钮（作用于文件栏显示的媒体）开 / 关字幕（会记住，在所有窗口同步）；一个媒体有多个字幕时按钮弹出菜单，可选「关闭」或其中一个，选择按媒体记住，没选过的默认用与媒体完全同名的，其次按文件名顺序第一个；没有字幕的媒体按钮变灰。字幕文件在该媒体第一次要显示字幕时才读取，本次会话内缓存，文件大小或修改时间变了才重新读取；编码先看 BOM，再按 UTF-8，不是时依次尝试 GB18030、Big5、Shift_JIS、EUC-KR（顺序随界面语言调整）。读不到时简短提示，不影响播放。字幕的文件名和选择随备份导出。
- **读盘**：导入和刷新只看文件名，不打开媒体文件。只有出现在视窗里的媒体和当前曲目才交给浏览器按需读取（不整体读进内存），其余离开视窗即释放；相邻的媒体不预先加载。
- **缩略图与封面**：缩略图栏和全屏缩略图里，视频、音频的格子与全屏缩略图的格子同样大小和比例（不压低高度），视频显示真实画面：优先用该视频时间最早的书签处的画面，没有书签时取片长约 10% 处，画面接近纯黑时再试 30%、50%。画面压缩成小图保存，只为看得到的视频在空闲时逐个生成（有视频、音频在播放或正文在读图时让路），文件没变就直接使用；播放不了的视频不反复尝试，仍显示类型图标小块。音频与书签列表里的音频书签同一种样子：整块显示音频卡片上的那张图（书的封面或占位图，不压暗、没有大图标），右下角是小音乐图标和时长，文件名在下沿的名称条上，书签角标在右上；封面换了跟着变。点击视频、音频的缩略图直接把该文件放到阅读区中央（不选中、不播放）；悬停或键盘选中时弹出文件详情框（见下）。
- **文件详情框**：缩略图栏、全屏缩略图里的视频、音频，以及书签面板、书架书签、全屏书签、「选择起点」里的视频、音频书签，悬停或键盘选中时立即在旁边弹出详情框（取代悬停提示）：文件名（前面是类型图标，最多两行，再长时省略中间、保留开头和结尾），以及一条画有这个文件全部书签和区段的进度条，滑块在上次播放到的位置（正在播放时为强调色、实时更新；时长还不知道时不读文件，也不画进度条）。详情框宽度固定，不随名称长短变化。书签上弹出的详情框内容与所在文件的相同，只是进度条上方另有一个朝下的三角指着这个书签的时间，它这一对标记高亮，最下一行写着它的时间和名称（指在区段书签那一项上时是区段书签那一端）。详情框不挡住所指的格子，也不能点；移开即消失。浮出的缩略图栏、书架书签（以及画中画的播放列表）要等完全显示之后才弹详情框，那时指针仍停在某项上就为它弹出。书架的默认封面取按文件名顺序第一个有画面的页（图片或视频）；全书只有音频时，用作品名生成文字封面。含视频、音频的书在封面右上角显示类型角标。

### 书签

- **长按 `F` 或 `Enter`**：在屏幕中央位置添加书签。按住时会出现逐渐填满的圆环，提示正在添加；提前松开则按单击处理。
- **单击 `F` 或 `Enter`**：跳到下一个书签，到最后一个后回到第一个；加 `Shift` 则反向，跳到上一个。
- **长按 `Shift+F` 或 `Shift+Enter`**：添加区段书签（见下文）。
- **右键单击**：在鼠标处打开书签面板，顶部是「添加书签」「添加区段书签」两个图标按钮（区段按钮为区段配色，名称和长按的快捷键在悬停提示里）和一个小的「设置为封面」按钮，「添加书签」正好在鼠标下方。最近书签（见下文）与鼠标悬停同样高亮。点击书签跳过去并关闭面板，鼠标悬停不会跳转；按 **Esc** 或点击面板外关闭，位置不变。

书签附带一张画面缩略图，并且记录的是所在文件而不是滚动位置，所以重新排序后依然有效。

**最近书签**：书签按书的顺序（与书架书签列表相同）、页序、页内位置（视频、音频按时间）排成一条线，区段的起点和区段书签各算一项；最近书签是当前阅读位置之前（正好在这里的也算）最近的一项，后面的不算。视窗中心是视频、音频时按它的当前播放时间：播放到 6:30 时，本文件 5:23 的书签比 4:20 的近，前面文件、图片上的更远。书签面板只看本书，前面没有就不高亮；书架书签在本书前面没有时取列表里前面最近一本有书签的书的最后一个；全屏书架书签打开时选中它；添加区段书签时默认选中它。区段不整段高亮，只高亮最近的那一项。刚跳到的书签（滚动位置没变，比如夹在书首、书尾）仍算最近。

**视频和音频的书签**：书签作用的文件（当前曲目在本书且中线在视窗内时是它，否则视窗中心所在的页）是视频、音频时，长按 `F` / `Enter`、书签面板的「添加书签」在它的当前播放时间加书签，文件栏或音频卡片上的书签按钮加在各自显示的那个文件上；同一媒体 2 秒内已有书签时提示已存在。书签按页序排列，同一个视频、音频里按时间先后。点击视频、音频的书签（书签面板、书架书签、全屏书签）或单击 `F` / `Enter` 跳到它时，把该媒体滚到视窗中央、定位到书签时间并开始后台播放（不取决于「自动播放」设置）。书签列表里，视频、音频书签带类型角标和时间点，名称叠在缩略图下沿；视频书签的缩略图是书签时刻的画面（在播放器里添加时直接截取，否则在列表里出现时才在后台逐个截取并保存），音频书签显示音频的图（书的封面或占位图，不压暗、没有大图标），不能选作封面。进度条上按时间画出这个文件的全部书签，指向时提示时间（标记挤在一起时取离指针最近的），点击跳过去。

**PotPlayer 书签**：视频、音频旁边有 PotPlayer 的书签文件（`.pbf`）时一并导入：它与同一文件夹里主文件名相同的媒体配对（`X.flac` 对 `X.pbf`，也认 `X.flac.pbf`；同一主文件名有多个媒体文件时不导入），直接拖入的媒体只与同一批拖入的 `.pbf` 配对；`.pbf` 本身不是页。导入的书签与其他书签一样进入书签列表，名称为「<文件名>-<PotPlayer 里的名称>」（PotPlayer 里没有名称的按应用内规则编号，见下文「书签名称」）。`.pbf` 在后台空闲时读取；之后随文件夹检查（打开、切回窗口、手动刷新）只比较它的大小和修改时间，有变化才重新读取并合并：新条目加入，PotPlayer 里改了名称的跟着改（在 MangaView 里手动改过名称的不被覆盖），与已有书签相差不到 1 秒的不重复添加；PotPlayer 里删掉的条目在 MangaView 中保留，在 MangaView 里删掉的也不会再被加回。导入时不截图，视频书签的画面在书签列表里出现时才生成。

**区段书签**：区段书签与它前面的一个书签配成一对，两者之间是一个书签区段。长按 `Shift+F` / `Shift+Enter`、书签面板的「添加区段书签」或文件栏、音频卡片上的区段按钮，都先弹出「选择起点」：图片列出本书当前位置之前的图片书签，视频、音频列出这个文件里当前时间之前的书签，按位置排列，默认选中最近的一个并滚到可见；书签很多时也可以按住拖动滚动。方向键或点击改选，回车或「确定」确认（双击直接确认），`Esc` 或「取消」取消；悬停只高亮、不改选。区段书签取触发那一刻的位置（媒体取那一刻的播放时间，不因对话框暂停）。所选起点已有区段时（格子带区段标记和虚线框，底部注明「已有区段，将移动终点」），把它的终点移到这里；区段书签本身不能作起点。前面没有可选的书签时只提示、不弹出。终点离起点不到半屏（媒体不到 2 秒）时按“这里已有书签”处理；图片书签与媒体书签互不配对。区段可以嵌套，也可以交叉；区段内仍可以照常添加普通书签。从 PotPlayer 导入的书签也可以在应用内补加区段书签，区段书签随备份导出。区段书签不计入书签数，也不是单击 `F` / `Enter` 的停靠点；在书签列表（书签面板、书架书签、全屏书签）里，起点和区段书签是同样大小的两项，与其他书签一起按位置排序（页序、页内位置，视频、音频按时间），区段内的其他书签夹在两者之间；两项各带一个互相呼应的区段配色（蓝色）标记，平时不描边；悬停或选中任意一项时两项一起以区段配色高亮（作为最近书签时只高亮那一项），点哪项跳到哪里（媒体跳到对应的时间），各有自己的删除和改名按钮（区段只有一个名称，两项显示同一个）；全屏书签里用方向键移动时，区段书签也是单独的一项。删除区段书签，起点变回普通书签；删除起点，区段书签一并删除。重新排序使区段书签排到起点之前时，这个区段暂不生效（区段书签那一项变灰、按它自己的位置排在起点之前，两头都不画区段标记，起点按普通书签显示），数据保留，排回来即恢复。缩略图角标、页内细标记、全屏缩略图的区段范围、进度条上的区段标记和区段、书签面板的「添加区段书签」按钮、长按添加区段书签的进度环都用同一个区段配色。进度条上的区段是一对方括号，起点和区段书签各在自己的时间点上（不连线、不分层）；指向或键盘聚焦某个标记时（挤在一起时取离指针最近的）只高亮它这一对，两者之间的一段在轨道上以区段配色显示，并提示两端的时间与名称，点击跳到该标记的时间。文件栏、音频卡片、文件详情框和画中画窗口里的进度条都是这样。

**书签名称**：视频、音频书签都有名称，叠在缩略图下沿，也出现在提示、进度条标记和全屏书签的搜索里。应用内添加的名称为「<文件名>-书签N」（文件名不含路径和扩展名，N 接着这个文件里已有的最大序号，「书签」一词按添加时的界面语言），旧版本留下的媒体书签打开时自动补上名称。图片书签没有默认名称，仍只显示缩略图（读屏为「第 N 页」）。任何书签都可以重命名：在书签面板、书架书签、全屏书签里选中（悬停或键盘选中）后按 `F2`，或点它上面的铅笔按钮，就地编辑；`Enter` 确认，`Esc` 取消，清空后确认则恢复默认（媒体书签恢复为自动名称，图片书签恢复为没有名称）。改过名的图片书签也显示名称。

**只播放书签区段**：总控栏上的开关，会记住并在所有窗口同步。开启后自动滚动只走区段：漫画、混合模式的滚动只经过图片区段，到区段终点直接跳到下一个区段的起点（漫画模式只经过区段内的图片）；区段嵌套、交叉时按所有区段的并集进行，重叠的部分只经过、只播放一次。一个媒体内只播放它的书签区段：从当前时间之后的第一个区段开始，播完一段跳到下一段，最后一段播完即算这个媒体播完（单文件循环时回到第一段）。混合、影音模式下没有区段的媒体被跳过，除非它整个处在某个图片区段之内（此时整段播放）；手动播放它们则整段播放。手动把进度拖到区段之外时照常播放，进入后面的区段后恢复跳转。进度条上各区段常显（即所有区段的并集），并集以外变暗。本书一个区段都没有时开关仍可打开，并提示「本书没有书签区段」；此时按「自动滚动」同样提示，不开始。

**书架书签**：与缩略图栏的用法相同，按阅读列表集中显示其中各书的书签（书架页选中书架、书库还是全部，就显示哪个列表里的书，不含过期书籍；有筛选时只含筛选结果，此时列表为空会提示清除或更换筛选条件）。藏书很多时也只排版、绘制看得到的部分，打开和滚动不卡。默认不常驻：鼠标移到窗口左缘稍作停留即浮动弹出、移开后淡出收起（**设置 → 阅读** 可关闭左缘弹出）。点工具栏的「书架书签」按钮可以把它常驻在左侧，正文相应变窄；拖动列表右边缘可以调整宽度。鼠标悬停不会跳转，点击书签才跳过去，必要时自动打开那本书。列表紧凑显示，每本书一组缩略图（当前书的一组高亮，最近书签与鼠标悬停同样高亮），不显示书名和文件名；切换书籍、跳转书签或列表弹出时，列表自动滚到最近书签（它可能在前面某本书的一组里；没有最近书签时滚到当前书的一组，都没有则不动；鼠标在列表上或刚手动滚动过时不自动滚动）；顶部整行的「全屏书签」按钮打开全屏书架书签。常驻期间、总控栏的「循环」是跨书循环时，单击 `F` / `Enter`（加 `Shift` 反向）也按这个列表前进，本书后面没有书签时跳到下一本书的第一个书签，最后回到开头；否则只在本书内循环。正在读的书不在阅读列表里时仍只在本书内循环。

**专注模式**（默认开启，可在 **设置 → 阅读** 关闭）：常驻的书架书签列表和缩略图栏在鼠标没有悬停、也没有用键盘进入时隐藏内容，但仍然占位、不收起，底色与阅读区相同，减少干扰。鼠标移上去即恢复显示。显示和隐藏都是带短暂延迟的淡入淡出，鼠标快速划过时不会闪。

### 缩略图栏

鼠标移到窗口右缘稍作停留，缩略图栏会浮在正文上方弹出，移开后自动收起（**设置 → 阅读** 可关闭）。点工具栏的缩略图按钮可以把它设为常驻：常驻时它停靠在右侧，正文相应变窄，不会被遮挡（正文宽度变化、调整窗口大小或进出全屏时，视窗中央的内容保持不动，已在书首 / 书尾的仍停在书首 / 书尾）。拖动缩略图栏左边缘可以调整宽度。栏顶整行是「全屏缩略图」按钮，并显示页数。缩略图栏跟着阅读位置滚动，不画出视窗对应的区域。点击图片的缩略图按点击处在图里的位置定位；点击视频、音频直接把该文件放到阅读区中央。

有书签的页在缩略图右上角显示书签角标（只有一个书签图标，同一页有多个书签时带数量；这一页有区段的起点或区段书签时图标为区段配色），缩略图左侧按书签在页内的位置画出细标记：普通书签是一道短线，区段的起点和区段书签是一对方括号，嵌套的区段向内缩进一级（最多 3 级），鼠标指向其中一头所在的页时两头一起高亮。增删书签只更新受影响的那几页。

缩略图缓存在本次会话的内存里（上限 64 MB，不写入磁盘）：同一本书再次打开全屏缩略图，或切到别的书再回来，都不必重新读取原图，直到关闭应用。

**全屏缩略图**：点缩略图栏顶部的按钮，或按 `V` / `]` 打开整本书的全屏总览，再按一次或按 `Esc` 关闭。页面默认排成规整的网格，标题行的按钮可以切换为按页面比例排列的瀑布流（两个全屏界面共用这个选择）；右侧是加宽的滚动条，适合页数很多的书快速浏览和定位。打开时选中当前页，当前页始终带高亮描边（不缩小，与移动中的选中项区分）；`A` `D` / `←` `→` 按页序移动，`W` `S` / `↑` `↓` 在同一列上下移动，也支持 `Page Up` / `Page Down`、`Home` / `End`。点击缩略图或按 `空格` / `Enter` 跳到该页顶部（视频、音频则放到阅读区中央）并关闭。有书签的页同样带书签角标；选中（悬停或键盘）带区段起点或区段书签的页时，标出这些区段覆盖的所有页（每个区段一圈描边，嵌套的向内缩进一级，最多 3 级），移开即消失。

**全屏界面里的搜索**：两个全屏界面的标题行都有搜索框，输入即过滤，键盘只在结果内移动。全屏缩略图匹配文件名（合并作品含卷的文件夹名）；全屏书架书签匹配作品名和书签所在文件的文件名，作品名命中时显示该作品的全部书签。搜索框旁有「图片 / 视频 / 音频」三个开关，可多选，全不选即不限（全屏书架书签按书签所在页的类型）。打开时焦点仍在当前内容上，`/` 或 `Ctrl+F` 聚焦搜索框；在搜索框里按 `Esc` 先清空并回到列表，再按一次才关闭。没有结果时提示「没有匹配的项」并给出一键清除（连同类型开关）。搜索词和类型只在本次打开期间有效，关闭即清空，不影响上一本 / 下一本和书签跳转。

**全屏书架书签**：点书架书签列表顶部的按钮，或按 `C` / `[` 打开，全屏显示书架书签列表里的所有书签，按书分组并以书名作小标题（当前书高亮），同样可以切换网格和瀑布流。打开时选中最近书签（没有时选中当前书的第一个书签）；`A` `D` / `←` `→` 按顺序移动，`W` `S` / `↑` `↓` 移到上 / 下一行横向最近的书签；点击或 `空格` / `Enter` 跳过去，必要时自动切换书籍。在一个全屏界面里按 `V` / `]` 或 `C` / `[` 可直接切换到另一个。

两个全屏界面的标题行右侧依次是网格 / 瀑布流切换、书架按钮（橙色、较宽，也可以按 `B`）和关闭，不显示按键说明。书架盖在全屏界面上层打开，全屏界面不关闭。在书架里切换书籍，全屏缩略图随之换成新书；关闭书架后回到原来的全屏界面。全屏界面只在跳转到某一页 / 书签，或主动关闭时才关闭。

### 排序

在「排序」里选「当前文件夹／书本」，只为当前这本书设置顺序；选「统一默认排序」则修改默认顺序。「跟随默认排序」会取消这本书的单独设置。每次选择「打乱顺序」都会重新洗牌，但重新打开同一本书时保持原来的乱序。按修改时间排序时，按需读取文件的修改时间；重新导入文件夹可以刷新这些时间。

### 刷新文件夹

MangaView 会在三种情况下检查文件夹里文件的增删（第一种可在「设置」中关闭）：

- 每次打开应用或刷新页面时，先检查当前这本书，其余仍有访问权限的文件夹在浏览器空闲时逐个在后台检查，不与阅读抢硬盘；同时开着多个窗口时，其余文件夹只由其中一个窗口检查一次；
- 切回应用窗口时，检查当前这本书；
- 点「刷新」按钮（工具栏最左侧和书架页上各有一个）时，检查全部文件夹，并可为当前书重新请求授权。

刷新不会发现新增的子文件夹，需要重新添加上一级文件夹。

### 过期书籍与文件搬家

找不到文件夹的书**永远不会**被自动删除，因为浏览器无法区分“文件夹已删除”和“移动硬盘未连接”。一本书的文件夹**全部**找不到时，它会归入「过期书籍」，封面、标签、书签和进度都保留；重新连接硬盘并刷新后会自动回到原来的列表。合并作品只有部分卷找不到时，书照常可读，缺失的卷暂时隐藏，书架卡片上有一个小提示，找回后自动恢复，也可以点卡片上的「恢复」重新关联。只有你手动删除时，记录才会被删除。

浏览器不会提供文件夹在磁盘上的完整路径，所以文件搬家后，MangaView 以**文件夹名称**加**首个文件**（按文件名排序的第一个文件，不论图片、视频还是音频；与封面画面、自定义封面无关）的指纹来识别书。指纹是文件名、精确大小和文件开头 64 KB 的摘要，不读整个文件。含视频、音频的书另在后台记下各媒体文件的大小（只读文件信息）：文件夹改名或首个文件对不上时，媒体文件的「文件名 + 大小」大多对得上的也会列出来由你确认，同名但大小不同的不会自动接回；散图图集里的视频、音频按相对路径和文件名找回时还要求大小一致。合并作品按每一卷分别匹配：

- **重新添加上一级文件夹**：文件夹名称和封面都一致的过期书或缺失的卷会自动接回原记录，不会重复添加。
- **批量恢复…**（在「过期书籍」中）：选择存放这些书的文件夹，层级不限。完全匹配的直接恢复；可能匹配的（改了名但封面相同，或同名但封面不同）列出来由你勾选；其余保持过期。散图图集里失效的图片也一并找回。恢复只接回已有的记录，**不会新增书**：文件夹里没有对应记录的内容一律忽略。恢复单本书或「定位原文件」时，所选文件夹里其他失效的书和散图也会一并接回。
- **单本「恢复」**：选择这本书的文件夹。不匹配时也可以「强制恢复」，保留标签、书签和进度；整本过期的合并作品一卷都对不上时，按所选文件夹重建，相对路径相同的卷保留书签和进度；合并作品只缺一卷时，可以把所选文件夹强制接到这一卷，其他卷不受影响；缺多卷时不猜测，提示没有找到匹配的文件夹。

### 多个窗口

可以同时打开多个 MangaView 窗口（浏览器标签页或已安装应用的窗口），包括同一本书：

- 在一个窗口里对书目、书签、标签、封面、书名、所在列表的改动，其他窗口在 1 秒内跟着更新，只更新受影响的项。不同窗口修改同一本书的不同内容（例如各加一个书签）都会保留。
- 一个窗口删除了某本书，正在读它的其他窗口会提示，并与本窗口删除一样切到阅读列表里的下一本（没有则上一本，列表空了回到书架页），这本书的记录不会被写回。
- 设置（设置面板里的各项、语言、默认排序、音量和静音、只播放书签区段，以及总控栏的播放模式、滚动速率、播放速率、单文件模式、循环）在所有窗口即时生效；缩略图栏和书架书签是否常驻、宽度、列表样式等布局各窗口互不影响，下次打开时用最后改动的那个。
- 每个窗口有自己的当前书和阅读位置；同一本书的阅读位置以最后保存的为准。
- 启动时检查全部文件夹、生成封面等后台读盘只由一个窗口进行，其他窗口不重复读硬盘；这个窗口关闭，或转到后台而另一个窗口在前台时，由别的窗口接手。
- 「还原默认设置」、导入备份、清除全部数据后，其他窗口自动重新载入。
- 新版本改变了存储结构时，仍开着的旧窗口会让出存储并提示重新载入，不会卡住新窗口。
- 画中画（见「视频与音频」）：同一浏览器同时只能有一个画中画窗口。一个 MangaView 窗口打开画中画时，另一个窗口原来的画中画窗口被浏览器关掉，那个窗口把画面收回页内、继续后台播放。每个窗口的画中画只显示本窗口的当前曲目和播放列表；主窗口刷新或关闭时它的画中画随之关闭。

### 数据与权限

图片、视频和音频只在本机读取，不会上传，也不会复制。浏览器里保存书目索引、只读文件句柄、排序设置、阅读位置、标签、书签、搜索预设，以及压缩后的小缩略图（封面、书签和视频画面，从不保存原文件）；清除站点数据会清空这些内容。

「设置 → 数据」显示存储占用，可以把全部数据导出为一个 JSON 文件，也可以导入（与现有数据合并或替换）。文件里不含图片和文件夹访问权限，在另一台电脑上导入后，书会显示在「过期书籍」里，用「批量恢复…」重新关联即可。备份格式为 2：仍可导入旧版导出的备份，但旧版应用无法导入新版备份。存储占用接近浏览器配额时，会提示删除不再需要的旧书记录。

设置面板底部的「还原默认设置」把设置项和界面布局（侧栏、宽度、默认排序等）恢复默认并重新载入页面，书籍、书签、标签、阅读进度、搜索预设和收藏的播放列表都不受影响。

- 重新打开时如果浏览器收回了访问权限，用「重新授权」。
- 浏览器更新后，之前保存的文件夹访问可能整体失效（浏览器不再响应这些授权，重新选择同一个文件夹却正常）。这是浏览器的行为，网页应用拿不到磁盘路径，无法自行重新打开文件夹。MangaView 启动时会在几秒内判断出来（只问浏览器，不读硬盘，所以不会和机械硬盘读得慢混淆），并显示一条提示，说明是浏览器更新所致。点提示里的「批量恢复…」，选择存放漫画的上级文件夹，单文件夹书、合并作品的各卷、散图图集都会接回原记录，标签、书签和进度保留；选择框会开在上次恢复时的位置。硬盘只是读得慢时，图片在等待一段时间后显示「图片无法显示」，稍后会重试。
- 如果文件已经移动，用「定位原文件」。
- 不支持文件句柄的浏览器，重启后需要重新选择原文件。

## 从 v1 升级

原来位于 `/mangaview/dist/` 的旧版已被 v2 取代。v1 不保存阅读记录，因此没有数据需要迁移。

- 访问旧地址或打开已安装的 v1 应用时，会自动跳转到新版。
- 如果安装过 v1，请从地址栏安装 v2，然后在 `chrome://apps`（Edge 为 `edge://apps`）卸载旧版应用。

## 开发

没有构建步骤，也没有第三方依赖，全部是以静态文件提供的原生 ES 模块。

### 本地运行

仅用于开发调试；日常阅读请直接使用在线版。

- **Windows**：安装 [Python 3](https://www.python.org/) 后，双击仓库根目录的 `local_run.bat`。它会在 http://127.0.0.1:4173/ 启动服务并打开浏览器，关闭命令行窗口即停止。
- **任意平台**：在仓库根目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173/ 。

不支持直接双击 `index.html` 打开，因为安装、离线和文件访问都需要安全上下文（HTTPS 或 localhost）。

```sh
# 全部测试：先跑核心测试，再逐个串行跑无头 Chrome / Edge 端到端测试，失败的自动单独重跑一次，最后列出通过 / 失败清单

# 只跑文件名包含给定名称的端到端测试（核心测试照常先跑）

# 只跑核心测试（纯逻辑，tests/core/*.test.mjs）
node tests/run.mjs
```

端到端测试（`tests/browser.mjs`、`tests/*.browser.mjs`）各自使用临时浏览器配置和自动生成的测试图片；视频、音频由 `tests/media-fixtures.mjs` 在测试页里现场生成。

以下几项自动化测试覆盖不到，需要人工验收：

- 安装后断网冷启动；
- 从真实机械硬盘（不要用 SSD 代替）导入数千张图片，并在滚动中切换书本；
- Windows 上用中键自动滚动连续读过长图；
- 已安装应用的实际窗口边框；
- 多个真实窗口在前台、后台、最小化之间切换时，后台读盘任务的交接；
- 机械硬盘上的大体积视频库（打开、定位、生成视频缩略图时的读盘表现）、真实窗口拖动缩放时视频的观感、视频的真实全屏；
- 低速自动滚动的平稳度、拖动滚动的惯性手感；
- 长时间的混合模式自动滚动，自动滚动中窗口转到后台再回来；
- 后台播放：窗口最小化或转到后台时播放列表照常接续（含跨书），大体积视频滚出视窗、切书后再回到页里时画面无缝衔接；
- 真实的画中画窗口：默认大小与拖动调整大小时的布局、切换「固定」时窗口随之放大 / 缩小而画面大小不变、不闪、搬动大体积视频时没有可察觉的中断、窗口自己的关闭按钮、两个 MangaView 窗口先后打开画中画，以及 Edge 上的表现（无头 Chrome 的画中画窗口大小不受请求控制，自动化测试只断言行为，布局另在普通容器里按尺寸断言）；
- 真实字幕文件的编码识别、真实全屏下的字幕与文件栏；
- 真实的系统选择框，以及往添加对话框里拖入真实文件夹。
