## 功能

- **打开本地文件**：用选择器或直接拖入文件夹、散图。每个直接包含图片、视频或音频的文件夹算一本书。
- **视频与音频**：浏览器能直接播放的视频和音频与图片排在同一条长条里，自带播放控件，全应用共用一套音量，可以自动播放。
- **导入为单个作品**：分卷存放的作品可以把多个文件夹合成一本书，连续阅读。
- **为长条漫画设计**：每本书是一条连续的纵向长条，图片之间不吸附、不停顿，超长条漫也能顺畅阅读。
- **大图库流畅**：只创建和解码可见页面，并限制同时读取的数量。机械硬盘上的数千张图片也能流畅浏览。
- **缩略图导航**：鼠标移到窗口右缘时弹出，也可以常驻在正文旁边；还可以全屏总览整本书。点击缩略图的任意位置，就跳到图中对应的画面，超长图内部同样准确。
- **书架与书库**：正在读的放书架，其余放书库。以纯封面显示，可在普通网格和瀑布流之间切换，鼠标悬停或用方向键选中时显示书名和操作按钮。
- **搜索、筛选与预设**：按书名、路径、标签、页数、是否有书签、含有的类型（图片 / 视频 / 音频）筛选，常用条件可存为预设。
- **标签**：可为任意书添加自定义标签，输入时联想已有标签，每个标签自动配色；点击标签或在搜索框输入 `#标签` 即可筛选。
- **书签**：长按 `F` 为当前位置添加书签，长按 `Shift+F` 用区段书签标出一段范围。书签列表显示画面缩略图，因为没人记得住文件名；缩略图上也标出哪些页有书签。
- **排序**：按文件名或修改时间正序、反序排列，或打乱顺序。可设为统一默认，也可单独设置某本书。
- **记住每本书的阅读位置**，刷新文件夹时同步新增或删除的文件。
- **文件搬家不丢记录**：找不到文件夹的书会归入「过期书籍」，封面、标签和书签都保留，之后可以重新关联。
- **备份**：所有应用数据可导出为一个文件，在另一台电脑上导入。
- **可安装、可离线**：可以安装为应用，首次加载后断网也能使用。
- **四种语言**：界面按浏览器语言自动显示中文、English、日本語或한국어。

## 开始使用

1. 用最新版桌面 **Chrome** 或 **Edge** 打开 **https://nohnolife.github.io/mangaview/** 。
2. *（可选）* 安装为应用：点击地址栏右端的安装图标，或在浏览器菜单中选择「安装 MangaView」。安装后有独立窗口，可固定到任务栏，断网也能使用。
3. 添加文件夹，或把图片、视频、音频拖进窗口。

新版本会自动更新，不需要下载、解压或任何配置。

## 使用说明

在欢迎页点「添加文件夹」，或用「添加到散图图集」选择图片，也可以拖到窗口任意位置。只拖入文件（图片、视频或音频，没有文件夹）时，松开即加入散图图集。拖入内容含文件夹时，覆盖层下方并排有「导入为单个作品」和「添加到散图图集」两块区域；放到「添加到散图图集」上，拖入的所有图片、视频和音频（包括文件夹里的）都作为散图加入散图图集，不按文件夹建书。鼠标移到窗口顶缘（或按 **T**）唤出工具栏。

### 工具栏与操作栏

鼠标移到窗口顶缘稍作停留，工具栏会在阅读区顶部居中弹出：一行图标，鼠标悬停显示名称，窗口较窄时自动换行；书名和阅读进度显示在它下方。也可以按 **T**，或按 Tab 聚焦左上角的菜单按钮后按 Enter。

鼠标移到窗口底缘则弹出操作栏，按钮固定为「上一本」「回到书首」、当前位置（当前页 / 总页数）、「滚到书尾」「下一本」，已在书首 / 书尾时对应按钮变灰；切书只在这里，工具栏里没有上 / 下一本。书架页设了筛选条件时，上一本 / 下一本只在筛选结果内切换，按钮上带一个小圆点提示。

两者在鼠标移开后淡出收起，可以在 **设置 → 工具栏** 分别关闭边缘弹出，**T** 键仍然可用。单击正文只翻屏（左半屏前一屏、右半屏后一屏），点在视频、音频上则是播放 / 暂停；触屏上点正文顶部可以开关工具栏。

### 书架、书库和标签

点「书架」按钮或按 **B** 打开全屏页面，有四个列表（再点一次当前列表的页签，或再按 **B**，回到阅读界面）：

- **书架**：正在读的书。新添加的文件夹、重新添加的文件夹都会放到这里。
- **书库**：其余的书，用于管理大量藏书。书架页正显示书库时，添加或拖入的书放到书库。
- **全部**：两者合在一起，方便搜索全部内容。
- **过期书籍**：只在有书找不到文件夹时出现，见下文。

「上一本 / 下一本」在当前书所在的列表（书架或书库）内切换。书架页开着时导入新书不会切换正在读的书，只提示导入了几本。

打开书架时，焦点落在正在读的书上并滚动到它的位置。鼠标悬停和方向键选中是同一个状态，选中的封面显示书名、进度和标签，以及编辑书名、编辑标签、设置封面、移动、复制书名、删除记录的按钮；`Enter` 打开，`Delete` 删除记录（会先确认）。有书签的书在封面左下角显示书签数。工具条最右侧的按钮在普通网格（默认，封面等大对齐）和瀑布流（按封面比例）之间切换。工具条按钮只显示图标，鼠标悬停可看说明。

**搜索与筛选**：搜索框匹配书名、文件夹路径、标签，以及合并作品各卷的文件夹名；输入 `#标签` 按标签筛选，`/` 或 `Ctrl+F` 可直接跳到搜索框。有筛选时，搜索框右侧显示结果数。「筛选」按钮展开筛选面板：页数范围、「包含书签」、类型（图片 / 视频 / 音频，可多选，书中含有任一所选类型的页即符合）和标签（多个标签需同时满足，标签多时可以搜索）。面板收起时，生效的条件显示在下方；搜索框右边的「清除筛选」按钮一键清除全部条件。筛选条件会保存下来，在书架、书库和全部之间切换时保持不变；上一本 / 下一本和书架书签也只在筛选结果内进行。

**搜索预设**：把当前筛选条件存为预设，在预设菜单里点选即可应用，也可以重命名、删除或用当前条件更新；应用后再改动条件，预设按钮上会出现一个小圆点（提示文字标出「已修改」）。

**书籍排序**：排序菜单可以按添加时间（默认反序，即新添加的在前）、文件夹时间、名称排序，均可正反序（正序：从旧到新 / A→Z）；书架、书库、全部共用这个设置，上一本 / 下一本和书架书签也按这个顺序。浏览器读不到文件夹本身的修改时间，「文件夹时间」取文件夹中最新一张图片的修改时间，选用时才在后台计算（只读文件信息，不读图片），尚未算出的排在最后。

**批量操作**菜单：复制列表中的书名；「全部移入书架 / 书库」作用于当前筛选出的所有结果；「清空书架 / 书库」删除该列表中的全部书目（不受筛选影响），会先弹出确认，不会删除原图。

卡片上的铅笔按钮可以编辑书名，只改显示的名称，不改文件夹，搜索原文件夹名仍能找到；留空即恢复原名。编辑标签时输入即在输入框下方浮出联想的已有标签（`↑` `↓` 选择，选中后也可用 `←` `→`，回车添加，`Esc` 先收起联想），输入框为空时列出最近用过和常用的标签。标签颜色按名称自动生成，同名标签在任何地方颜色都一样。

**自定义封面**：卡片上的「设置封面」按钮列出这本书所有书签的缩略图，点选一个即以该书签处的画面作封面（能读到原图时按封面比例重新截取，读不到时用书签缩略图）；书还没有书签时提示先添加书签。底部的「重置封面」恢复默认封面。自定义封面是单独保存的一张小图，之后删除那个书签、刷新、恢复或重新导入都不会改变它，也随备份导出；设置和重置只更新这一张卡片。识别文件夹仍只看默认封面。

### 导入为单个作品

一部作品分成多个文件夹（例如每卷一个）时，可以合成一本书连续阅读：拖入时把文件夹放到覆盖层下方的「导入为单个作品」区域，或点书架页头的「导入为单个作品」按钮选择一个文件夹，其下各个带图片的文件夹合成一本，按路径顺序排列。

- 同一组文件夹再次导入时，更新原来那本书而不是重复添加：新增的卷追加进来，已不存在的卷移除，书签和进度保留。
- 同一个文件夹可以既是一本独立的书，又是一本或多本合并作品中的一卷，刷新或重新导入时各处同步更新。
- 书名用所选（拖入）的文件夹名称；拖入多个文件夹时，用按文件名顺序排第一的那个。
- 只有一个带图片的文件夹时按普通的书导入（识别和恢复仍以这个文件夹为准），但书名用所选的根文件夹名，搜索原文件夹名仍能找到；编辑过书名的书再次导入时不覆盖。散图加入散图图集。

### 散图图集

散图图集只有一个：「添加到散图图集」选择的图片、直接拖入的图片，以及拖到「添加到散图图集」区域的所有图片都加入它。同名的不同图片可以共存，同一个文件不会重复加入。部分图片找不到时图集照常可读，找不到的图显示为无法读取；用「定位原文件」（图集过期时用卡片上的「恢复」）选择存放这些图片的文件夹（层级不限），按相对路径和文件名逐张找回。

### 视频与音频

浏览器能直接播放的视频（mp4、m4v、webm、mkv、mov、ogv）和音频（mp3、flac、wav、ogg、oga、opus、m4a、aac、weba）与图片一样按扩展名识别，作为页排在同一条纵向长条里，排序规则（文件名、修改时间、打乱）一视同仁。只有视频或音频的文件夹也算一本书；直接拖入的视频、音频并入散图图集。

- **不支持的格式**：avi、wmv、flv、rmvb、ts、mpg、wma、ape 等浏览器播不了的媒体文件不导入，导入结果里会说明数量并列出扩展名；刷新时不再提示。扩展名受支持但实际播不了的文件（如部分 HEVC 编码的 mkv），该页显示「浏览器无法播放此文件」和「重试」，不影响其他页；这个结果连同文件的大小和修改时间记下来，文件没变就不再尝试，点「重试」或文件变化后才重新尝试。
- **布局**：视频的宽度规则与图片相同（跟随「铺满宽度」），高度按画面比例；比阅读区还高时等比缩小到正好一屏并居中，保证整个画面可见（调整窗口大小时，停下约 0.2 秒后才按新高度重排，期间画面在原位置临时缩小）。尺寸在第一次显示时读到并记下，之前按 16:9 占位，读到后不会把当前画面挤走。音频是固定高度的横条：类型图标、文件名和播放控件，宽度有上限、居中。
- **播放控件**：播放 / 暂停、可点击和拖动的进度条（画有书签标记）、当前时间 / 总时长、静音、音量滑块，添加书签、添加区段书签、只播放书签区段、播放顺序、循环、新窗口播放，视频另有全屏（全屏的是画面连同控件，快捷键照常可用）。控件都是图标，悬停看说明；宽度不够时，音量滑块等次要控件收进「更多」弹出层。视频的控件浮在画面底部，鼠标移开或播放中静止几秒后淡出；音频的控件常显。单击画面播放 / 暂停（不翻屏），按住拖动仍是滚动。
- **当前媒体**：快捷键作用的对象是本窗口正在播放的媒体；没有在播放的，就是中线在视窗内、离视窗中心最近的那个（暂停的也算）。一个窗口同时只播放一个媒体。
- **自动播放**（**设置 → 阅读**，默认开启）：滚动停下约 0.3 秒、且没有媒体在播放时，播放离视窗中心最近的媒体；快速滚过不会触发。播放中的媒体中线离开视窗即暂停；手动暂停的媒体在离开视窗再回来之前不会自动播放。打开应用或切换书籍后，要先有一次按键、点击或滚轮操作才会自动播放，避免一打开就出声。
- **音量**：全应用一套音量和静音，所有视频、音频共用，会记住，并在所有窗口同步。`Q` / `;` 减、`E` / `'` 加，每次 5%，按住连续调，调节时短暂显示音量。
- **播放顺序与循环**：控件上的「播放顺序」按钮在列表（默认）、随机、单集之间轮换，图标随之变化；「循环」是开关。一个媒体播完后：列表按页序播放下一个视频或音频（跳过图片和播不了的），最后一个播完停下，开循环则回到第一个；随机不重复地播放，全部播过一遍后停下，开循环则重新洗牌继续；单集播完停下，开循环则重复播放。切到下一个媒体时把它滚到视窗中央、从头播放。两项设置会记住，在所有窗口同步。
- **播放位置**：每个媒体记住上次播到哪里，滚到它或手动播放时从那里继续；播到结尾（剩余不足 5 秒）则下次从头开始，按播放顺序自动切到的媒体也从头播放。位置随书目保存（在暂停、离开视窗、切书、关闭窗口时，播放中至多每 10 秒一次），也随备份导出。
- **快进 / 快退**：长按 `D` / `→` 快进、长按 `A` / `←` 快退当前媒体（暂停中的也可以），约每 0.25 秒跳一次，步长随按住时间增大（2 秒、5 秒、10 秒，之后每次 30 秒），同时显示累计偏移和目标时间，松开即停。单击仍是翻屏。
- **新窗口播放**：播放控件上的「新窗口播放」按钮，或 `Z` / `/`（作用于当前媒体），打开一个较小的新窗口，定位到同一本书的同一个媒体并从当前时间接着播放，原窗口里的它随之暂停。新窗口就是完整的应用，只是不做启动时的文件夹检查；窗口在后台或最小化时照常播放，播放顺序与循环照常生效。浏览器拦截了弹出窗口时会提示（允许本站弹出窗口后重试），原窗口照常播放；浏览器不让新窗口自动出声时，新窗口提示并停在该位置，点击即可播放。
- **读盘**：导入和刷新只看文件名，不打开媒体文件。只有出现在视窗里的媒体才交给浏览器按需读取（不整体读进内存），离开视窗即释放；相邻的媒体不预先加载。
- **缩略图与封面**：缩略图栏和全屏缩略图里，视频显示真实画面：优先用该视频时间最早的书签处的画面，没有书签时取片长约 10% 处，画面接近纯黑时再试 30%、50%。画面压缩成小图保存，只为看得到的视频在空闲时逐个生成（有视频、音频在播放或正文在读图时让路），文件没变就直接使用；播放不了的视频不反复尝试，仍显示类型图标小块。音频显示为带类型图标、文件名和时长的小块。书架的默认封面取按文件名顺序第一个有画面的页（图片或视频）；全书只有音频时，用作品名生成文字封面。含视频、音频的书在封面右上角显示类型角标。

### 书签

- **长按 `F` 或 `Enter`**：在屏幕中央位置添加书签。按住时会出现逐渐填满的圆环，提示正在添加；提前松开则按单击处理。
- **单击 `F` 或 `Enter`**：跳到下一个书签，到最后一个后回到第一个；加 `Shift` 则反向，跳到上一个。
- **长按 `Shift+F` 或 `Shift+Enter`**：添加区段书签（见下文）。
- **右键单击**：在鼠标处打开书签面板，「添加书签」按钮正好在鼠标下方，下面是「添加区段书签」。离当前阅读位置最近的书签与鼠标悬停同样高亮。点击书签跳过去并关闭面板，鼠标悬停不会跳转；按 **Esc** 或点击面板外关闭，位置不变。

书签附带一张画面缩略图，并且记录的是所在文件而不是滚动位置，所以重新排序后依然有效。

**视频和音频的书签**：有当前媒体（正在播放的，或离视窗中心最近的）时，长按 `F` / `Enter`、书签面板的「添加书签」或播放控件上的书签按钮，都在它的当前播放时间加书签；同一媒体 2 秒内已有书签时提示已存在。单击 `F` / `Enter` 跳到媒体书签时，把该媒体滚到视窗中央并定位到书签时间，开着自动播放就从那里播放，否则停在那个画面。书签列表里，视频、音频书签带类型角标和时间点；视频书签的缩略图是书签时刻的画面（在播放器里添加时直接截取，否则在列表里出现时才在后台逐个截取并保存），音频书签显示为带图标和文件名的小块，不能选作封面。进度条上按时间画出这个文件的全部书签，悬停显示时间，点击跳过去。

**PotPlayer 书签**：视频、音频旁边有 PotPlayer 的书签文件（`.pbf`）时一并导入：它与同一文件夹里主文件名相同的媒体配对（`X.flac` 对 `X.pbf`，也认 `X.flac.pbf`；同一主文件名有多个媒体文件时不导入），直接拖入的媒体只与同一批拖入的 `.pbf` 配对；`.pbf` 本身不是页。导入的书签与其他书签一样进入书签列表，带上 PotPlayer 里的名称（显示在提示和全屏书签里，可被搜索）。`.pbf` 在后台空闲时读取；之后随文件夹检查（打开、切回窗口、手动刷新）只比较它的大小和修改时间，有变化才重新读取并合并：新条目加入，改了名称的更新名称，与已有书签相差不到 1 秒的不重复添加；PotPlayer 里删掉的条目在 MangaView 中保留，在 MangaView 里删掉的也不会再被加回。导入时不截图，视频书签的画面在书签列表里出现时才生成。

**区段书签**：区段书签与它前面的一个书签配成一对，两者之间是一个书签区段。添加时取屏幕中央的位置：位置在某个区段之内，就把这个区段的终点移到这里；否则配给前面最近的一个区段（延长它的终点）或不在任何区段内的普通书签（以它为起点新建区段）；前面什么都没有时只提示、不添加。终点离起点不到半屏时按“这里已有书签”处理。区段之间不嵌套、不交叉，区段内仍可以照常添加普通书签，它们不参与配对。区段书签不计入书签数，也不是单击 `F` / `Enter` 的停靠点；在书签列表里，它是起点缩略图左下角的一张小图，起点和区段书签各带一个互相呼应的标记，悬停任意一张两张一起高亮，点哪张跳到哪里，小图上有自己的删除按钮。删除区段书签，起点变回普通书签；删除起点，区段书签一并删除。重新排序使区段书签排到起点之前时，这个区段暂不生效（小图变灰、不画标记），数据保留，排回来即恢复。视频、音频的区段书签只在同一个文件内按时间配对（取当前播放时间，离起点不到 2 秒按“这里已有书签”处理），播放控件上也有「添加区段书签」按钮；图片书签与媒体书签互不配对。进度条上起点和区段书签画成一对方括号，悬停或聚焦任意一个时高亮两者之间的区段，并提示两端的时间。

**只播放书签区段**：播放控件上的开关，会记住并在所有窗口同步。开启后一个媒体内只播放它的书签区段：从当前时间之后的第一个区段开始，播完一段跳到下一段，最后一段播完即算这个媒体播完，再按播放顺序与循环决定下一个；按播放顺序自动切换时跳过没有区段的媒体（手动播放它们则整段播放）。手动把进度拖到区段之外时照常播放，进入后面的区段后恢复跳转。进度条上区段常显，区段以外变暗。本书一个区段都没有时开关仍可打开，并提示「本书没有书签区段」。

**书架书签**：与缩略图栏的用法相同，按书架顺序集中显示书架上所有书的书签（不含书库和过期书籍；书架页有筛选时只含筛选结果，此时列表为空会提示清除或更换筛选条件）。默认不常驻：鼠标移到窗口左缘稍作停留即浮动弹出、移开后淡出收起（**设置 → 阅读** 可关闭左缘弹出）。点工具栏的「书架书签」按钮可以把它常驻在左侧，正文相应变窄；拖动列表右边缘可以调整宽度。鼠标悬停不会跳转，点击书签才跳过去，必要时自动打开那本书。列表紧凑显示，每本书一组缩略图（当前书的一组高亮，离当前阅读位置最近的书签与鼠标悬停同样高亮），不显示书名和文件名；切换书籍、跳转书签或列表弹出时，列表自动滚到当前书的书签（当前书没有书签则不动；鼠标在列表上或刚手动滚动过时不自动滚动）；顶部整行的「全屏书签」按钮打开全屏书架书签。常驻期间单击 `F` / `Enter`（加 `Shift` 反向）也按这个列表前进，本书后面没有书签时跳到下一本书的第一个书签，最后回到开头。当前书在书库中时仍只在本书内循环。

**专注模式**（默认开启，可在 **设置 → 阅读** 关闭）：常驻的书架书签列表和缩略图栏在鼠标没有悬停、也没有用键盘进入时隐藏内容，但仍然占位、不收起，底色与阅读区相同，减少干扰。鼠标移上去即恢复显示。显示和隐藏都是带短暂延迟的淡入淡出，鼠标快速划过时不会闪。

### 缩略图栏

鼠标移到窗口右缘稍作停留，缩略图栏会浮在正文上方弹出，移开后自动收起（**设置 → 阅读** 可关闭）。点工具栏的缩略图按钮可以把它设为常驻：常驻时它停靠在右侧，正文相应变窄，不会被遮挡。拖动缩略图栏左边缘可以调整宽度。栏顶整行是「全屏缩略图」按钮，并显示页数。

有书签的页在缩略图右上角显示书签角标（同一页有多个书签时带数量；区段的起点、区段书签用各自成对的标记），缩略图左侧按书签在页内的位置画出细标记：普通书签是一道短线，区段的起点和区段书签是一对方括号，鼠标指向其中一头所在的页时两头一起高亮。增删书签只更新受影响的那几页。

缩略图缓存在本次会话的内存里（上限 64 MB，不写入磁盘）：同一本书再次打开全屏缩略图，或切到别的书再回来，都不必重新读取原图，直到关闭应用。

**全屏缩略图**：点缩略图栏顶部的按钮，或按 `V` / `]` 打开整本书的全屏总览，再按一次或按 `Esc` 关闭。页面默认排成规整的网格，标题行的按钮可以切换为按页面比例排列的瀑布流（两个全屏界面共用这个选择）；右侧是加宽的滚动条，适合页数很多的书快速浏览和定位。打开时选中当前页，当前页始终带高亮描边（不缩小，与移动中的选中项区分）；`A` `D` / `←` `→` 按页序移动，`W` `S` / `↑` `↓` 在同一列上下移动，也支持 `Page Up` / `Page Down`、`Home` / `End`。点击缩略图或按 `空格` / `Enter` 跳到该页顶部并关闭。有书签的页同样带书签角标；选中（悬停或键盘）带区段起点或区段书签的页时，标出这个区段覆盖的所有页，移开即消失。

**全屏界面里的搜索**：两个全屏界面的标题行都有搜索框，输入即过滤，键盘只在结果内移动。全屏缩略图匹配文件名（合并作品含卷的文件夹名）；全屏书架书签匹配作品名和书签所在文件的文件名，作品名命中时显示该作品的全部书签。搜索框旁有「图片 / 视频 / 音频」三个开关，可多选，全不选即不限（全屏书架书签按书签所在页的类型）。打开时焦点仍在当前内容上，`/` 或 `Ctrl+F` 聚焦搜索框；在搜索框里按 `Esc` 先清空并回到列表，再按一次才关闭。没有结果时提示「没有匹配的项」并给出一键清除（连同类型开关）。搜索词和类型只在本次打开期间有效，关闭即清空，不影响上一本 / 下一本和书签跳转。

**全屏书架书签**：点书架书签列表顶部的按钮，或按 `C` / `[` 打开，全屏显示书架上所有书签，按书分组并以书名作小标题（当前书高亮），同样可以切换网格和瀑布流。打开时选中当前位置附近的书签；`A` `D` / `←` `→` 按顺序移动，`W` `S` / `↑` `↓` 移到上 / 下一行横向最近的书签；点击或 `空格` / `Enter` 跳过去，必要时自动切换书籍。在一个全屏界面里按 `V` / `]` 或 `C` / `[` 可直接切换到另一个。

两个全屏界面的标题行都有书架按钮（也可以按 `B`）：书架盖在全屏界面上层打开，全屏界面不关闭。在书架里切换书籍，全屏缩略图随之换成新书；关闭书架后回到原来的全屏界面。全屏界面只在跳转到某一页 / 书签，或主动关闭时才关闭。

### 排序

在「排序」里选「当前文件夹／书本」，只为当前这本书设置顺序；选「统一默认排序」则修改默认顺序。「跟随默认排序」会取消这本书的单独设置。每次选择「打乱顺序」都会重新洗牌，但重新打开同一本书时保持原来的乱序。按修改时间排序时，按需读取文件的修改时间；重新导入文件夹可以刷新这些时间。

### 刷新文件夹

MangaView 会在三种情况下检查文件夹里文件的增删（第一种可在「设置」中关闭）：

- 每次打开应用或刷新页面时，先检查当前这本书，其余仍有访问权限的文件夹在浏览器空闲时逐个在后台检查，不与阅读抢硬盘；同时开着多个窗口时，其余文件夹只由其中一个窗口检查一次；
- 切回应用窗口时，检查当前这本书；
- 点「刷新」按钮（工具栏「书架」按钮右侧和书架页上各有一个）时，检查全部文件夹，并可为当前书重新请求授权。

刷新不会发现新增的子文件夹，需要重新添加上一级文件夹。

### 过期书籍与文件搬家

找不到文件夹的书**永远不会**被自动删除，因为浏览器无法区分“文件夹已删除”和“移动硬盘未连接”。一本书的文件夹**全部**找不到时，它会归入「过期书籍」，封面、标签、书签和进度都保留；重新连接硬盘并刷新后会自动回到原来的列表。合并作品只有部分卷找不到时，书照常可读，缺失的卷暂时隐藏，书架卡片上有一个小提示，找回后自动恢复，也可以点卡片上的「恢复」重新关联。只有你手动删除时，记录才会被删除。

浏览器不会提供文件夹在磁盘上的完整路径，所以文件搬家后，MangaView 以**文件夹名称**加**首个文件**（按文件名排序的第一个文件，不论图片、视频还是音频；与封面画面、自定义封面无关）的指纹来识别书。指纹是文件名、精确大小和文件开头 64 KB 的摘要，不读整个文件。含视频、音频的书另在后台记下各媒体文件的大小（只读文件信息）：文件夹改名或首个文件对不上时，媒体文件的「文件名 + 大小」大多对得上的也会列出来由你确认，同名但大小不同的不会自动接回；散图图集里的视频、音频按相对路径和文件名找回时还要求大小一致。合并作品按每一卷分别匹配：

- **重新添加上一级文件夹**：文件夹名称和封面都一致的过期书或缺失的卷会自动接回原记录，不会重复添加。
- **批量恢复…**（在「过期书籍」中）：选择存放这些书的文件夹，层级不限。完全匹配的直接恢复；可能匹配的（改了名但封面相同，或同名但封面不同）列出来由你勾选；其余保持过期。散图图集里失效的图片也一并找回。恢复只接回已有的记录，**不会新增书**：文件夹里没有对应记录的内容一律忽略。恢复单本书或「定位原文件」时，所选文件夹里其他失效的书和散图也会一并接回。
- **单本「恢复」**：选择这本书的文件夹。不匹配时也可以「强制恢复」，保留标签、书签和进度；整本过期的合并作品一卷都对不上时，按所选文件夹重建，相对路径相同的卷保留书签和进度；合并作品只缺一卷时，可以把所选文件夹强制接到这一卷，其他卷不受影响；缺多卷时不猜测，提示没有找到匹配的文件夹。

### 多个窗口

可以同时打开多个 MangaView 窗口（浏览器标签页或已安装应用的窗口），包括同一本书：

- 在一个窗口里对书目、书签、标签、封面、书名、所在列表的改动，其他窗口在 1 秒内跟着更新，只更新受影响的项。不同窗口修改同一本书的不同内容（例如各加一个书签）都会保留。
- 一个窗口删除了某本书，正在读它的其他窗口会提示并切到下一本，这本书的记录不会被写回。
- 设置（设置面板里的各项、语言、默认排序、音量和静音、播放顺序、循环、只播放书签区段）在所有窗口即时生效；缩略图栏和书架书签是否常驻、宽度、列表样式等布局各窗口互不影响，下次打开时用最后改动的那个。
- 每个窗口有自己的当前书和阅读位置；同一本书的阅读位置以最后保存的为准。视频、音频可以用「新窗口播放」放到单独的小窗口里接着播。
- 启动时检查全部文件夹、生成封面等后台读盘只由一个窗口进行，其他窗口不重复读硬盘；这个窗口关闭，或转到后台而另一个窗口在前台时，由别的窗口接手。
- 「还原默认设置」、导入备份、清除全部数据后，其他窗口自动重新载入。
- 新版本改变了存储结构时，仍开着的旧窗口会让出存储并提示重新载入，不会卡住新窗口。

### 数据与权限

图片、视频和音频只在本机读取，不会上传，也不会复制。浏览器里保存书目索引、只读文件句柄、排序设置、阅读位置、标签、书签、搜索预设，以及压缩后的小缩略图（封面、书签和视频画面，从不保存原文件）；清除站点数据会清空这些内容。

「设置 → 数据」显示存储占用，可以把全部数据导出为一个 JSON 文件，也可以导入（与现有数据合并或替换）。文件里不含图片和文件夹访问权限，在另一台电脑上导入后，书会显示在「过期书籍」里，用「批量恢复…」重新关联即可。备份格式为 2：仍可导入旧版导出的备份，但旧版应用无法导入新版备份。存储占用接近浏览器配额时，会提示删除不再需要的旧书记录。

设置面板底部的「还原默认设置」把设置项和界面布局（侧栏、宽度、默认排序等）恢复默认并重新载入页面，书籍、书签、标签、阅读进度和搜索预设都不受影响。

- 重新打开时如果浏览器收回了访问权限，用「重新授权」。
- 浏览器更新后，之前保存的文件夹访问可能整体失效（浏览器不再响应这些授权，重新选择同一个文件夹却正常）。这是浏览器的行为，网页应用拿不到磁盘路径，无法自行重新打开文件夹。MangaView 启动时会在几秒内判断出来（只问浏览器，不读硬盘，所以不会和机械硬盘读得慢混淆），并显示一条提示，说明是浏览器更新所致。点提示里的「批量恢复…」，选择存放漫画的上级文件夹，单文件夹书、合并作品的各卷、散图图集都会接回原记录，标签、书签和进度保留；选择框会开在上次恢复时的位置。硬盘只是读得慢时，图片在等待一段时间后显示「图片无法显示」，稍后会重试。
- 如果文件已经移动，用「定位原文件」。
- 不支持文件句柄的浏览器，重启后需要重新选择原文件。

## 从 v1 升级

原来位于 `/mangaview/dist/` 的旧版已被 v2 取代。v1 不保存阅读记录，因此没有数据需要迁移。

- 访问旧地址或打开已安装的 v1 应用时，会自动跳转到新版。
- 如果安装过 v1，请从地址栏安装 v2，然后在 `chrome://apps`（Edge 为 `edge://apps`）卸载旧版应用。

## 开发

没有构建步骤，也没有第三方依赖，全部是以静态文件提供的原生 ES 模块。

### 本地运行

仅用于开发调试；日常阅读请直接使用在线版。

- **Windows**：安装 [Python 3](https://www.python.org/) 后，双击仓库根目录的 `local_run.bat`。它会在 http://127.0.0.1:4173/ 启动服务并打开浏览器，关闭命令行窗口即停止。
- **任意平台**：在仓库根目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173/ 。

不支持直接双击 `index.html` 打开，因为安装、离线和文件访问都需要安全上下文（HTTPS 或 localhost）。

```sh
# 全部测试：先跑核心测试，再逐个串行跑无头 Chrome / Edge 端到端测试，失败的自动单独重跑一次，最后列出通过 / 失败清单
node tests/run.mjs "<chrome.exe 或 msedge.exe 的路径>"
# 只跑文件名包含给定名称的端到端测试（核心测试照常先跑）
node tests/run.mjs "<路径>" shelf media
# 只跑核心测试（纯逻辑，tests/core/*.test.mjs）
node tests/run.mjs
```

端到端测试（`tests/browser.mjs`、`tests/*.browser.mjs`）各自使用临时浏览器配置和自动生成的测试图片；视频、音频由 `tests/media-fixtures.mjs` 在测试页里现场生成。

以下几项自动化测试覆盖不到，需要人工验收：

- 安装后断网冷启动；
- 从真实机械硬盘（不要用 SSD 代替）导入数千张图片，并在滚动中切换书本；
- Windows 上用中键自动滚动连续读过长图；
- 已安装应用的实际窗口边框；
- 多个真实窗口在前台、后台、最小化之间切换时，后台读盘任务的交接；
- 机械硬盘上的大体积视频库（打开、定位、生成视频缩略图时的读盘表现）、真实窗口拖动缩放时视频的观感、视频的真实全屏。

### 发布

1. **同时**修改 `index.html` 的 `<title>` 和 `sw.js` 的 `cacheName` 中的版本号（有测试检查两者一致）。
2. 推送到 `main`，GitHub Pages 从仓库根目录提供服务。

已打开的窗口继续使用启动时的版本。新版在后台下载完成，并且旧窗口全部关闭后才会切换；下载失败或离线时继续使用当前版本。只要可能还有 v1 用户，就保留 `dist/`。
