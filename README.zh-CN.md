## 功能

- **打开本地文件**：用选择器或直接拖入文件夹、散图。每个直接包含图片的文件夹算一本书。
- **导入为单个作品**：分卷存放的作品可以把多个文件夹合成一本书，连续阅读。
- **为长条漫画设计**：每本书是一条连续的纵向长条，图片之间不吸附、不停顿，超长条漫也能顺畅阅读。
- **大图库流畅**：只创建和解码可见页面，并限制同时读取的数量。机械硬盘上的数千张图片也能流畅浏览。
- **缩略图导航**：鼠标移到窗口右缘时弹出，也可以常驻在正文旁边；还可以全屏总览整本书。点击缩略图的任意位置，就跳到图中对应的画面，超长图内部同样准确。
- **书架与书库**：正在读的放书架，其余放书库。以纯封面显示，可在普通网格和瀑布流之间切换，鼠标悬停或用方向键选中时显示书名和操作按钮。
- **搜索、筛选与预设**：按书名、路径、标签、页数、是否有书签筛选，常用条件可存为预设。
- **标签**：可为任意书添加自定义标签，输入时联想已有标签，每个标签自动配色；点击标签或在搜索框输入 `#标签` 即可筛选。
- **书签**：长按 `F` 为当前位置添加书签。书签列表显示画面缩略图，因为没人记得住文件名。
- **排序**：按文件名或修改时间正序、反序排列，或打乱顺序。可设为统一默认，也可单独设置某本书。
- **记住每本书的阅读位置**，刷新文件夹时同步新增或删除的图片。
- **文件搬家不丢记录**：找不到文件夹的书会归入「过期书籍」，封面、标签和书签都保留，之后可以重新关联。
- **备份**：所有应用数据可导出为一个文件，在另一台电脑上导入。
- **可安装、可离线**：可以安装为应用，首次加载后断网也能使用。
- **四种语言**：界面按浏览器语言自动显示中文、English、日本語或한국어。

## 开始使用

1. 用最新版桌面 **Chrome** 或 **Edge** 打开 **https://nohnolife.github.io/mangaview/** 。
2. *（可选）* 安装为应用：点击地址栏右端的安装图标，或在浏览器菜单中选择「安装 MangaView」。安装后有独立窗口，可固定到任务栏，断网也能使用。
3. 打开文件夹，或把图片拖进窗口。

新版本会自动更新，不需要下载、解压或任何配置。

### 工具栏与操作栏

鼠标移到窗口顶缘稍作停留，工具栏会在阅读区顶部居中弹出：一行图标，鼠标悬停显示名称，窗口较窄时自动换行；书名和阅读进度显示在它下方。也可以按 **T**，或按 Tab 聚焦左上角的菜单按钮后按 Enter。

鼠标移到窗口底缘则弹出操作栏，按钮固定为「上一本」「回到书首」、当前位置、「滚到书尾」「下一本」，已在书首 / 书尾时对应按钮变灰；切书只在这里，工具栏里没有上 / 下一本。书架页设了筛选条件时，上一本 / 下一本只在筛选结果内切换，按钮上带一个小圆点提示。

两者在鼠标移开后淡出收起，可以在 **设置 → 工具栏** 分别关闭边缘弹出，**T** 键仍然可用。单击正文只翻屏（左半屏前一屏、右半屏后一屏）；触屏上点正文顶部可以开关工具栏。

### 书架、书库和标签

点「书架」按钮或按 **B** 打开全屏页面，有四个列表（再点一次当前列表的页签，或再按 **B**，回到阅读界面）：

- **书架**：正在读的书。新打开的文件夹、重新打开的文件夹都会放到这里。
- **书库**：其余的书，用于管理大量藏书。书架页正显示书库时，打开或拖入的书放到书库。
- **全部**：两者合在一起，方便搜索全部内容。
- **过期书籍**：只在有书找不到文件夹时出现，见下文。

「上一本 / 下一本」在当前书所在的列表（书架或书库）内切换。书架页开着时导入新书不会切换正在读的书，只提示导入了几本。

打开书架时，焦点落在正在读的书上并滚动到它的位置。鼠标悬停和方向键选中是同一个状态，选中的封面显示书名、进度和标签，以及编辑书名、编辑标签、移动、复制书名、删除记录的按钮；`Enter` 打开，`Delete` 删除记录（会先确认）。有书签的书在封面左下角显示书签数。工具条最右侧的按钮在普通网格（默认，封面等大对齐）和瀑布流（按封面比例）之间切换。工具条按钮只显示图标，鼠标悬停可看说明。

**搜索与筛选**：搜索框匹配书名、文件夹路径、标签，以及合并作品各卷的文件夹名；输入 `#标签` 按标签筛选，`/` 或 `Ctrl+F` 可直接跳到搜索框。有筛选时，搜索框右侧显示结果数。「筛选」按钮展开筛选面板：页数范围、「包含书签」和标签（多个标签需同时满足，标签多时可以搜索）。面板收起时，生效的条件显示在下方；搜索框右边的「清除筛选」按钮一键清除全部条件。筛选条件会保存下来，在书架、书库和全部之间切换时保持不变；上一本 / 下一本和书架书签也只在筛选结果内进行。

**搜索预设**：把当前筛选条件存为预设，在预设菜单里点选即可应用，也可以重命名、删除或用当前条件更新；应用后再改动条件，预设按钮上会出现一个小圆点（提示文字标出「已修改」）。

**书籍排序**：排序菜单可以按添加时间（默认反序，即新添加的在前）、文件夹时间、名称排序，均可正反序（正序：从旧到新 / A→Z）；书架、书库、全部共用这个设置，上一本 / 下一本和书架书签也按这个顺序。浏览器读不到文件夹本身的修改时间，「文件夹时间」取文件夹中最新一张图片的修改时间，选用时才在后台计算（只读文件信息，不读图片），尚未算出的排在最后。

**批量操作**菜单：复制列表中的书名；「全部移入书架 / 书库」作用于当前筛选出的所有结果；「清空书架 / 书库」删除该列表中的全部书目（不受筛选影响），会先弹出确认，不会删除原图。

卡片上的铅笔按钮可以编辑书名，只改显示的名称，不改文件夹，搜索原文件夹名仍能找到；留空即恢复原名。编辑标签时输入即在输入框下方浮出联想的已有标签（`↑` `↓` 选择，选中后也可用 `←` `→`，回车添加，`Esc` 先收起联想），输入框为空时列出最近用过和常用的标签。标签颜色按名称自动生成，同名标签在任何地方颜色都一样。

### 导入为单个作品

一部作品分成多个文件夹（例如每卷一个）时，可以合成一本书连续阅读：拖入时把文件夹放到覆盖层下方的「导入为单个作品」区域，或点书架页头的「导入为单个作品」按钮选择一个文件夹，其下各个带图片的文件夹合成一本，按路径顺序排列。

- 同一组文件夹再次导入时，更新原来那本书而不是重复添加：新增的卷追加进来，已不存在的卷移除，书签和进度保留。
- 同一个文件夹可以既是一本独立的书，又是一本或多本合并作品中的一卷，刷新或重新导入时各处同步更新。
- 只有一个带图片的文件夹时按普通导入处理；散图仍单独导入。

### 书签

- **长按 `F` 或 `Enter`**：在屏幕中央位置添加书签。按住时会出现逐渐填满的圆环，提示正在添加；提前松开则按单击处理。
- **单击 `F` 或 `Enter`**：跳到下一个书签，到最后一个后回到第一个；加 `Shift` 则反向，跳到上一个。
- **右键单击**：在鼠标处打开书签面板，「添加书签」按钮正好在鼠标下方。点击书签跳过去并关闭面板，鼠标悬停不会跳转；按 **Esc** 或点击面板外关闭，位置不变。

书签附带一张画面缩略图，并且记录的是所在图片而不是滚动位置，所以重新排序后依然有效。

**书架书签**：与缩略图栏的用法相同，按书架顺序集中显示书架上所有书的书签（不含书库和过期书籍；书架页有筛选时只含筛选结果）。默认不常驻：鼠标移到窗口左缘稍作停留即浮动弹出、移开后淡出收起（**设置 → 阅读** 可关闭左缘弹出）。点工具栏的「书架书签」按钮可以把它常驻在左侧，正文相应变窄；拖动列表右边缘可以调整宽度。鼠标悬停不会跳转，点击书签才跳过去，必要时自动打开那本书。列表紧凑显示，每本书一组缩略图（当前书的一组高亮），不显示书名和文件名；顶部的按钮打开全屏书架书签。常驻期间单击 `F` / `Enter`（加 `Shift` 反向）也按这个列表前进，本书后面没有书签时跳到下一本书的第一个书签，最后回到开头。当前书在书库中时仍只在本书内循环。

**专注模式**（默认开启，可在 **设置 → 阅读** 关闭）：常驻的书架书签列表和缩略图栏在鼠标没有悬停、也没有用键盘进入时隐藏内容，但仍然占位、不收起，底色与阅读区相同，减少干扰。鼠标移上去即恢复显示。显示和隐藏都是带短暂延迟的淡入淡出，鼠标快速划过时不会闪。

### 缩略图栏

鼠标移到窗口右缘稍作停留，缩略图栏会浮在正文上方弹出，移开后自动收起（**设置 → 阅读** 可关闭）。点工具栏的缩略图按钮可以把它设为常驻：常驻时它停靠在右侧，正文相应变窄，不会被遮挡。拖动缩略图栏左边缘可以调整宽度。栏顶显示页数和「全屏缩略图」按钮。

缩略图缓存在本次会话的内存里（上限 64 MB，不写入磁盘）：同一本书再次打开全屏缩略图，或切到别的书再回来，都不必重新读取原图，直到关闭应用。

**全屏缩略图**：点缩略图栏顶部的按钮，或按 `V` / `]` 打开整本书的全屏总览，再按一次或按 `Esc` 关闭。页面默认排成规整的网格，标题行的按钮可以切换为按页面比例排列的瀑布流（两个全屏界面共用这个选择）；右侧是加宽的滚动条，适合页数很多的书快速浏览和定位。打开时选中当前页；`A` `D` / `←` `→` 按页序移动，`W` `S` / `↑` `↓` 在同一列上下移动，也支持 `Page Up` / `Page Down`、`Home` / `End`。点击缩略图或按 `空格` / `Enter` 跳到该页顶部并关闭。

**全屏书架书签**：点书架书签列表顶部的按钮，或按 `C` / `[` 打开，全屏显示书架上所有书签，按书分组并以书名作小标题（当前书高亮），同样可以切换网格和瀑布流。打开时选中当前位置附近的书签；`A` `D` / `←` `→` 按顺序移动，`W` `S` / `↑` `↓` 移到上 / 下一行横向最近的书签；点击或 `空格` / `Enter` 跳过去，必要时自动切换书籍。在一个全屏界面里按 `V` / `]` 或 `C` / `[` 可直接切换到另一个。

### 排序

在「排序」里选「当前文件夹／书本」，只为当前这本书设置顺序；选「统一默认排序」则修改默认顺序。「跟随默认排序」会取消这本书的单独设置。每次选择「打乱图片」都会重新洗牌，但重新打开同一本书时保持原来的乱序。按修改时间排序时，按需读取文件的修改时间；重新导入文件夹可以刷新这些时间。

### 刷新文件夹

MangaView 会在三种情况下检查文件夹里图片的增删（第一种可在「设置」中关闭）：

- 每次打开应用或刷新页面时，先检查当前这本书，其余仍有访问权限的文件夹在浏览器空闲时逐个在后台检查，不与阅读抢硬盘；
- 切回应用窗口时，检查当前这本书；
- 点「刷新」按钮（工具栏「书架」按钮右侧和书架页上各有一个）时，检查全部文件夹，并可为当前书重新请求授权。

刷新不会发现新增的子文件夹，需要重新打开上一级文件夹。

### 过期书籍与文件搬家

找不到文件夹的书**永远不会**被自动删除，因为浏览器无法区分“文件夹已删除”和“移动硬盘未连接”。一本书的文件夹**全部**找不到时，它会归入「过期书籍」，封面、标签、书签和进度都保留；重新连接硬盘并刷新后会自动回到原来的列表。合并作品只有部分卷找不到时，书照常可读，缺失的卷暂时隐藏，书架卡片上有一个小提示，找回后自动恢复，也可以点卡片上的「恢复」重新关联。只有你手动删除时，记录才会被删除。

浏览器不会提供文件夹在磁盘上的完整路径，所以文件搬家后，MangaView 以**文件夹名称**加**封面**（按文件名排序的第一张图）的内容摘要来识别书；合并作品按每一卷分别匹配：

- **重新打开上一级文件夹**：文件夹名称和封面都一致的过期书或缺失的卷会自动接回原记录，不会重复添加。
- **批量恢复…**（在「过期书籍」中）：选择存放这些书的文件夹，层级不限。完全匹配的直接恢复；可能匹配的（改了名但封面相同，或同名但封面不同）列出来由你勾选；其余保持过期。
- **单本「恢复」**：选择这本书的文件夹。不匹配时也可以「强制恢复」，保留标签、书签和进度；整本过期的合并作品一卷都对不上时，按所选文件夹重建，相对路径相同的卷保留书签和进度；合并作品只缺一卷时，可以把所选文件夹强制接到这一卷，其他卷不受影响；缺多卷时不猜测，提示没有找到匹配的文件夹。

### 数据与权限

图片只在本机读取，不会上传，也不会复制。浏览器里保存书目索引、只读文件句柄、排序设置、阅读位置、标签、书签、搜索预设，以及压缩后的小缩略图（封面和书签，从不保存原图）；清除站点数据会清空这些内容。

「设置 → 数据」显示存储占用，可以把全部数据导出为一个 JSON 文件，也可以导入（与现有数据合并或替换）。文件里不含图片和文件夹访问权限，在另一台电脑上导入后，书会显示在「过期书籍」里，用「批量恢复…」重新关联即可。备份格式为 2：仍可导入旧版导出的备份，但旧版应用无法导入新版备份。存储占用接近浏览器配额时，会提示删除不再需要的旧书记录。

设置面板底部的「还原默认设置」把设置项和界面布局（侧栏、宽度、默认排序等）恢复默认并重新载入页面，书籍、书签、标签、阅读进度和搜索预设都不受影响。

- 重新打开时如果浏览器收回了访问权限，用「重新授权」。
- 如果文件已经移动，用「定位原文件」。
- 不支持文件句柄的浏览器，重启后需要重新选择原文件。

## 从 v1 升级

原来位于 `/mangaview/dist/` 的旧版已被 v2 取代。v1 不保存阅读记录，因此没有数据需要迁移。

- 访问旧地址或打开已安装的 v1 应用时，会自动跳转到新版。
- 如果安装过 v1，请从地址栏安装 v2，然后在 `chrome://apps`（Edge 为 `edge://apps`）卸载旧版应用。

## 开发

没有构建步骤，也没有第三方依赖，全部是以静态文件提供的原生 ES 模块。

### 本地运行

仅用于开发调试；日常阅读请直接使用在线版。

- **Windows**：安装 [Python 3](https://www.python.org/) 后，双击仓库根目录的 `local_run.bat`。它会在 http://127.0.0.1:4173/ 启动服务并打开浏览器，关闭命令行窗口即停止。
- **任意平台**：在仓库根目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4173/ 。

不支持直接双击 `index.html` 打开，因为安装、离线和文件访问都需要安全上下文（HTTPS 或 localhost）。

### 发布

1. **同时**修改 `index.html` 的 `<title>` 和 `sw.js` 的 `cacheName` 中的版本号（有测试检查两者一致）。
2. 推送到 `main`，GitHub Pages 从仓库根目录提供服务。

已打开的窗口继续使用启动时的版本。新版在后台下载完成，并且旧窗口全部关闭后才会切换；下载失败或离线时继续使用当前版本。只要可能还有 v1 用户，就保留 `dist/`。
